Here is the Python function implementing the decision logic based on the provided features:

```python
def predict(X: dict) -> tuple[int, list[int]]:
    """
    Predicts the party affiliation (Republican or Democrat) based on votes for MX Missile and Aid to Nicaraguan Contras.

    Args:
        X (dict): A dictionary containing the voting data with keys as feature names and values as 1 ('No') or 2 ('Yes').

    Returns:
        tuple[int, list[int]]: A tuple where the first element is the prediction (1 for Republican, 0 for Democrat),
                               and the second element is a list of integers representing whether each inner node condition was met.
    """
    
    # Initialize nodes to track which conditions were met
    nodes = [False] * 2
    
    # First condition: Vote on MX Missile
    nodes[0] = X['mx missile'] == 2
    if nodes[0]:
        prediction = 1  # Predict Republican
    else:
        # Second condition: Vote on Aid to Nicaraguan Contras
        nodes[1] = X['aid to nicaraguan contras'] == 2
        if nodes[1]:
            prediction = 1  # Predict Republican
        else:
            prediction = 0  # Predict Democrat
    
    # Convert boolean nodes to integers (True -> 1, False -> 0)
    nodes_as_int = [int(node) for node in nodes]
    
    return prediction, nodes_as_int
```

**Explanation:**

- **Function Definition:** The function `predict` takes a dictionary `X` containing the voting data and returns a tuple with the predicted party (1 for Republican, 0 for Democrat) and a list indicating which inner node conditions were satisfied.

- **Nodes Initialization:** Two nodes are initialized to track whether each condition was met. In this case, nodes correspond to votes on MX Missile and Aid to Nicaraguan Contras.

- **First Condition Check:** The function first checks if the vote on MX Missile was 'Yes' (value 2). If true, it predicts Republican and stops further evaluation as per decision tree logic.

- **Second Condition Check:** If the first condition is not met, the function then checks the vote on Aid to Nicaraguan Contras. A 'Yes' vote here also leads to a Republican prediction, while a 'No' results in a Democrat prediction.

- **Nodes Conversion:** The boolean values of the nodes are converted to integers (True becomes 1, False becomes 0) for the final output list.

This function accurately models the decision tree logic and provides clear outputs for both the prediction and the evaluation path taken through the tree.
