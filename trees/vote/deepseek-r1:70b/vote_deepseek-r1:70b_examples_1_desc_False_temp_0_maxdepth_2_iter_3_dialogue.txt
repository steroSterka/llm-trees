Here's a Python function implementing the decision tree for predicting party affiliation based on the voting features:

```python
def predict(X: dict):
    # Initialize nodes with None
    nodes = [None] * 2
    
    # First node: Aid to Nicaraguan contras (yes == 2)
    nodes[0] = X["aid to nicaraguan contras"] == 2
    
    if nodes[0]:
        # Second node: MX missile (yes == 2)
        nodes[1] = X["mx missile"] == 2
        if nodes[1]:
            prediction = 1  # Republican
        else:
            prediction = 0  # Democrat
    else:
        # Second node: El Salvador aid (yes == 2)
        nodes[1] = X["el salvador aid"] == 2
        if nodes[1]:
            prediction = 0  # Democrat
        else:
            prediction = 1  # Republican
    
    # Convert booleans to integers for the nodes list
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
```

This function first evaluates whether aid was provided to Nicaraguan contras. Depending on this result, it then checks either the MX missile funding or El Salvador aid. The prediction is made based on these evaluations, and both conditions are recorded as integers (1 for True, 0 for False) in the nodes list.
