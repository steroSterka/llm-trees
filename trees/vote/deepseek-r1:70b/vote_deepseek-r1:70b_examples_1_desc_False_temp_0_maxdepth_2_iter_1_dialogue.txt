Here is the Python function that implements the decision tree classifier:

```python
def predict(X: dict):
    nodes = [None, None]
    
    # First inner node: Vote on MX missile (yes / no)
    nodes[0] = X['mx missile'] == 2
    
    # Second inner node: Vote on aid to Nicaraguan contras (yes / no)
    nodes[1] = X['aid to nicaraguan contras'] == 2
    
    if nodes[0]:
        prediction = 1  # Republican
    else:
        if nodes[1]:
            prediction = 1  # Republican
        else:
            prediction = 0  # Democrat
            
    return prediction, [int(nodes[0]), int(nodes[1])]
```

This function takes a dictionary `X` with the specified features and returns both the predicted party affiliation (as an integer) and a list of boolean values representing the evaluation of each inner node in the decision tree.
