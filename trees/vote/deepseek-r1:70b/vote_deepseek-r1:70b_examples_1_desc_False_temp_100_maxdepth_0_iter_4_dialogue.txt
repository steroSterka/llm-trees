To address this problem, we need to create a function that predicts a political party affiliation based on specific voting behaviors. The prediction is determined using a decision tree approach, where each node represents a condition check on the votes cast for certain policies. The goal is to return both the predicted class and a list of truth values representing whether each condition in the decision tree was met.

### Approach
1. **Decision Tree Structure**: The decision tree prioritizes three specific votes: "aid to El Salvador", "MX missile", and "immigration". The structure is as follows:
   - If the vote on "aid to El Salvador" is 'yes' (represented by 2), the prediction is Republican.
   - If not, check the vote on "MX missile": if 'yes', predict Republican; otherwise, proceed.
   - If neither of the above conditions is met, check the vote on "immigration": if 'yes', predict Democrat; otherwise, predict Democrat.

2. **Node Evaluation**: Each condition in the decision tree is evaluated upfront and stored in a list. This ensures that all relevant node conditions are checked regardless of the prediction path taken.

3. **Prediction Logic**: Based on the evaluated nodes, the function determines the final prediction by following the decision tree's hierarchical structure.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    # Initialize nodes with None (will be replaced by 0 or 1)
    nodes = [None] * 3
    
    # Evaluate conditions for each node upfront
    nodes[0] = X['el salvador aid'] == 2  # Vote yes on El Salvador aid?
    nodes[1] = X['mx missile'] == 2      # Vote yes on MX missile?
    nodes[2] = X['immigration'] == 2     # Vote yes on immigration?
    
    # Convert boolean values to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]
    
    # Determine prediction based on the decision tree
    if nodes[0]:  # El Salvador aid is yes
        prediction = 1  # Republican
    else:
        if nodes[1]:  # MX missile is yes
            prediction = 1  # Republican
        else:
            prediction = 0  # Democrat (whether immigration is yes or no)
    
    return prediction, nodes
```

### Explanation
- **Node Initialization**: The function initializes a list `nodes` with three elements set to `None`, each representing a condition check in the decision tree.
- **Condition Evaluation**: Each node is evaluated based on the corresponding feature's value from the input dictionary `X`. These evaluations are converted to boolean values and then to integers (1 for True, 0 for False).
- **Prediction Logic**: The function follows the hierarchical structure of the decision tree. It first checks if "aid to El Salvador" was voted yes; if not, it proceeds to check "MX missile", and finally "immigration".
- **Return Values**: The function returns a tuple containing the predicted class (0 for Democrat, 1 for Republican) and a list of integers representing whether each condition in the decision tree was met.

This approach ensures that all relevant conditions are evaluated efficiently, providing both the prediction result and the trace of how the decision was reached.
