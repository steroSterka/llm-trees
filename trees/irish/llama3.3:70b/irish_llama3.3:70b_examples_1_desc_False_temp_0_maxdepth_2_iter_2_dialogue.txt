Here's a Python function that implements the decision tree for predicting whether a school leaving certificate is taken or not based on the given features. This function takes in a dictionary `X` containing the feature values and returns a tuple where the first element is the predicted target variable (0 = not taken, 1 = taken) and the second element is a list of boolean values representing the truth values of the inner nodes.

```python
def predict(X: dict):
    """
    Predicts whether a school leaving certificate is taken or not based on the given features.
    
    Parameters:
    X (dict): Dictionary containing feature values. Keys are 'Sex', 'DVRT', 'Educational_level', 'Prestige_score', 'Type_school'.
    
    Returns:
    tuple: A tuple where the first element is the predicted target variable (0 = not taken, 1 = taken) and the second element is a list of boolean values representing the truth values of the inner nodes.
    """
    
    # Initialize nodes
    nodes = 2 * [None]
    
    # Node 0: Educational level attained <= 5
    nodes[0] = X["Educational_level"] <= 5
    
    # Node 1: Type of school is secondary (Type_school == 1)
    nodes[1] = X["Type_school"] == 1
    
    # Prediction based on the decision tree
    if not nodes[0]:  # Educational level > 5
        prediction = 1  # Certificate taken
    else:
        if nodes[1]:  # Type of school is secondary
            prediction = 1  # Certificate taken
        else:
            prediction = 0  # Certificate not taken
    
    # Convert boolean values to integers (True -> 1, False -> 0) for the nodes list
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes

# Example usage:
X = {
    "Sex": 0,
    "DVRT": 50,
    "Educational_level": 8,

print(f"Prediction: {prediction}")  # Output: Prediction: 1

```

This decision tree uses the `Educational_level` and `Type_school` features to make predictions.
