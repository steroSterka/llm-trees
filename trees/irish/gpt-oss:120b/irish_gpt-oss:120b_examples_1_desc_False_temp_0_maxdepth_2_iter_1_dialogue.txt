**Python implementation of the depth‑2 decision tree**

```python
def predict(X: dict):
    """
    Predict whether the school‑leaving certificate is taken (target = 1)
    or not (target = 0) using a depth‑2 decision tree.

    Expected keys in the input dictionary *X*:
        - 'DVRT'               : Drumcondra Verbal Reasoning Test score (numeric)
        - 'Educational_level' : Categorical level encoded as 0‑10 (see description)
        - 'Prestige_score'    : Father’s occupational prestige (0‑28)

    Returns
    -------
    prediction : int
        1 if the model predicts the certificate is taken,
        0 otherwise.
    nodes : list[int]
        Truth values of the inner (decision) nodes in the order they are
        evaluated.  `1` means the condition is satisfied, `0` means it is not.
        The list has length 2:
            nodes[0] – result of the root split (DVRT ≤ 48)
            nodes[1] – result of the second‑level split that is actually
                       evaluated for the branch taken.
    """
    # -------------------------------------------------
    # 1️⃣  Root node: DVRT score
    # -------------------------------------------------
    nodes = [None, None]                     # placeholder for the two inner nodes
    nodes[0] = 1 if X["DVRT"] <= 48 else 0   # 1 → “DVRT ≤ 48”, 0 → “DVRT > 48”

    # -------------------------------------------------
    # 2️⃣  Second‑level node – depends on the root outcome
    # -------------------------------------------------
    if nodes[0] == 1:          # DVRT ≤ 48  → look at Educational_level
        nodes[1] = 1 if X["Educational_level"] <= 4 else 0
        # Educational_level ≤ 4  → no certificate (0)
        # Educational_level > 4  → certificate   (1)
        prediction = 0 if nodes[1] == 1 else 1
    else:                      # DVRT > 48  → look at Prestige_score
        nodes[1] = 1 if X["Prestige_score"] <= 12 else 0
        # Prestige_score ≤ 12   → certificate   (1)
        # Prestige_score > 12   → no certificate (0)
        prediction = 1 if nodes[1] == 1 else 0

    return prediction, nodes
```

### How the function works  

| Step | Condition evaluated (`nodes[i]`) | Meaning of `1` | Meaning of `0` | Resulting prediction |
|------|-----------------------------------|----------------|----------------|----------------------|
| 0    | `DVRT ≤ 48`                       | Yes (score ≤ 48) | No (score > 48) | – |
| 1 (left branch) | `Educational_level ≤ 4` | Yes → **no** certificate (`target = 0`) | No → **yes** certificate (`target = 1`) | Determined by this node |
| 1 (right branch) | `Prestige_score ≤ 12` | Yes → **yes** certificate (`target = 1`) | No → **no** certificate (`target = 0`) | Determined by this node |

The returned `nodes` list tells you exactly which internal decisions were true (`1`) or false (`0`) for the particular input record, while `prediction` is the final class (0 = not taken, 1 = taken).
