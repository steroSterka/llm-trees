### How to read the tree

* **Root node** – the first split checks whether the learner has already reached **educational level 5** (roughly the midway point of a 10‑level system).  
  * If **yes**, the model is confident the certificate will be obtained → **Certificate_Taken**.  
  * If **no**, we look deeper.

* **Second level** – for those below level 5, the **Verbal Reasoning Test Score** is examined.  
  * A score **≥ 68** (about the 70th percentile in typical samples) still predicts completion despite the low level.  
  * Scores **< 68** move to the next decision.

* **Third level** – **type of school** matters most for low‑scoring, low‑level students.  
  * **Secondary** schools (standard academic track) still give a good chance → **Certificate_Taken**.  
  * **Vocational** or **primary‑terminal** schools need further discrimination.

* **Fourth level** – **father’s occupational prestige** acts as a proxy for socioeconomic support.  
  * **≥ 12** (mid‑range prestige) lifts the odds enough to predict completion.  
  * **< 12** pushes us to the final split.

* **Fifth level** – **Sex** is the last tie‑breaker for the most at‑risk group (low level, low test score, low‑prestige background, non‑secondary school).  
  * **Female** learners are slightly more likely to stay in school → **Certificate_Taken**.  
  * **Male** learners in this exact profile are predicted **not** to obtain the certificate → **Certificate_Not_Taken**.

```python
def predict(X: dict):
    """
    Predict whether the school‑leaving certificate is taken (target = 1)
    or not taken (target = 0) using the tree described in the prompt.

    Expected keys in *X* (pay attention to spelling and case):
        'Sex'                : 0 = female, 1 = male
        'DVRT'               : Drumcondra Verbal Reasoning Test score (0‑100)
        'Educational_level' : integer 0‑10 (see description for each code)
        'Prestige_score'    : 0‑28
        'Type_school'       : 0 = primary_terminal_leaver,
                              1 = secondary_terminal_leaver,
                              2 = vocational

    Returns
    -------
    prediction : int
        1 → certificate taken, 0 → not taken
    nodes : list[int]
        Truth values of the inner‑node tests in the order they are
        evaluated. 1 means the condition is satisfied, 0 otherwise.
    """

    # ------------------------------------------------------------------
    # 1️⃣  Compute the Boolean outcome of every inner node (independent of
    #     the path that will later be followed).  The list follows the
    #     order used in the nested‑if structure below.
    # ------------------------------------------------------------------
    nodes = [None] * 5                     # placeholder for 5 inner nodes

    # Node 0 : Educational_level >= 5 ?
    nodes[0] = 1 if X["Educational_level"] >= 5 else 0

    # Node 1 : DVRT >= 68 ?
    nodes[1] = 1 if X["DVRT"] >= 68 else 0

    # Node 2 : Type_school == 1  (secondary terminal leaver) ?
    nodes[2] = 1 if X["Type_school"] == 1 else 0

    # Node 3 : Prestige_score >= 12 ?
    nodes[3] = 1 if X["Prestige_score"] >= 12 else 0

    # Node 4 : Sex == 0  (female) ?
    nodes[4] = 1 if X["Sex"] == 0 else 0

    # ------------------------------------------------------------------
    # 2️⃣  Follow the decision tree using the pre‑computed node values.
    # ------------------------------------------------------------------
    if nodes[0]:                     # Educational_level >= 5
        prediction = 1               # certificate taken
    else:
        if nodes[1]:                 # DVRT >= 68
            prediction = 1
        else:
            if nodes[2]:             # secondary school
                prediction = 1
            else:
                if nodes[3]:         # Prestige_score >= 12
                    prediction = 1
                else:
                    if nodes[4]:     # female
                        prediction = 1
                    else:
                        prediction = 0   # male, low prestige, vocational/primary

    # Convert Booleans (True/False) to ints (1/0) for the output list
    nodes = [int(v) for v in nodes]

    return prediction, nodes
```

### How it works  

| Inner node (index) | Test (as computed in `nodes[i]`)                     | Meaning when **1** |
|--------------------|------------------------------------------------------|--------------------|
| 0                  | `Educational_level >= 5`                             | Learner has reached at least the “Junior‑cycle terminal leaver – secondary” stage. |
| 1                  | `DVRT >= 68`                                         | Verbal‑reasoning ability is above the 70‑th percentile – strong predictor of completion. |
| 2                  | `Type_school == 1`                                   | Attends a secondary (academic) school rather than vocational or primary‑terminal. |
| 3                  | `Prestige_score >= 12`                               | Father’s occupational prestige is at least median. |
| 4                  | `Sex == 0`                                           | Learner is female (slightly higher persistence). |

If **any** of the conditions 0 → 4 is satisfied (in the order above), the model predicts that the school‑leaving certificate will be taken (`prediction = 1`).  
Only when **all** five conditions are false (i.e., low educational level, low DVRT, non‑secondary school, low prestige, and male) does the model output `0` (certificate not taken).
