To solve this problem, we need to build a decision tree classifier that predicts an outcome based on given features. The tree will have a maximum depth of 2, meaning it can have at most two levels of splits. This constraint ensures the model remains simple and interpretable while still capturing important patterns in the data.

### Approach
The approach involves using a decision tree with a maximum depth of 2. The tree will first split the data based on the "Educational_level" feature. If the educational level is greater than 5, it will further split based on the "DVRT" feature. If the educational level is 5 or less, it will split based on the "Prestige_score" feature. Each path from the root to a leaf represents a decision rule that predicts the target variable.

### Solution Code
```python
def predict(X):
    nodes = []
    # First condition: Educational_level > 5
    educational_condition = X['Educational_level'] > 5
    nodes.append(educational_condition)
    
    if educational_condition:
        # Second condition for Educational_level > 5 branch: DVRT > 50
        dvrt_condition = X['DVRT'] > 50
        nodes.append(dvrt_condition)
    else:
        # Second condition for Educational_level <= 5 branch: Prestige_score > 15
        prestige_condition = X['Prestige_score'] > 15
        nodes.append(prestige_condition)
    
    # Determine prediction based on the evaluated conditions
    if educational_condition:
        prediction = 1 if nodes[1] else 0
    else:
        prediction = 1 if nodes[1] else 0
    
    return prediction, nodes
```

### Explanation
The function `predict` takes a dictionary `X` containing the features and returns both the predicted outcome and a list of boolean values representing the conditions evaluated at each inner node of the decision tree.

1. **First Split (Root Node):** The data is first split based on whether "Educational_level" is greater than 5.
2. **Second Split:** Depending on the result of the first split:
   - If true, further split using "DVRT" > 50.
   - If false, further split using "Prestige_score" > 15.

The prediction is determined based on these splits:
- If both conditions (first and subsequent) are met, the prediction is 1.
- If any condition fails, the prediction is adjusted accordingly to 0 or remains 0.

This approach ensures that we build a simple yet effective decision tree model with a maximum depth of 2, which helps in maintaining interpretability while making accurate predictions.
