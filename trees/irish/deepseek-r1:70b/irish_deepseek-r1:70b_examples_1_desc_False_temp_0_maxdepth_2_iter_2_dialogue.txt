To solve this problem, we need to implement a function that predicts an outcome based on given thresholds for two features: Educational Level and DVRT. The prediction is made using a decision tree structure with a maximum depth of 2.

### Approach
The approach involves the following steps:
1. **Evaluate the first feature (Educational Level)**: Check if the value is less than or equal to a threshold (5). This determines whether we proceed to evaluate the second feature.
2. **Conditionally evaluate the second feature (DVRT)**: Only if the first condition (Educational Level) is met, check if DVRT is less than or equal to another threshold (50).
3. **Make the prediction**: Based on the results of the evaluations:
   - If both conditions are satisfied, predict 0.
   - Otherwise, predict 1.

### Solution Code
```python
def predict(X: dict):
    educational_level = X['Educational_level']
    dvrt = X['DVRT']
    
    node0 = int(educational_level <= 5)
    node1 = 0
    
    if node0:
        node1 = int(dvrt <= 50)
    
    prediction = 0 if (node0 and node1) else 1
    
    return prediction, [node0, node1]
```

### Explanation
- **Feature Evaluation**: The function starts by extracting the values of 'Educational_level' and 'DVRT' from the input dictionary. It then evaluates these against their respective thresholds.
- **Decision Tree Structure**: 
  - The first evaluation (`node0`) checks if `Educational_level` is less than or equal to 5. This determines whether we proceed to evaluate the second feature.
  - If `node0` is true, the function proceeds to check if `DVRT` is less than or equal to 50 (`node1`). 
- **Prediction**: The prediction is made based on both evaluations. If both conditions are satisfied (both nodes are 1), the prediction is 0. Otherwise, the prediction is 1.

This approach efficiently uses a decision tree structure with conditional checks to make accurate predictions while ensuring minimal computations by only evaluating the second feature when necessary.
