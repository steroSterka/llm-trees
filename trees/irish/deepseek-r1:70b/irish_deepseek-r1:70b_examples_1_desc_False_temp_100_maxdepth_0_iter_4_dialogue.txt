To solve this problem, we need to determine whether an individual took a specific certificate based on their educational background and other factors such as DVRT (Dental Vocational Registration Test) scores and prestige scores. The decision is made using a decision tree that evaluates different conditions based on the type of school attended.

### Approach
The approach involves constructing a decision tree where each node represents a condition check. The tree starts by checking the type of school attended, which can be secondary, vocational, or primary. Depending on the type of school, different subsequent conditions are evaluated:

1. **Secondary School**: If the individual attended secondary school, we first check if their educational level is 4 or higher. If so, they are considered to have taken the certificate. Otherwise, we check if their DVRT score exceeds 50.
2. **Vocational School**: For vocational school attendees, we check if their prestige score is at least 10. If it is, they are considered to have taken the certificate; otherwise, they are not.
3. **Primary Terminal Leaver**: For those who attended primary school, we first check if their educational level is 5 or higher. If so, they took the certificate. Otherwise, we check if their DVRT score exceeds 45. If it does, we then check if their prestige score is at least 12 to determine the outcome.

Each condition check corresponds to a node in the decision tree, and the results of these checks are recorded as boolean values in a list, which is returned along with the final prediction.

### Solution Code
```python
def predict(X):
    type_school = X['Type_school']
    educational_level = X['Educational_level']
    dvrt = X['DVRT']
    prestige_score = X['Prestige_score']

    # Initialize nodes to keep track of each condition check in order
    nodes = [False] * 6  # Six inner node conditions

    prediction = 0  # Default assumption is did not take the certificate

    if type_school == 1:
        # Secondary school path
        nodes[0] = (educational_level >= 4)
        if nodes[0]:
            prediction = 1
        else:
            nodes[1] = (dvrt > 50)
            prediction = 1 if nodes[1] else 0

    elif type_school == 2:
        # Vocational school path
        nodes[2] = (prestige_score >= 10)
        prediction = 1 if nodes[2] else 0

    else:
        # Primary terminal leaver path
        nodes[3] = (educational_level >= 5)
        if nodes[3]:
            prediction = 1
        else:
            nodes[4] = (dvrt > 45)
            if nodes[4]:
                nodes[5] = (prestige_score >= 12)
                prediction = 1 if nodes[5] else 0
            else:
                prediction = 0

    # Convert boolean values in nodes to integers (True->1, False->0)
    nodes_int = [int(node) for node in nodes]

    return prediction, nodes_int
```

### Explanation
The function `predict` takes a dictionary `X` containing the individual's educational background and scores. It initializes a list of nodes to keep track of each condition check. The type of school attended determines the subsequent checks:

1. **Secondary School**: Checks if the educational level is at least 4, then DVRT score if needed.
2. **Vocational School**: Checks the prestige score directly.
3. **Primary Terminal Leaver**: Checks educational level first, followed by DVRT and prestige scores if necessary.

Each condition's result is stored in the nodes list as boolean values, which are then converted to integers (1 for True, 0 for False) before returning along with the final prediction of whether the certificate was taken. This approach ensures that each decision path is accurately captured and evaluated.
