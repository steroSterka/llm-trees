```python
def predict(X: dict):
    nodes = [None] * 4  # Initialize nodes to keep track of condition evaluations
    
    # Determine Type of School
    type_school = X['Type_school']
    nodes[0] = (type_school == 0)  # Primary terminal leaver
    
    if type_school == 0:
        prediction = 0  # Not taken
    else:
        educational_level = X['Educational_level']
        x_threshold = 7
        nodes[1] = (educational_level > x_threshold)
        
        if educational_level > x_threshold:
            prediction = 1  # Taken
        else:
            dvrt_score = X['DVRT']
            y_threshold = 50
            nodes[2] = (dvrt_score > y_threshold)
            
            if dvrt_score > y_threshold:
                prediction = 1  # Taken
            else:
                prestige_score = X['Prestige_score']
                z_threshold = 14
                nodes[3] = (prestige_score > z_threshold)
                
                if prestige_score > z_threshold:
                    prediction = 1  # Taken
                else:
                    prediction = 0  # Not taken
    
    # Convert boolean nodes to 1 (True) or 0 (False)
    nodes = [1 if node else 0 for node in nodes]
    
    return prediction, nodes
```

- **Nodes Tracking**: Each condition in the decision tree is evaluated and stored in `nodes`, which are then converted to 1 (True) or 0 (False).
