```python
def predict(X: dict):
    nodes = [None, None]  # Two inner nodes for max depth of 2
    
    # First split: DVRT <= 30
    nodes[0] = X["DVRT"] <= 30
    
    if nodes[0]:
        # Second split: Educational_level <= 4
        nodes[1] = X["Educational_level"] <= 4
        
        if nodes[1]:
            prediction = 0  # Certificate not taken
        else:
            prediction = 1  # Certificate taken
    else:
        # Second split: Type_school is either secondary (1) or vocational (2)
        nodes[1] = X["Type_school"] in [1, 2]
        
        if nodes[1]:
            prediction = 1  # Certificate taken
        else:
            prediction = 0  # Certificate not taken
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation:

- **First Inner Node (`nodes[0]`)**: Checks if the `DVRT` score is less than or equal to 30. This helps determine whether the individual's verbal reasoning abilities are below a certain threshold.
  
- **Second Inner Node (`nodes[1]`)**:
  - If `nodes[0]` is true, it checks if the `Educational_level` is less than or equal to 4. Lower educational levels often correlate with not obtaining a certificate.
  - If `nodes[0]` is false, it checks if the `Type_school` is either secondary (1) or vocational (2). These types of schools are more likely to lead to certificate attainment compared to primary terminal leavers.

- **Prediction**:
  - Based on the path taken through the decision tree, the function returns a prediction of whether the school leaving certificate was taken (1) or not (0).
  - The list `nodes` contains boolean values (converted to integers) indicating whether each condition was met during the classification process. This helps in understanding the decision-making path for transparency and debugging purposes.
