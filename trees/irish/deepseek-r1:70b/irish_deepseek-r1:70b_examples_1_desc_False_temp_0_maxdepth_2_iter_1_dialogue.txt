To solve this problem, we need to create a decision tree model that predicts whether someone is likely to be educated beyond a certain level based on their educational level and DVRT score. The decision tree will have a maximum depth of 2, meaning it can split data in two places.

### Approach
1. **Problem Analysis**: We are given two features: Educational Level (ranging from 0 to 10) and DVRT Score. Based on these features, we need to predict if the person's educational level is higher than a certain threshold.
2. **Decision Tree Structure**: The decision tree will have a root node that splits based on the Educational Level. If the Educational Level is greater than 5, it predicts a positive outcome (educated beyond the threshold). Otherwise, it further splits based on the DVRT Score to make the prediction.
3. **Inner Nodes Evaluation**: We evaluate both conditions (Educational Level and DVRT Score) for each input, even though some instances will only need the first condition due to the tree's structure.

### Solution Code

```python
def predict(X):
    # Evaluate the two inner node conditions
    nodes = [
        X['Educational_level'] > 5,
        X['DVRT'] > 50
    ]
    
    if nodes[0]:
        prediction = 1
    else:
        if nodes[1]:
            prediction = 1
        else:
            prediction = 0
    
    # Convert boolean values to integers for the nodes list as per example
    nodes_int = [int(node) for node in nodes]
    
    return prediction, nodes_int
```

### Explanation
1. **Node Evaluation**: The function first evaluates two conditions based on the given features:
   - `nodes[0]` checks if the Educational Level is greater than 5.
   - `nodes[1]` checks if the DVRT Score is greater than 50.
   
2. **Prediction Logic**:
   - If `nodes[0]` (Educational Level > 5) is true, the prediction is set to 1, indicating the person's educational level is beyond the threshold.
   - If `nodes[0]` is false, we check `nodes[1]`. If true, the prediction is still 1; otherwise, it is set to 0.

3. **Conversion to Integers**: The boolean results of the node evaluations are converted to integers (1 for True, 0 for False) to match the expected output format.

This approach ensures that we efficiently use a shallow decision tree to make accurate predictions based on the given features while adhering to the constraint of maximum depth 2.
