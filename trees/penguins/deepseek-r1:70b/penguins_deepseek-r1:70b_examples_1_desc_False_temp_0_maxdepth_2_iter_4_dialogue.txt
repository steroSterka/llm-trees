### Decision Tree:
```
|--- flipper length (mm) <= 205
||--- culmen depth (mm) <= 18.5
||||--- class: Chinstrap
||--- culmen depth (mm) > 18.5
||||--- class: Adelie
|--- flipper length (mm) > 205
||--- island == Torgersen
||||--- class: Gentoo
||--- island != Torgersen
||||--- class: Gentoo
```

1. **First Split (flipper length):**
   - Flipper length is a critical feature for distinguishing between Gentoo penguins and the other species. Gentoo penguins generally have longer flippers than Adelie and Chinstrap penguins.

2. **Second Split (culmen depth):**

   - If culmen depth is greater than 18.5 mm, it is classified as an Adelie penguin; otherwise, it is classified as a Chinstrap penguin.

3. **Gentoo Penguins:**
   - For penguins with flipper lengths greater than 205 mm, we check the island feature to confirm if the species is Gentoo. Regardless of the island, this split leads to the classification of Gentoo penguins.

This decision tree uses the most important features (flipper length and culmen depth) to classify penguin species effectively within a maximum depth of 2.

def predict(X):
    # Initialize the list to store the truth values of inner node conditions
    nodes = [None, None]
    
    # First condition based on flipper length
    flipper_length_condition = X['flipper_length_mm'] <= 205
    nodes[0] = flipper_length_condition
    
    if flipper_length_condition:
        # Second condition for Adelie vs Chinstrap species
        culmen_depth_condition = X['culmen_depth_mm'] <= 18.5
        nodes[1] = culmen_depth_condition
        
        if culmen_depth_condition:
            prediction = 1  # Chinstrap
        else:
            prediction = 0  # Adelie
    else:
        # Second condition for Gentoo species based on island
        island_condition = (X['island'] == 2)  # Torgersen is encoded as 2
        nodes[1] = island_condition
        
        prediction = 2  # Gentoo
    
    return prediction, nodes
