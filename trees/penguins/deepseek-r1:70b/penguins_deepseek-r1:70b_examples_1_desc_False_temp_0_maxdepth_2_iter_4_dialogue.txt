To implement the decision tree classifier for penguin species prediction based on the given features, we'll construct a Python function. This function will evaluate the conditions at each node and return both the predicted species and a list indicating whether each condition was met.

### Approach
The decision tree is structured as follows:
1. **First Node (Root):** Check if the penguin's island is either Biscoe or Dream. If true, classify as Chinstrap.
2. **Second Node:** If the island is Torgersen, check the body mass. If body mass is less than or equal to 4500 grams, classify as Adelie; otherwise, classify as Gentoo.

The function will:
- Evaluate both nodes regardless of the path taken for prediction.
- Convert boolean results of node evaluations into integers (1 for true, 0 for false).
- Return the predicted species and a list representing the evaluation results of each inner node.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    """
    Predicts the penguin species based on features using a decision tree classifier.
    
    Args:
        X (dict): Dictionary containing the features of the penguin.
        
    Returns:
        tuple[int, list[int]]: A tuple where the first element is the predicted species
        (0 for Adelie, 1 for Chinstrap, 2 for Gentoo) and the second element is a list of integers
        representing whether each inner node condition was met (1 if true, 0 otherwise).
    """
    
    # Extract features from the input dictionary
    island = X['island']
    body_mass_g = X.get('body_mass_g', 0)
    
    # Compute conditions for each inner node
    node0 = island <= 1  # Island is either Biscoe (0) or Dream (1)
    node1 = body_mass_g <= 4500  # Body mass is less than or equal to 4500 grams
    
    nodes = [int(node0), int(node1)]  # Convert booleans to integers
    
    if node0:
        prediction = 1  # Chinstrap
    else:
        if node1:
            prediction = 0  # Adelie
        else:
            prediction = 2  # Gentoo
    
    return prediction, nodes
```

### Explanation
- **Feature Extraction:** The function begins by extracting the relevant features (`island` and `body_mass_g`) from the input dictionary.
- **Node Evaluation:** It evaluates each node condition. The first node checks if the island is Biscoe or Dream (encoded as 0 or 1). If true, the prediction is Chinstrap. The second node is only evaluated if the first condition is false and checks if the body mass is within a specified threshold.
- **Result Compilation:** The results of each node evaluation are compiled into a list of integers, where `1` indicates the condition was met, and `0` indicates it wasn't.
- **Prediction:** Based on the node evaluations, the function returns the predicted species and the list of node evaluations.

This approach ensures that all conditions are evaluated, providing clear insight into how each feature contributes to the classification decision.
