### Penguin Species Prediction Function

#### Approach
The function `predict` takes a dictionary of features as input and returns both the predicted species (as an integer) and a list indicating whether each condition in the decision tree was met (1 for true, 0 for false). The decision tree is structured based on the provided features: island, culmen length, culmen depth, flipper length, body mass, and sex. Each condition corresponds to an inner node in the tree.

#### Solution Code

```python
def predict(X):
    # Initialize nodes list with None values; size based on number of conditions
    num_inner_nodes = 5  # Update this based on actual number of inner nodes
    nodes = [None] * num_inner_nodes
    
    # Evaluate each condition and update nodes
    if X['island'] == 'Biscoe':
        nodes[0] = True
    else:
        nodes[0] = False

    if X['culmen_length_mm'] <= 44.5:
        nodes[1] = True
    else:
        nodes[1] = False

    if X['flipper_length_mm'] <= 203.0:
        nodes[2] = True
    else:
        nodes[2] = False

    if X['culmen_depth_mm'] <= 18.9:
        nodes[3] = True
    else:
        nodes[3] = False

    if X['body_mass_g'] > 4150.0:
        nodes[4] = True
    else:
        nodes[4] = False

    # Convert boolean values to integers (1 for True, 0 for False)
    nodes = [1 if node else 0 for node in nodes]

    # Determine prediction based on conditions
    if not nodes[0]:  # If island is not Biscoe
        if nodes[4]:  # body_mass_g > 4150.0
            prediction = 2  # Gentoo
        else:
            prediction = 1  # Chinstrap
    else:  # Island is Biscoe
        if nodes[1]:  # culmen_length_mm <= 44.5
            prediction = 0  # Adelie
        else:
            if nodes[2]:  # flipper_length_mm <= 203.0
                prediction = 2  # Gentoo
            else:
                prediction = 1  # Chinstrap

    return prediction, nodes
```

#### Explanation
1. **Initialization**: The function initializes a list `nodes` to keep track of whether each condition in the decision tree is met.

2. **Condition Evaluation**: Each feature condition from the decision tree is evaluated sequentially and the result (True/False) is stored in the corresponding position in the `nodes` list.

3. **Conversion to Integers**: The boolean values in `nodes` are converted to integers, where True becomes 1 and False becomes 0.

4. **Prediction Logic**: Based on the evaluated conditions, the function navigates through the decision tree to determine the species prediction (Adelie: 0, Chinstrap: 1, Gentoo: 2).

5. **Return Values**: The function returns both the predicted species as an integer and the list of integers representing the truth values of each inner node condition.

This structured approach ensures that the decision tree logic is accurately translated into a functional Python implementation, providing clear and traceable predictions based on input features.
