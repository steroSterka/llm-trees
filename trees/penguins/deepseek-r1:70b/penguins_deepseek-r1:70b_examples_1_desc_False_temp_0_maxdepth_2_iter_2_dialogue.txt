Here is a Python function that implements the decision tree for classifying penguin species based on their physical characteristics. The function takes a dictionary of features as input and returns both the predicted species and a list indicating whether each inner node's condition was satisfied.

```python
def predict(X: dict):
    nodes = [None, None]  # Initialize two inner nodes
    
    flipper_length_mm = X['flipper_length_mm']
    culmen_depth_mm = X['culmen_depth_mm']
    
    # Evaluate the conditions for each inner node
    nodes[0] = (flipper_length_mm > 195)
    nodes[1] = (culmen_depth_mm > 17)
    
    if nodes[0]:
        prediction = 2  # Gentoo
    else:
        if nodes[1]:
            prediction = 0  # Adelie
        else:
            prediction = 1  # Chinstrap
    
    # Convert boolean values to integers for the nodes list
    nodes_int = [int(nodes[0]), int(nodes[1])]
    
    return prediction, nodes_int

# Example usage:
sample_input = {
    'flipper_length_mm': 200,
    'culmen_depth_mm': 20
}
predicted_species, node_evaluations = predict(sample_input)
print(f"Predicted Species: {predicted_species}")
print(f"Node Evaluations: {node_evaluations}")
```

**Explanation:**

1. **Function Definition:** The function `predict` accepts a dictionary `X` containing the penguin's features.

2. **Inner Nodes Initialization:** Two inner nodes are initialized to track the evaluation of conditions at each level of the decision tree.

3. **Feature Extraction:** The relevant features, `flipper_length_mm` and `culmen_depth_mm`, are extracted from the input dictionary.

4. **Condition Evaluation:**
   - The first condition (`nodes[0]`) checks if the flipper length is greater than 195 mm.
   - The second condition (`nodes[1]`) checks if the culmen depth is greater than 17 mm.

5. **Prediction Logic:**
   - If `flipper_length_mm` exceeds 195 mm, the penguin is classified as Gentoo (2).
   - Otherwise, it checks the culmen depth to determine between Adelie (0) and Chinstrap (1).

6. **Conversion to Integers:** The boolean results of the node evaluations are converted to integers for consistency.

7. **Return Values:** The function returns both the predicted species and a list indicating the evaluation of each inner node condition.

This implementation ensures that all conditions are evaluated, and the appropriate classification is made based on the defined decision tree structure.
