```python
def predict_penguin_species(X: dict):
    nodes = [None, None]
    
    # First split: Check if body mass is less than or equal to 4000 grams
    nodes[0] = X["body_mass_g"] <= 4000
    
    if nodes[0]:
        # Second split for smaller penguins (Adelie and Chinstrap): Check culmen length
        nodes[1] = X["culmen_length_mm"] > 42
        
        if nodes[1]:
            prediction = 1  # Chinstrap
        else:
            prediction = 0  # Adelie
    else:
        prediction = 2  # Gentoo
    
    # Convert boolean values in nodes to integers (1 for True, 0 for False)
    nodes = [int(node) if node is not None else 0 for node in nodes]
    
    return prediction, nodes

# Example usage:
example_features = {
    "island": 0,
    "culmen_length_mm": 43,
    "culmen_depth_mm": 15,
    "flipper_length_mm": 190,
    "body_mass_g": 3500,
    "sex": 2
}

predicted_species, node_conditions = predict_penguin_species(example_features)
print(f"Predicted Species: {predicted_species}")
print(f"Node Conditions: {node_conditions}")
```

### Explanation:
- **Decision Tree Logic**:
  - The first split is based on the penguin's body mass. If `body_mass_g` is less than or equal to 4000 grams, it proceeds to evaluate the second feature.
  - For smaller penguins (Adelie and Chinstrap), the function checks the culmen length. A culmen length greater than 42 mm classifies the penguin as Chinstrap; otherwise, it is classified as Adelie.
  - Penguins with a body mass exceeding 4000 grams are classified as Gentoo.

- **Function Output**:
  - The function returns an integer representing the predicted species (0 for Adelie, 1 for Chinstrap, 2 for Gentoo) and a list of integers indicating whether each condition in the inner nodes was met (1 if true, 0 otherwise).
