To create a Python function that predicts the species of penguins based on given features using a decision tree and returns both the predicted species and a list of truth values representing the conditions met in each inner node:

```python
def predict_penguin_species(X: dict) -> tuple[int, list[int]]:
    """
    Predicts the species of a penguin based on its body mass and flipper length.
    
    Args:
        X (dict): A dictionary containing the features of the penguin.
            Features include 'body_mass_g' and 'flipper_length_mm'.
    
    Returns:
        tuple[int, list[int]]: A tuple where the first element is the predicted species
            (0 for Adelie, 1 for Chinstrap, 2 for Gentoo) and the second element is a list of integers
            representing whether each inner node condition was met (1 if true, 0 otherwise).
    """

    # Extract relevant features from the input dictionary
    body_mass = X['body_mass_g']
    flipper_length = X['flipper_length_mm']

    # Compute conditions for inner nodes
    node_0 = body_mass <= 5000  # Condition for Body Mass (g)
    node_1 = flipper_length > 200  # Condition for Flipper Length (mm)

    # Convert boolean values to integers (1 if condition met, 0 otherwise)
    nodes = [int(node_0), int(node_1)]

    # Determine the prediction based on the decision tree
    if node_0:
        prediction = 1  # Chinstrap species
    else:
        if node_1:
            prediction = 2  # Gentoo species
        else:
            prediction = 0  # Adelie species

    return prediction, nodes
```

### Explanation:

1. **Extract Features**: The function extracts the relevant features, `body_mass_g` and `flipper_length_mm`, from the input dictionary.

2. **Compute Conditions**: It computes two conditions based on these features:
   - `node_0`: Checks if the body mass is less than or equal to 5000 grams.
   - `node_1`: Checks if the flipper length is greater than 200 mm.

3. **Convert Conditions to Integers**: The boolean results of these conditions are converted into integers (1 for True, 0 for False) and stored in a list called `nodes`.

4. **Determine Prediction**: Using the decision tree logic:
   - If `node_0` is True, the species is classified as Chinstrap.
   - If `node_0` is False but `node_1` is True, the species is Gentoo.
   - If both conditions are False, the species is Adelie.

5. **Return Result**: The function returns a tuple with the predicted species (as an integer) and the list of condition results as integers.

This approach ensures that the prediction is made efficiently using the decision tree rules, and the conditions evaluated in each inner node are clearly represented for further analysis or debugging purposes.
