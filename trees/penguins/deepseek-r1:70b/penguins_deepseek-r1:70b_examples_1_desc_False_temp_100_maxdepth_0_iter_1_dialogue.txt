Here is a Python function that implements the decision tree for predicting penguin species based on the given features:

```python
def predict(X):
    nodes = [None, None]  # Initialize with two nodes for our conditions
    
    # First condition: body mass <= 4500 grams
    nodes[0] = X['body_mass_g'] <= 4500
    
    # Second condition: flipper length <= 190 mm
    nodes[1] = X['flipper_length_mm'] <= 190
    
    if nodes[0]:
        if nodes[1]:
            prediction = 0  # Adelie
        else:
            prediction = 1  # Chinstrap
    else:
        prediction = 2     # Gentoo
    
    return prediction, nodes
```

### Explanation:

- **nodes**: This list keeps track of the boolean results of each condition in the decision tree. In our case, we have two conditions corresponding to body mass and flipper length.
  
- **Conditions**:
  - `nodes[0]` checks if the penguin's body mass is less than or equal to 4500 grams.
  - `nodes[1]` checks if the flipper length is less than or equal to 190 mm.

- **Prediction Logic**:
  - If both conditions are true, the species is classified as Adelie (0).
  - If the first condition is true but the second is false, it's classified as Chinstrap (1).
  - If the first condition is false, indicating a larger body mass, the species is Gentoo (2).

This function efficiently uses the two most significant features to predict the penguin species and returns both the prediction and the evaluation of each inner node.
