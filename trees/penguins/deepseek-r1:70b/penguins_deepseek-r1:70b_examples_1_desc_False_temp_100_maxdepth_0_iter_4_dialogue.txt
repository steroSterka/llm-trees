To create a function that predicts penguin species based on given features using a decision tree and returns both the prediction and a list of truth values for inner nodes:

1. **Evaluate Conditions**: First, evaluate the conditions for each feature threshold in the decision tree.
2. **Store Truth Values**: Store these conditions as boolean values (True/False) in a list where each position corresponds to an inner node condition.
3. **Decision Logic**: Use nested if-else statements based on the stored conditions to determine the species prediction.

Here is the Python function implementing this logic:

```python
def predict(X: dict):
    nodes = [None] * 2
    # Evaluate the conditions for each inner node
    flipper_condition = X['flipper_length_mm'] <= 190
    body_mass_condition = X['body_mass_g'] > 3700
    
    nodes[0] = flipper_condition
    nodes[1] = body_mass_condition

    if nodes[0]:
        # Flipper length is <= 190 mm, check body mass
        if nodes[1]:
            prediction = 1  # Chinstrap
        else:
            prediction = 0  # Adelie
    else:
        prediction = 2      # Gentoo

    return prediction, [int(node) for node in nodes]
```

**Explanation:**

- **Conditions Evaluation**: The function first evaluates whether the flipper length is less than or equal to 190 mm and whether the body mass exceeds 3700 grams. These conditions are stored as boolean values.
  
- **Node Truth Values**: The `nodes` list captures these boolean values, converting them to integers (1 for True, 0 for False) before returning.

- **Prediction Logic**: Using nested if statements based on the evaluated conditions, the function determines the species. If flipper length is within the threshold, it further checks body mass to distinguish between Adelie and Chinstrap. If not, it classifies as Gentoo.

This approach ensures that all inner node conditions are evaluated and stored, providing a clear path from feature inputs to the final prediction.
