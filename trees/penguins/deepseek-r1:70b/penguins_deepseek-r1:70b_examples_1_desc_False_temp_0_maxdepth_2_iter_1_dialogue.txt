```python
def predict(X: dict):
    # Initialize nodes with None
    nodes = [None, None]
    
    # Evaluate conditions for each inner node
    island_biscoe = (X['island'] == 0)
    flipper_length_condition = (X['flipper_length_mm'] <= 205)
    
    nodes[0] = island_biscoe
    nodes[1] = flipper_length_condition
    
    # Determine the prediction based on conditions
    if nodes[0]:
        prediction = 0  # Adelie
    else:
        if nodes[1]:
            prediction = 1  # Chinstrap
        else:
            prediction = 2  # Gentoo
    
    # Convert boolean values to integers for the nodes list
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
```

This function first evaluates the conditions for each inner node of the decision tree. It checks if the penguin is from Biscoe Island and whether its flipper length is less than or equal to 205 mm. Based on these evaluations, it classifies the species and returns both the predicted class and a list of truth values representing the evaluated conditions as integers (1 for True, 0 for False).
