To solve this problem, we need to create a function that predicts the species of a penguin based on two features: the island it inhabits and its sex. The function should return both the predicted species and the results of the internal decision-making nodes used in the prediction process.

### Approach
The approach involves using a decision tree with a maximum depth of 2. The first node checks if the penguin is from Biscoe Island (encoded as 0). If true, it predicts the species as Adelie (0). If false, it proceeds to check the second node, which determines if the sex is male (encoded as 2). Based on this, it predicts either Chinstrap (1) or Gentoo (2).

The function computes both node conditions upfront and stores them in a list. This ensures that all internal decision-making steps are recorded, even if some conditions are not used due to branching.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[bool | None]]:
    nodes = [None, None]
    
    # Compute the first inner node condition: island == 0 (Biscoe)
    nodes[0] = X["island"] == 0
    
    # Compute the second inner node condition: sex == 2 (male), even if not used
    nodes[1] = X["sex"] == 2
    
    # Determine prediction based on the evaluated conditions
    if nodes[0]:
        prediction = 0  # Adelie
    else:
        if nodes[1]:
            prediction = 1  # Chinstrap
        else:
            prediction = 2  # Gentoo
    
    return prediction, nodes
```

### Explanation
The function `predict` takes a dictionary `X` containing the features of the penguin. It initializes a list `nodes` to store the results of the internal decision-making steps.

1. **First Node Check**: The function checks if the penguin is from Biscoe Island by comparing `X["island"]` to 0. This result is stored in `nodes[0]`.
2. **Second Node Check**: Regardless of the first node's outcome, the function then checks if the sex is male by comparing `X["sex"]` to 2. This result is stored in `nodes[1]`.

Based on these evaluations:
- If the first condition (Biscoe Island) is true, the species is predicted as Adelie (0).
- If false, the function checks the second condition (male sex). If true, it predicts Chinstrap (1); otherwise, it predicts Gentoo (2).

The function returns both the predicted species and the list of node evaluations, providing transparency into the decision-making process.
