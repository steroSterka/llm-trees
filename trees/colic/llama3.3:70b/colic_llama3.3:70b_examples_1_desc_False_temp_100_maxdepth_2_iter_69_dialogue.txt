```python
def predict_horse_colic_surgery(X: dict):
    """
    Predicts whether a horse colic lesion requires surgery based on abdominal distension and nasogastric reflux.
    
    Parameters:
    X (dict): A dictionary containing the features of the horse colic case.
    
    Returns:
    prediction (int): 0 if no surgery is required, 1 if surgery is required.
    nodes (list): A list of boolean values representing the conditions at each node in the decision tree.
    """
    
    # Initialize the nodes
    nodes = 2 * [None]
    
    # Node 1: Check if abdominal distension is severe or moderate
    nodes[0] = X["abdominal_distension"] in [1, 3]  # 1 = moderate, 3 = severe
    
    # Node 2: Check if nasogastric reflux is more than 1 liter ( encoded as 0 )
    nodes[1] = X["nasogastric_reflux"] == 0
    
    # Make the prediction
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Surgery required if both conditions are met
        else:
            prediction = 1  # Surgery likely still required due to severe or moderate abdominal distension
    else:
        prediction = 0  # No surgery required if abdominal distension is not severe or moderate
    
    return prediction, [int(node) for node in nodes]
```

This function takes a dictionary `X` containing the features of the horse colic case as input and returns a tuple. The first element of the tuple is the prediction (0 for no surgery, 1 for surgery), and the second element is a list representing the conditions at each node in the decision tree, where `True` becomes 1 and `False` becomes 0.
