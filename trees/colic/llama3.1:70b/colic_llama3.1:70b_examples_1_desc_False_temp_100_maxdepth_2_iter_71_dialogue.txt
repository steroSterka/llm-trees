Here's a code snippet in Python using scikit-learn library to build the decision tree:
```python
import pandas as pd
from sklearn.tree import DecisionTreeClassifier

# Load data into a Pandas dataframe
df = pd.read_csv('data.csv')

# Select top 5 features and target variable (surgery)
features = ['Nasogastric Reflux', 'Abdominal Distension', 'Degree of Pain', 
            'Rectal Examination Findings', 'Packed Cell Volume']
target = 'surgery'

X = df[features]
y = df[target]

# Train the decision tree classifier
clf = DecisionTreeClassifier(max_depth=2)
clf.fit(X, y)

print("Decision Tree:")
print(clf.tree_)
```

Here is the Python function that implements the decision tree classifier with a maximum depth of 2:

```python
def predict(X: dict):
    """
    Predicts whether a horse colic lesion is surgical or not.

    Args:
    X (dict): A dictionary containing the features.
        - 'nasogastric_reflux': Nasogastric Reflux (0 = more than 1 liter, 1 = less than 1 liter)
        - 'abdominal_distension': Abdominal Distension (1 = moderate, 2 = none, 3 = severe, 4 = slight)
        - 'pain': Degree of Pain (1 = alert, 2 = continuous severe pain, 3 = depressed, 4 = intermittent mild pain, 5 = intermittent severe pain)

    Returns:
    tuple: A tuple containing the prediction and a list representing the truth values of the inner nodes.
        - prediction (int): 0 if no surgery is needed, 1 if surgery is needed
        - nodes (list): A list of boolean values representing the truth values of the inner nodes
    """
    nodes = 2 * [None]
    
    # Node 0: Nasogastric Reflux > 1 liter
    nodes[0] = X['nasogastric_reflux'] == 0
    
    # Node 1: Abdominal Distension > slight
    nodes[1] = X['abdominal_distension'] in [3, 4]
    
    if nodes[0]:
        prediction = 1  # surgery needed if Nasogastric Reflux > 1 liter
    elif nodes[1]:
        prediction = 1  # surgery needed if Abdominal Distension > slight and Nasogastric Reflux <= 1 liter
    else:
        # Additional check for pain
        if X['pain'] in [2, 5]:  
            prediction = 1  # surgery needed if severe pain
        else:
            prediction = 0  # no surgery needed
    
    return prediction, nodes
```

You can call this function by passing a dictionary containing the features as an argument. The function will return a tuple containing the prediction and a list representing the truth values of the inner nodes.
