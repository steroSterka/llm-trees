Here's a Python function that implements the decision tree logic to predict whether a horse with colic requires surgical intervention based on the Degree of Pain and Pulse Rate features. The function returns a prediction (0 for no surgery, 1 for surgery) along with a list indicating the evaluation of each condition in the decision tree.

```python
def predict(X):
    nodes = [0] * 2
    
    # Evaluate the first condition: Is the Degree of Pain severe?
    nodes[0] = 1 if X['pain'] in [2, 5] else 0
    
    # Evaluate the second condition: Is the Pulse Rate greater than 45 beats per minute?
    nodes[1] = 1 if X['pulse'] > 45 else 0
    
    # Determine the prediction based on the decision tree logic
    if nodes[0]:
        prediction = 1
    else:
        prediction = 1 if nodes[1] else 0
        
    return prediction, nodes
```

### Explanation:

1. **nodes List Initialization**: The list `nodes` is initialized to keep track of whether each condition in the decision tree is met (1 for true, 0 for false).

2. **First Condition Evaluation**: The first condition checks if the Degree of Pain is severe. This is determined by checking if `X['pain']` is either 2 (continuous severe pain) or 5 (intermittent severe pain). If so, `nodes[0]` is set to 1; otherwise, it remains 0.

3. **Second Condition Evaluation**: The second condition checks if the Pulse Rate exceeds 45 beats per minute. If `X['pulse']` is greater than 45, then `nodes[1]` is set to 1; otherwise, it stays at 0.

4. **Prediction Logic**: 
   - If the first condition (severe pain) is met (`nodes[0]` is 1), the prediction is set to 1 (surgery needed).
   - If the first condition is not met, the prediction depends on the second condition: if `nodes[1]` is 1, then surgery is needed (prediction = 1); otherwise, no surgery is needed (prediction = 0).

This function accurately reflects the decision tree's structure and ensures that both conditions are evaluated to provide a comprehensive result.
