4. **Store Truth Values**: Collect the truth values of all conditions into a list, converting boolean values to integers (1 for True, 0 for False).

Here's the Python function:

```python
def predict(X):
    # Compute each node condition upfront
    pain_severe = X['pain'] in [2, 5]
    naso_significant = X['nasogastric_reflux'] != 3
    temp_high = X['rectal_temperature'] > 38.5
    abd_severe = X['abdominal_distension'] == 3

    # Create nodes list with truth values as integers
    nodes = [
        int(pain_severe),
        int(naso_significant),
        int(temp_high),
        int(abd_severe)
    ]

    # Determine prediction based on the decision tree logic
    if pain_severe:
        prediction = 1
    elif naso_significant:
        prediction = 1
    elif temp_high:
        prediction = 1
    elif abd_severe:
        prediction = 1
    else:
        prediction = 0

    return prediction, nodes
```

**Explanation:**

- **Conditions**: Each condition checks specific features to determine if they meet the criteria for classifying as surgical.
- **Nodes List**: The truth values of each condition are stored in a list and converted to integers for clarity.
- **Prediction Logic**: The function evaluates conditions sequentially, stopping when it finds the first true condition that leads to a surgical classification. If none are met, it defaults to non-surgical.

This approach ensures that all inner node conditions are evaluated and their truth values recorded, providing transparency into which conditions influenced the final prediction.
