Here is the Python function implementing the decision tree logic:

```python
def predict(X: dict):
    # Evaluate conditions for each inner node
    nodes = [
        int(X["rectal_temperature"] <= 101.5),  # Node 0 condition
        int(X["abdominal_distension"] == 3)       # Node 1 condition
    ]
    
    if nodes[0]:  # Rectal Temperature <= 101.5
        prediction = 0  # No surgery
    else:
        if nodes[1]:  # Abdominal Distension is severe (value 3)
            prediction = 1  # Surgery
        else:
            prediction = 0  # No surgery
    
    return prediction, nodes
```

**Explanation:**

- **Function Definition:** The function `predict` takes a dictionary `X` containing the feature values for a horse.
  
- **Inner Nodes Evaluation:**
  - `nodes[0]`: Checks if the rectal temperature is less than or equal to 101.5°C, converting the boolean result to an integer (1 for True, 0 for False).
  - `nodes[1]`: Checks if the abdominal distension level is severe (encoded as value 3), similarly converted to an integer.

- **Prediction Logic:**
  - If `nodes[0]` is True (rectal temperature ≤ 101.5°C), the prediction is set to 0, indicating no surgery.
  - If `nodes[0]` is False (rectal temperature > 101.5°C), then `nodes[1]` is evaluated:
    - If `nodes[1]` is True (abdominal distension is severe), prediction is 1 (surgery).
    - Otherwise, prediction remains 0.

- **Return Values:** The function returns the predicted outcome and a list of integers representing the evaluation of each inner node's condition.

**Example Usage:**
