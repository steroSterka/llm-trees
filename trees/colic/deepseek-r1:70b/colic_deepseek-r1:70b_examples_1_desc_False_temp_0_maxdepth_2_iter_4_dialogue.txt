Here's the Python function that predicts whether a horse colic lesion requires surgery based on the given features using a decision tree of maximum depth 2:

```python
def predict(X: dict):
    nodes = [None, None]
    # First node: Rectal Temperature check
    nodes[0] = X["rectal_temperature"] <= 38.0
    
    # Second node: Degree of Pain check for severe pain (encoded as 5)
    nodes[1] = X["pain"] == 5

    prediction = 0  # Default to no surgery

    if not nodes[0]:  # If rectal temperature is above 38.0
        if nodes[1]:  # And degree of pain is severe
            prediction = 1  # Predict surgery

    return prediction, nodes
```

**Explanation:**

- **Decision Tree Logic:**
  - The first node checks if the horse's rectal temperature is less than or equal to 38.0°C.
  - If true, it predicts no surgery (0).
  - If false (temperature above 38.0°C), it proceeds to check the second node.
  - The second node evaluates whether the degree of pain is severe (encoded as 5).
    - If true, it predicts surgery (1).
    - If false, it predicts no surgery (0).

- **Nodes List:**
  - `nodes[0]` is `True` if rectal temperature ≤ 38.0°C.
  - `nodes[1]` is `True` if the degree of pain is severe.

This function efficiently uses two critical features to make a prediction, adhering to the specified maximum depth and providing clear conditions for each decision.
