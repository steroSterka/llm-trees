**Decision Tree – Surgical vs Non‑Surgical Colic Lesion**  
*(the tree is built from the most predictive clinical variables that are routinely recorded for equine colic cases)*  

```
|--- Degree of Pain = severe
||--- class: surgical
|--- Degree of Pain = moderate
||--- Abdominal Distension = severe OR moderate
|||--- class: surgical
||--- Abdominal Distension = slight OR none
|||--- Peristalsis = absent OR hypomotile
||||--- class: surgical
|||--- Peristalsis = normal OR hypermotile
||||--- Nasogastric Reflux = > 1 L
|||||||--- class: surgical
||||--- Nasogastric Reflux = < 1 L OR none
|||||||--- Rectal Temperature (°C) > 38.5
||||||||--- class: non‑surgical
|||||||--- Rectal Temperature (°C) ≤ 38.5
||||||||--- Packed Cell Volume (%) > 45
|||||||||||--- class: surgical
||||||||--- Packed Cell Volume (%) ≤ 45
|||||||||||--- Total Protein (g/dL) > 6.5
||||||||||||--- class: non‑surgical
|||||||||||--- Total Protein (g/dL) ≤ 6.5
||||||||||||--- class: surgical
|--- Degree of Pain = mild OR none
||--- class: non‑surgical
```

### How to read the tree
* **Each “|---” line** is a decision node.  
* **Conditions** (e.g., `Degree of Pain = severe`) are tested in the order shown.  
* When a leaf node (`class: …`) is reached, the model predicts **“surgical”** (the lesion will require an operation) or **“non‑surgical”** (medical management is expected to be sufficient).

### Rationale for the chosen splits  

| Feature (used in the tree) | Why it is highly predictive for surgery |
|----------------------------|------------------------------------------|
| **Degree of Pain** | Severe or moderate pain is the strongest clinical indicator of a strangulating/ischemic lesion that usually needs surgery. |
| **Abdominal Distension** | Marked distension reflects gas or fluid accumulation from an obstructive process. |
| **Peristalsis** | Absent or hypomotile gut sounds suggest ileus or severe obstruction. |
| **Nasogastric Reflux** | Large volumes (> 1 L) of reflux are classic for a surgical obstruction. |
| **Rectal Temperature** | Mild fever (≤ 38.5 °C) often accompanies inflammatory but non‑strangulating lesions; higher temperatures can indicate systemic infection rather than primary surgical disease. |
| **Packed Cell Volume (PCV)** | Elevated PCV (> 45 %) indicates hemoconcentration from third‑spacing of fluid, common in severe intestinal compromise. |
| **Total Protein** | Low plasma protein (≤ 6.5 g/dL) reflects protein loss into the abdomen (e.g., endotoxemia) and often accompanies non‑surgical colic. |

Other recorded variables (e.g., mucous‑membrane colour, capillary refill time, pulse, respiratory rate, etc.) are valuable for overall case assessment but, in most data‑driven studies, contribute less to the **initial binary decision** of “surgical vs. non‑surgical” than the features shown above. They can be added as deeper branches if a more granular model is required.

**Python implementation of the decision‑tree classifier**

```python
def predict(colic: dict):
    """
    Predict whether a horse with colic needs surgery (target = 1) or not (target = 0).

    Parameters
    ----------
    colic : dict
        Dictionary that contains the 22 clinical variables exactly with the
        names shown in the dataset description, e.g.  colic["pain"],
        colic["abdominal_distension"], colic["rectal_temperature"], ….

    Returns
    -------
    prediction : int
        1 → surgical lesion, 0 → non‑surgical lesion
    nodes : list[int]
        Truth values (1 = True, 0 = False) for each inner node of the tree,
        in the order they appear in the code (8 nodes total).
    """

    # ------------------------------------------------------------------ #
    # 0.  Pain – severe (continuous severe pain  OR intermittent severe)
    #     encoding: 2 = continuous severe, 5 = intermittent severe
    # ------------------------------------------------------------------ #
    node0 = colic["pain"] in (2, 5)

    # ------------------------------------------------------------------ #
    # 1.  Pain – moderate (depressed)
    #     encoding: 3 = depressed
    # ------------------------------------------------------------------ #
    node1 = colic["pain"] == 3

    # ------------------------------------------------------------------ #
    # 2.  Abdominal distension – severe or moderate
    #     encoding: 1 = moderate, 3 = severe
    # ------------------------------------------------------------------ #
    node2 = colic["abdominal_distension"] in (1, 3)

    # ------------------------------------------------------------------ #
    # 3.  Peristalsis – absent or hypomotile
    #     encoding: 1 = absent, 3 = hypomotile
    # ------------------------------------------------------------------ #
    node3 = colic["peristalsis"] in (1, 3)

    # ------------------------------------------------------------------ #
    # 4.  Nasogastric reflux – > 1 L
    #     encoding: 0 = more than 1 L
    # ------------------------------------------------------------------ #
    node4 = colic["nasogastric_reflux"] == 0

    # ------------------------------------------------------------------ #
    # 5.  Rectal temperature > 38.5 °C
    # ------------------------------------------------------------------ #
    node5 = colic["rectal_temperature"] > 38.5

    # ------------------------------------------------------------------ #
    # 6.  Packed cell volume > 45 %
    # ------------------------------------------------------------------ #
    node6 = colic["packed_cell_volume"] > 45

    # ------------------------------------------------------------------ #
    # 7.  Total protein > 6.5 g/dL
    # ------------------------------------------------------------------ #
    node7 = colic["total_protein"] > 6.5

    # store the truth values as 1/0 (as required)
    nodes = [int(v) for v in (node0, node1, node2, node3,
                              node4, node5, node6, node7)]

    # -------------------------- decision logic -------------------------- #
    if node0:                                 # severe pain → surgery
        prediction = 1

    else:
        if node1:                             # moderate pain branch
            if node2:                         # severe/moderate distension
                prediction = 1               # → surgery
            else:                             # slight/none distension
                if node3:                     # absent/hypomotile peristalsis
                    prediction = 1           # → surgery
                else:                         # normal/hypermotile peristalsis
                    if node4:                 # >1 L reflux
                        prediction = 1       # → surgery
                    else:                     # ≤1 L or none reflux
                        if node5:             # temperature >38.5 °C
                            prediction = 0   # non‑surgical
                        else:                 # ≤38.5 °C
                            if node6:         # PCV >45 %
                                prediction = 1   # surgery
                            else:                 # PCV ≤45 %
                                if node7:         # TP >6.5 g/dL
                                    prediction = 0   # non‑surgical
                                else:
                                    prediction = 1   # surgery
        else:                                 # mild / no pain
            prediction = 0                     # non‑surgical

    return prediction, nodes
```

### How the function works
* **`nodes` list** – contains eight integers (1 = True, 0 = False) that correspond to the eight internal decision points of the tree, in the exact order they are evaluated.
* **`prediction`** – the final class:
  * `1` → the colic lesion is **surgical** (needs an operation)  
  * `0` → the lesion is **non‑surgical** (medical management).

The thresholds and categorical mappings used in the code reflect the most informative clinical variables for distinguishing surgical from non‑surgical colic lesions, as described in the earlier tree.
