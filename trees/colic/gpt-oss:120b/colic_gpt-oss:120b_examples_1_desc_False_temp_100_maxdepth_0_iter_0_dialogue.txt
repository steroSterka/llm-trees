**Illustrative Decision‑Tree for Classifying Horse‑Colic Lesions  
(“Surgical” vs “Non‑surgical”)**

```
|    |--- class: surgical

|    |--- class: non‑surgical
```

### How the tree was constructed  

| Rank | Feature (most‑important → less‑important) | Why it matters for “surgical” colic |
|------|-------------------------------------------|--------------------------------------|
| 1 | **Degree of Pain** | Severe or moderate pain is the strongest clinical clue for an obstructive/strangulating lesion that usually needs surgery. |
| 2 | **Abdominal Distension** | Distension (especially moderate‑to‑severe) signals gas or fluid buildup from a blockage. |
| 3 | **Peristalsis** | Absent or markedly reduced gut motility is typical of an incarcerated intestine. |
| 4 | **Nasogastric Reflux** | Large‑volume reflux (>1 L) indicates an obstruction proximal to the stomach. |
| 5 | **Packed Cell Volume (PCV)** | Elevated PCV (>45 %) reflects hemoconcentration from third‑spacing fluid loss, common in severe colic. |
| 6 | **Temperature of Extremities** | Cool or cold extremities suggest peripheral vasoconstriction from shock. |
| 7 | **Rectal Temperature** | Fever (>38.5 °C) often accompanies inflammatory or infectious processes that may require surgery. |
| 8 | **Other variables** (Pulse, Respiratory Rate, Mucous‑membrane colour, Capillary refill, etc.) are still useful but were not needed to reach a decision in this simplified tree.

**Python implementation**

```python
def predict(X: dict):
    """
    Predict whether a horse‑colic lesion requires surgery (target = 1)
    or not (target = 0).

    Parameters
    ----------
    X : dict
        A dictionary that contains **exactly** the keys shown in the
        specification (e.g. "pain", "abdominal_distension", …).

    Returns
    -------
    prediction : int
        1 → surgical lesion, 0 → non‑surgical lesion
    nodes : list[bool]
        Truth values of the inner decision‑nodes, in the order they are
        evaluated (see the table below).

    Node order
    ----------
    0 – pain_severe               : pain in {2, 5}
    1 – pain_moderate             : pain == 3
    2 – abd_dist_mod_or_severe    : abdominal_distension in {1, 3}
    3 – peristalsis_abs_hypo      : peristalsis in {1, 3}
    4 – nasogastric_reflux_big    : nasogastric_reflux == 0   ( > 1 L )
    5 – packed_cell_volume_high   : packed_cell_volume > 45
    6 – temp_extremities_cold_warm: temp_extremities in {1, 2}
    7 – rectal_temperature_high   : rectal_temperature > 38.5
    """

    # ------------------------------------------------------------------
    # 1️⃣  evaluate every inner node (independent of the path taken)
    # ------------------------------------------------------------------
    nodes = [None] * 8

    # 0 – severe pain ?
    nodes[0] = X["pain"] in (2, 5)                     # 2 = continuous severe,
                                                     # 5 = intermittent severe

    # 1 – moderate pain ?  (we treat “depressed” as moderate)
    nodes[1] = X["pain"] == 3

    # 2 – abdominal distension moderate or severe ?
    nodes[2] = X["abdominal_distension"] in (1, 3)    # 1 = moderate, 3 = severe

    # 3 – peristalsis absent or hypomotile ?
    nodes[3] = X["peristalsis"] in (1, 3)             # 1 = absent, 3 = hypomotile

    # 4 – nasogastric reflux > 1 L ?
    nodes[4] = X["nasogastric_reflux"] == 0          # 0 = > 1 L

    # 5 – packed cell volume > 45 % ?
    nodes[5] = X["packed_cell_volume"] > 45

    # 6 – extremities cold or cool ?
    nodes[6] = X["temp_extremities"] in (1, 2)       # 1 = cold, 2 = cool

    # 7 – rectal temperature > 38.5 °C ?
    nodes[7] = X["rectal_temperature"] > 38.5

    # ------------------------------------------------------------------
    # 2️⃣  walk through the tree to obtain the final prediction
    # ------------------------------------------------------------------
    # root – severe pain → surgery
    if nodes[0]:
        prediction = 1
    # moderate pain branch
    elif nodes[1]:
        # abdominal distension moderate / severe → surgery
        if nodes[2]:
            prediction = 1
        else:
            # peristalsis absent / hypomotile → surgery
            if nodes[3]:
                prediction = 1
            else:
                # large nasogastric reflux → surgery
                if nodes[4]:
                    prediction = 1
                else:
                    # high PCV → surgery, otherwise no surgery
                    prediction = 1 if nodes[5] else 0
    # mild pain branch
    elif X["pain"] == 4:          # 4 = intermittent mild pain
        if nodes[6]:
            prediction = 1
        else:
            prediction = 1 if nodes[7] else 0
    # no pain (alert) branch → never surgery
    else:                         # pain == 1 (alert)
        prediction = 0

    return prediction, nodes
```

### How the function works  

| Node index | Condition evaluated (stored in `nodes[i]`) | Meaning in the clinical tree |
|------------|--------------------------------------------|------------------------------|
| 0 | `pain` is 2 or 5 | **Severe pain** → immediate surgical decision |
| 1 | `pain` is 3 | **Moderate pain** (depressed) |
| 2 | `abdominal_distension` is 1 or 3 | Moderate / severe distension |
| 3 | `peristalsis` is 1 or 3 | Absent or hypomotile gut motility |
| 4 | `nasogastric_reflux` == 0 | > 1 L reflux (large volume) |
| 5 | `packed_cell_volume` > 45 | Hemoconcentration suggesting shock |
| 6 | `temp_extremities` is 1 or 2 | Cold / cool extremities (peripheral vasoconstriction) |
| 7 | `rectal_temperature` > 38.5 °C | Fever |

The function first evaluates **all** eight inner‑node conditions (so the caller can see the whole logical picture) and then follows the decision path to return the final binary prediction (`1` = surgical, `0` = non‑surgical).
