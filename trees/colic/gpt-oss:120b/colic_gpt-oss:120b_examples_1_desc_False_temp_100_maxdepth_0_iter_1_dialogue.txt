Below is a **sample decision‑tree** that could be used to predict whether a horse with colic needs **surgical** treatment (lesion = “Surgical”) or can be managed **medically** (lesion = “Non‑surgical”).  
The splits are ordered by the features that, in the classic Horse‑Colic data set, have the highest information‑gain / Gini‑importance (e.g., abdominal distension, peristalsis, nasogastric reflux, pulse, pain level, and mucous‑membrane colour).  

The format follows the example you gave (text‑only, “|---” for each level of the tree).

```
|--- Abdominal Distension = severe
||--- class: Surgical
|--- Abdominal Distension != severe
||--- Peristalsis
|||--- Peristalsis = absent OR hypomotile
||||--- class: Surgical
|||--- Peristalsis = normal OR hypermotile
||||--- Nasogastric Reflux
||||||--- Nasogastric Reflux = > 1 liter
|||||||--- class: Surgical
||||||--- Nasogastric Reflux = ≤ 1 liter
|||||||--- Pulse (beats per minute)
||||||||--- Pulse > 80
||||||||||--- class: Surgical
||||||||--- Pulse ≤ 80
||||||||||--- Degree of Pain
|||||||||||--- Degree of Pain = severe OR moderate
||||||||||||--- class: Surgical
|||||||||||--- Degree of Pain = mild OR none
||||||||||||--- Appearance of Mucous Membranes
||||||||||||--- Mucous Membranes = bright pink OR bright red
|||||||||||||||--- class: Non‑surgical
||||||||||||--- Mucous Membranes = pale pink OR pale cyanotic OR dark cyanotic
|||||||||||||||--- class: Surgical
```

### How to read the tree  

* **Root node** – the first split is on **Abdominal Distension**.  
  * If the horse shows **severe abdominal distension**, the model predicts **Surgical**.  
  * Otherwise (none, slight, or moderate distension) we continue down the left branch.  

* **Second level** – **Peristalsis** (intestinal motility).  
  * **Absent** or **hypomotile** peristalsis strongly suggests a surgical lesion.  
  * **Normal** or **hypermotile** peristalsis leads to further evaluation.  

* **Third level** – **Nasogastric Reflux** (volume of fluid returned).  
  * **> 1 L** of reflux is a classic surgical sign → **Surgical**.  
  * **≤ 1 L** (including “none”) requires additional checks.  

* **Fourth level** – **Pulse** (heart rate).  
  * **> 80 bpm** is a tachycardia that, together with the previous findings, leans toward surgery.  
  * **≤ 80 bpm** proceeds to pain assessment.  

* **Fifth level** – **Degree of Pain**.  
  * **Severe** or **moderate** pain → **Surgical**.  
  * **Mild** or **none** → we look at mucous‑membrane colour.  

* **Sixth level** – **Appearance of Mucous Membranes** (indicator of circulatory status).  
  * **Bright pink** or **bright red** (well‑perfused) → **Non‑surgical** (the horse is likely stable enough for medical management).  
  * **Pale pink**, **pale cyanotic**, or **dark cyanotic** (poor perfusion) → **Surgical**.

---

### Why these features?

| Rank | Feature (most important) | Reason it helps separate surgical vs. non‑surgical lesions |
|------|--------------------------|------------------------------------------------------------|
| 1    | **Abdominal Distension** | Severe distension often means a mechanical blockage that needs surgery. |
| 2    | **Peristalsis**          | Absence or marked reduction indicates obstruction or strangulation. |
| 3    | **Nasogastric Reflux**   | Large-volume reflux (especially > 1 L) is a classic sign of a surgical colic. |
| 4    | **Pulse**                | Tachycardia (> 80 bpm) reflects pain, hypovolemia, or systemic stress. |
| 5    | **Degree of Pain**       | Moderate‑to‑severe pain correlates with more serious lesions. |
| 6    | **Mucous‑membrane colour** | Poor colour (pale/cyanotic) signals circulatory compromise, often accompanying surgical lesions. |

Other variables (temperature, respiratory rate, capillary refill, packed cell volume, etc.) are useful clinically, but in a **pure decision‑tree** built on information‑gain they usually appear lower in the hierarchy or are not needed to achieve a compact, high‑accuracy rule set.

---

### Using the tree

1. **Collect the values** for the listed features for a given horse.  
2. **Follow the branches** from the root down, checking the condition at each node.  
3. **Stop at the first leaf** you reach – the leaf label tells you whether the lesion is predicted to be **Surgical** or **Non‑surgical**.  

---

> **Note:** This tree is an **illustrative example** based on known patterns in the public Horse‑Colic dataset.  
> In practice you would train a CART model on the actual data, prune it (e.g., using cost‑complexity pruning), and validate performance (accuracy, sensitivity, specificity) on a held‑out test set before using it for clinical decision‑making.

**Python implementation of the decision‑tree**

```python
def predict(colic_features: dict):
    """
    Predict whether a horse with colic needs surgery (target = 1) or not (target = 0).

    Parameters
    ----------
    colic_features : dict
        Dictionary that contains the 22 raw feature values using the exact keys
        given in the problem statement, e.g.
        {
            "abdominal_distension": 3,
            "peristalsis": 4,
            "nasogastric_reflux": 1,
            "pulse": 72,
            "pain": 4,
            "mucous_membranes": 1,
            ... (other features are ignored by the tree)
        }

    Returns
    -------
    prediction : int
        1 → surgical lesion, 0 → non‑surgical lesion
    nodes : list[int]
        Truth values (1 = condition satisfied, 0 = not satisfied) for each
        inner node of the tree in the order:
        0 – abdominal_distension = severe
        1 – peristalsis absent or hypomotile
        2 – nasogastric reflux > 1 L
        3 – pulse > 80 bpm
        4 – pain severe / moderate
        5 – mucous membranes bright pink or bright red
    """

    # ------------------------------------------------------------------ #
    # 1️⃣  Inner‑node evaluations (store as 0 / 1)
    # ------------------------------------------------------------------ #
    nodes = [0] * 6

    # 0 – abdominal_distension = severe (encoding 3)
    nodes[0] = 1 if colic_features.get("abdominal_distension") == 3 else 0

    # 1 – peristalsis absent (1) or hypomotile (3)
    nodes[1] = 1 if colic_features.get("peristalsis") in (1, 3) else 0

    # 2 – nasogastric reflux > 1 L (encoding 0)
    nodes[2] = 1 if colic_features.get("nasogastric_reflux") == 0 else 0

    # 3 – pulse > 80 bpm (numeric)
    nodes[3] = 1 if colic_features.get("pulse", 0) > 80 else 0

    # 4 – pain severe / moderate
    #    severe: 2 (continuous severe) or 5 (intermittent severe)
    #    moderate: 3 (depressed) – treated as “moderate” for this tree
    nodes[4] = 1 if colic_features.get("pain") in (2, 3, 5) else 0

    # 5 – mucous membranes bright pink (1) or bright red (2)
    nodes[5] = 1 if colic_features.get("mucous_membranes") in (1, 2) else 0

    # ------------------------------------------------------------------ #
    # 2️⃣  Follow the tree logic to obtain the final prediction
    # ------------------------------------------------------------------ #
    if nodes[0]:                     # severe abdominal distension
        prediction = 1                # surgical
    else:
        if nodes[1]:                 # peristalsis absent / hypomotile
            prediction = 1
        else:
            if nodes[2]:             # > 1 L reflux
                prediction = 1
            else:
                if nodes[3]:         # pulse > 80
                    prediction = 1
                else:
                    if nodes[4]:     # pain severe / moderate
                        prediction = 1
                    else:
                        if nodes[5]: # good mucous‑membrane colour
                            prediction = 0
                        else:
                            prediction = 1

    # Return both the class label and the list of node truth values
    return prediction, nodes
```

### How to use it
```python
sample = {
    "abdominal_distension": 1,   # moderate
    "peristalsis": 4,            # normal
    "nasogastric_reflux": 1,     # < 1 L
    "pulse": 76,
    "pain": 4,                   # intermittent mild pain
    "mucous_membranes": 1,       # bright pink
    # … other features can be present but are ignored by the tree
}

pred, node_vals = predict(sample)
print(pred)        # 0  → non‑surgical
print(node_vals)   # [0, 0, 0, 0, 0, 1]
```

The function follows the exact decision‑tree described earlier, uses the official numeric encodings for each categorical variable, and supplies a binary list (`nodes`) that records whether each inner‑node condition was met (`1`) or not (`0`).
