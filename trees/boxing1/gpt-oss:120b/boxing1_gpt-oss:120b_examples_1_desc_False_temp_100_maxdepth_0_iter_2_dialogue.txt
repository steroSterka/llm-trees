**Python function that implements the decision‑tree**

```python
def predict(X: dict):
    """
    Predict which fighter won a given round.

    Parameters
    ----------
    X : dict
        Dictionary that must contain the three feature keys
        (exact spelling, case‑sensitive):
            * 'Judge'    – integer code of the judge
                           (0 = E. Williams, 1 = L. O'Connell,
                            2 = S. Christodoulu, 3 = HBO‑Lederman,
                            4 = Sportsticker, 5 = Boxing Times,
                            6 = Sportsline, 7 = Associated Press,
                            8 = ESPN, 9 = Boxing Monthly‑Leach)
            * 'Official' – 1 if the judge is an *official* judge, 0 otherwise
            * 'Round'    – integer round number (1 … 12)

    Returns
    -------
    prediction : int
        1 → Lewis won the round
        0 → Holyfield won the round
    nodes : list[int]
        Truth values of the inner‑node tests, in the order they appear
        in the tree (1 = condition satisfied, 0 = not satisfied).

    Tree logic (re‑written as Python conditionals)

    |--- Official == 0            → Lewis
    |--- Official == 1
    ||--- Judge ∈ {0,1,2}
    |||--- Round ≤ 6              → Holyfield
    |||--- Round > 6              → Lewis
    ||--- Judge ∉ {0,1,2}          → Holyfield
    """
    # ------------------------------------------------------------------
    # 1️⃣  Inner‑node evaluations (store as 0 / 1 integers)
    # ------------------------------------------------------------------
    # node 0 : is the judge an official judge?
    nodes = [0] * 3                     # three inner nodes in total
    nodes[0] = 1 if X["Official"] == 1 else 0

    # node 1 : does the judge belong to the “Group A” set?
    #          (E. Williams, L. O'Connell, S. Christodoulu)
    group_a = {0, 1, 2}
    nodes[1] = 1 if X["Judge"] in group_a else 0

    # node 2 : round number (only relevant when we are in Group A)
    nodes[2] = 1 if X["Round"] <= 6 else 0

    # ------------------------------------------------------------------
    # 2️⃣  Decision logic following the tree
    # ------------------------------------------------------------------
    if nodes[0] == 0:                     # Official == 0  → Lewis
        prediction = 1
    else:                                 # Official == 1
        if nodes[1] == 1:                 # Judge in Group A
            if nodes[2] == 1:             # Round ≤ 6
                prediction = 0            # Holyfield
            else:                         # Round > 6
                prediction = 1            # Lewis
        else:                             # Judge in Group B
            prediction = 0                # Holyfield

    return prediction, nodes
```

### How the function works

| Inner node index | Condition evaluated                                 | Stored value (`nodes[i]`) |
|------------------|------------------------------------------------------|---------------------------|
| **0**            | `Official == 1` (judge is official)                  | `1` if true, `0` otherwise |
| **1**            | `Judge` is one of `{0, 1, 2}` (E. Williams, L. O'Connell, S. Christodoulu) | `1` if true, `0` otherwise |
| **2**            | `Round ≤ 6` (only consulted when node 1 is true)    | `1` if true, `0` otherwise |

The returned `prediction` follows exactly the tree described earlier:

* **Official = 0** → Lewis (prediction = 1)  
* **Official = 1** & **Judge in Group A**  
  * Round ≤ 6 → Holyfield (0)  
  * Round > 6 → Lewis (1)  
* **Official = 1** & **Judge in Group B** → Holyfield (0)
