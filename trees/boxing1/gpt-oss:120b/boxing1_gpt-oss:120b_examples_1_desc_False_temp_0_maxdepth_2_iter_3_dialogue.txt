**Python implementation of the depth‑2 decision tree**

```python
def predict(X: dict):
    """
    Predict which fighter won the round.

    Parameters
    ----------
    X : dict
        A dictionary that must contain the three feature keys
        exactly as they appear in the data set:

        - "Judge"    : integer 0‑9 (see encoding below)
        - "Official" : 1 = judge is an official judge, 0 = otherwise
        - "Round"    : integer from 1 to 12

    Returns
    -------
    prediction : int
        1 → Lewis won the round
        0 → Holyfield won the round
    nodes : list[int]
        Truth values of the two inner nodes (1 = condition satisfied,
        0 = condition not satisfied) in the order they appear in the tree.

    Tree structure (max depth = 2)

    |--- Official == 1
    |    |--- Round <= 6        → Holyfield (0)
    |    |--- Round > 6         → Lewis     (1)
    |--- Official == 0
    |    |--- Judge <= 2        → Lewis     (1)   # Judges 0,1,2  → E. Williams, L. O'Connell, S. Christodoulu
    |    |--- Judge > 2         → Holyfield (0)   # All other judges
    """
    # ------------------------------------------------------------------
    # 0️⃣  First inner node : is the judge an official judge?
    # ------------------------------------------------------------------
    node0 = X["Official"] == 1          # True → go to the “official” branch
    # store as 1 / 0
    nodes = [int(node0), None]

    # ------------------------------------------------------------------
    # 1️⃣  Second inner node : depends on the outcome of node0
    # ------------------------------------------------------------------
    if node0:                                   # official judge branch
        node1 = X["Round"] <= 6                 # early rounds favour Holyfield
    else:                                       # non‑official judge branch
        node1 = X["Judge"] <= 2                 # judges 0‑2 tend to favour Lewis

    nodes[1] = int(node1)

    # ------------------------------------------------------------------
    # 2️⃣  Leaf / prediction
    # ------------------------------------------------------------------
    if node0:                       # official judge
        prediction = 0 if node1 else 1
    else:                           # non‑official judge
        prediction = 1 if node1 else 0

    return prediction, nodes
```

### How the function works

| Step | Condition evaluated (`node`) | Meaning in the tree | Truth value stored |
|------|------------------------------|---------------------|--------------------|
| 0️⃣ | `X["Official"] == 1` | “Is the judge an official judge?” (root) | `1` if *yes*, `0` if *no* |
| 1️⃣ | *depends on node 0*:<br>• if node 0 = 1 → `X["Round"] <= 6`<br>• if node 0 = 0 → `X["Judge"] <= 2` | Second‑level split (either round number or judge identity) | `1` if the chosen condition is satisfied, otherwise `0` |
| 2️⃣ | Leaf decision (prediction) | Returns **1** for *Lewis* or **0** for *Holyfield* according to the tree logic. |

The function returns both the predicted winner (`prediction`) and the list `nodes` that records the boolean outcomes of the two inner decision nodes, exactly as requested.
