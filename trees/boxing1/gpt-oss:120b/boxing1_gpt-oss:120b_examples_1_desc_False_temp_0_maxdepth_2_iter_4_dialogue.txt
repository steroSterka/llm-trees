**Python function that implements the depth‑2 decision tree**

```python
def predict_round_winner(X: dict):
    """
    Predict which fighter won a given round.

    Parameters
    ----------
    X : dict
        Dictionary that contains the three input features (exact key spelling):
        - "Judge"    : int  (0‑9, see encoding below)
        - "Official" : int  (1 = Yes, 0 = No)
        - "Round"    : int  (1‑12)   # not used in the depth‑2 tree
        The dictionary may also contain the other keys that appear in the
        original data set (e.g. "Target variable", "target") – they are ignored.

    Returns
    -------
    prediction : int
        1 → Lewis won the round
        0 → Holyfield won the round
    nodes : list[int]
        Boolean truth values (1 = True, 0 = False) of the inner nodes
        in the order they are evaluated:
        nodes[0] – result of the root split (Judge in {0,1,2})
        nodes[1] – result of the second‑level split (Official == 1)
    """

    # ----- inner node 0 : root split on Judge -------------------------
    # Judges 0,1,2 correspond to
    #   0 = E. Williams
    #   1 = L. O'Connell
    #   2 = S. Christodoulu
    judges_favoring_lewis = {0, 1, 2}
    node0 = int(X["Judge"] in judges_favoring_lewis)      # 1 if True, 0 if False

    # ----- inner node 1 : split on Official (only relevant if node0 == 0) -----
    # Official == 1  → official judge (Yes)
    node1 = int(X["Official"] == 1)                      # 1 if Yes, 0 if No

    # ----- make the prediction -----------------------------------------
    if node0:                     # Judge is one of {0,1,2}
        prediction = 1            # Lewis
    else:                         # Judge is in the other eight judges
        if node1:                 # Official judge = Yes
            prediction = 0        # Holyfield
        else:                     # Official judge = No
            prediction = 1        # Lewis

    # Return prediction and the list of inner‑node truth values
    return prediction, [node0, node1]
```

### How the function works

| Node index | Condition evaluated | Meaning when the condition is **True** (value = 1) |
|------------|--------------------|----------------------------------------------------|
| **0**      | `Judge` is 0, 1 or 2 | The round is automatically assigned to **Lewis** (target = 1). |
| **1**      | `Official` == 1      | For the remaining judges, the round goes to **Holyfield** (target = 0). If this condition is **False**, the round goes back to **Lewis**. |

The list `nodes` therefore contains two integers (`0` or `1`) that tell you which branches of the tree were taken for the supplied input. The function returns both the final class (`prediction`) and the branch‑truth list, matching the format you asked for.
