```python
def predict(X: dict):
    """
    Predict which fighter won a given round.

    Parameters
    ----------
    X : dict
        Dictionary that contains the three input features (exact keys must match
        the dataset description):
            - "Judge"      : int, 0‑9   (0 = E. Williams, 1 = L. O'Connell, …,
                                         8 = ESPN, 9 = Boxing Monthly‑Leach)
            - "Official"   : int, 0 or 1 (0 = No, 1 = Yes)
            - "Round"      : int, 1‑12

    Returns
    -------
    prediction : int
        1 → Lewis wins the round  
        0 → Holyfield wins the round
    nodes : list[int]
        Truth values of the two inner nodes (1 = condition satisfied,
        0 = condition not satisfied) in the order they are evaluated.
    """

    # -------------------------------------------------
    # inner node 0 : split on the round number
    # -------------------------------------------------
    node0 = int(X["Round"] <= 6)          # 1 if early round (1‑6), else 0
    # -------------------------------------------------
    # inner node 1 : condition depends on which side of node0 we are on
    # -------------------------------------------------
    if node0:                              # early rounds → look at the judge
        node1 = int(X["Judge"] in (0, 3, 8))   # judges that favour Holyfield
        if node1:                          # Judge is E. Williams, HBO‑Lederman or ESPN
            prediction = 0                # Holyfield
        else:
            prediction = 1                # Lewis
    else:                                 # late rounds → look at Official flag
        node1 = int(X["Official"] == 1)   # 1 if the judge is an official judge
        if node1:                          # official judge
            prediction = 1                # Lewis
        else:
            prediction = 0                # Holyfield

    nodes = [node0, node1]
    return prediction, nodes
```

The function returns both the predicted class (`1 = Lewis`, `0 = Holyfield`) and the list `nodes` that records whether each inner‑node condition was satisfied (`1`) or not (`0`). This matches the format shown in the example you provided.
