**Python function – decision‑tree predictor**

```python
def predict(X: dict):
    """
    Predict which fighter won a given round.

    Feature encoding (as described in the prompt)
    -------------------------------------------------
    X['Judge']    : integer 0‑9
        0 = E. Williams
        1 = L. O'Connell
        2 = S. Christodoulu
        3 = HBO‑Lederman
        4 = Sportsticker
        5 = Boxing Times
        6 = Sportsline
        7 = Associated Press
        8 = ESPN
        9 = Boxing Monthly‑Leach

    X['Official'] : 1 = judge is on the official panel,
                    0 = guest / media judge

    X['Round']    : integer from 1 to 12 (the round number)

    Target (output)
    -------------------------------------------------
    1 → Lewis won the round
    0 → Holyfield won the round
    """

    # ------------------------------------------------------------------
    # 1️⃣  Build the truth‑values for every inner node of the tree.
    # ------------------------------------------------------------------
    #   nodes[0] – is the judge a *guest* (Official == 0) ?
    #   nodes[1] – for a guest judge: is the judge in {ESPN, Boxing Monthly‑Leach,
    #               Sportsline} ?  (indices 8, 9, 6)
    #   nodes[2] – for an official judge: is the round ≤ 6 ?
    #   nodes[3] – (round ≤ 6) is the judge S. Christodoulu (index 2) ?
    #   nodes[4] – (round > 6) is the round ≤ 9 ?
    #   nodes[5] – (6 < round ≤ 9) is the judge HBO‑Lederman or Boxing Times
    #               (indices 3 or 5) ?
    # ------------------------------------------------------------------
    nodes = [None] * 6

    nodes[0] = X['Official'] == 0                     # guest judge ?
    nodes[1] = X['Judge'] in (8, 9, 6)                # guest‑judge → Lewis ?
    nodes[2] = X['Round'] <= 6                       # official & early round ?
    nodes[3] = X['Judge'] == 2                       # S. Christodoulu ?
    nodes[4] = X['Round'] <= 9                       # official & 7‑9 ?
    nodes[5] = X['Judge'] in (3, 5)                  # HBO‑Lederman or Boxing Times ?

    # ------------------------------------------------------------------
    # 2️⃣  Follow the tree using the pre‑computed node values.
    # ------------------------------------------------------------------
    if nodes[0]:                     # ──> Guest judge branch
        if nodes[1]:
            prediction = 1           # Lewis
        else:
            prediction = 0           # Holyfield
    else:                            # ──> Official judge branch
        if nodes[2]:                 # Round 1‑6
            if nodes[3]:             # Judge = S. Christodoulu
                prediction = 0       # Holyfield
            else:
                prediction = 1       # Lewis
        else:                        # Round 7‑12
            if nodes[4]:             # Round 7‑9
                if nodes[5]:         # Judge = HBO‑Lederman or Boxing Times
                    prediction = 0   # Holyfield
                else:
                    prediction = 1   # Lewis
            else:                    # Round 10‑12
                prediction = 0       # Holyfield

    return prediction, nodes
```

### How the function works
1. **Node evaluation** – All inner‑node conditions are evaluated first and stored in `nodes`.  
2. **Tree traversal** – The `if/else` block uses those boolean values to walk the tree exactly as described in the earlier textual representation.  
3. **Output** – The function returns a tuple:
   * `prediction` – `1` (Lewis) or `0` (Holyfield) for the supplied round‑record.  
   * `nodes` – a list of the six truth values `[node0, node1, …, node5]` where `1` means the condition was true and `0` means false.  

You can now call the predictor, for example:

```python
sample = {'Judge': 3, 'Official': 1, 'Round': 8}
winner, truth_vals = predict(sample)
print(winner)        # 0 → Holyfield
```

The list `truth_vals` mirrors the inner‑node decisions made by the tree for that particular input.
