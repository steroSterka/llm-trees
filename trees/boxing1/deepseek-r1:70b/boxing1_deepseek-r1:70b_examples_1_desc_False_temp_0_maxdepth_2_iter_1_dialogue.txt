To solve this problem, we need to create a Python function that predicts which boxer (Lewis or Holyfield) won a given round based on specific features. The decision tree used for prediction is structured to use two features: whether the judge is official and the round number.

### Approach
The approach involves constructing a decision tree with a maximum depth of 2, using the following logic:

1. **Check if the Judge is Official**: 
   - If the judge is an official judge (Official == 1), predict that Holyfield won the round.
   
2. **If the Judge is Not Official**:
   - Check the round number.
     - For rounds 1 through 6, predict that Lewis won the round.
     - For rounds 7 through 12, predict that Holyfield won the round.

The function will return both the prediction and a list indicating whether each condition in the decision tree was satisfied (1 if true, 0 otherwise).

### Solution Code

```python
def predict(X: dict):
    nodes = [None, None]  # Initialize nodes for two inner conditions
    
    # Node 0: Check if the judge is official
    nodes[0] = X['Official'] == 1
    
    prediction = 0  # Default prediction as Holyfield
    
    if not nodes[0]:  # If not an official judge, proceed to check Round
        # Node 1: Check if Round <=6
        nodes[1] = X['Round'] <= 6
        
        if nodes[1]:
            prediction = 1  # Lewis wins rounds 1-6 when judge is not official
    
    # Convert boolean values in nodes to integers (1 for True, 0 otherwise)
    nodes = [int(node) if node is not None else 0 for node in nodes]
    
    return prediction, tuple(nodes)
```

### Explanation
The function `predict` takes a dictionary `X` containing the features 'Judge', 'Official', and 'Round'. It evaluates these features using the decision tree logic:

1. **Node 0**: Checks if the judge is official (`X['Official'] == 1`). If true, Holyfield wins.
2. **Node 1**: Only evaluated if Node 0 is false (non-official judge). Checks if the round number is less than or equal to 6. If true, Lewis wins; otherwise, Holyfield wins.

The function returns a tuple with the prediction result and a list indicating whether each condition in the decision tree was satisfied. This approach ensures that we accurately predict the winner of each round based on the given features while maintaining simplicity and interpretability.
