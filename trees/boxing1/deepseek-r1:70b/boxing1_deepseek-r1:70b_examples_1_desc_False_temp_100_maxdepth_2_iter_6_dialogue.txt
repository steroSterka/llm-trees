Here's how you can implement this:

```python
def predict_winner(X):
    # Define which judges favor Lewis in early rounds
    lewis_early_judges = {0, 1, 4, 6, 8}
    
    # Extract features from input dictionary X
    judge = int(X['Judge'])
    round_number = int(X['Round'])
    
    # Create the nodes list with two conditions checked during prediction
    node = [round_number <= 6]
    if judge in lewis_early_judges:
        node.append(True)
    else:
        node.append(False)
    
    # Convert boolean values to integers for the nodes list
    nodes = [int(condition) for condition in node]
    
    # Determine prediction based on conditions
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Lewis wins
        else:
            prediction = 0  # Holyfield wins
    else:
        if nodes[1]:
            prediction = 0  # Holyfield wins
        else:
            prediction = 1  # Lewis wins
    
    return prediction, nodes

# Example usage:
features = {'Judge': '1', 'Round': '5'}
predicted_winner, nodes = predict_winner(features)
print(f"Predicted winner: {['Holyfield', 'Lewis'][predicted_winner]}")
print(f"Nodes evaluated: {nodes}")
```

1. **Define Judges Favoring Lewis in Early Rounds:**
   - Create a set of judge indices who tend to favor Lewis during early rounds (rounds 1 through 6).

   - Retrieve the judge's index and the round number from the input dictionary.

3. **Create Nodes List with Conditions Checked During Prediction:**
   - The first node checks if the round is an early round (`<=6`).
   - The second node checks if the current judge is one who favors Lewis in early rounds.

4. **Convert Boolean Values to Integers for Nodes List:**
   - Convert `True` to `1` and `False` to `0` to represent the conditions as integers.

5. **Determine Prediction Based on Conditions:**
   - If it's an early round, check if the judge favors Lewis; if so, Lewis wins.
   - If it's a late round, rely on whether the judge typically switches their decision post-round 6 to determine the winner.
