To create a Python function that predicts which boxer won each round based on the given features using a decision tree of maximum depth 2, follow these steps:

### Approach
The decision tree will use two primary features to classify the winner:
1. **Official**: Indicates if the judge is official (1 for yes, 0 for no).
2. **Round**: The round number (ranging from 1 to 12).

The tree first checks if the judge is official. If true, it predicts Lewis as the winner. If false, it then checks the round number: rounds 1-6 are predicted as wins for Holyfield, and rounds 7-12 for Lewis.

### Solution Code
```python
def predict(X: dict):
    nodes = [None, None]
    # Evaluate conditions for inner nodes
    nodes[0] = (X['Official'] == 1)
    nodes[1] = (X['Round'] <= 6)
    
    # Convert boolean values to integers (1 if True, 0 otherwise)
    nodes = [int(node) for node in nodes]
    
    # Determine prediction based on the decision tree logic
    if nodes[0]:
        prediction = 1  # Lewis wins
    else:
        if nodes[1]:
            prediction = 0  # Holyfield wins
        else:
            prediction = 1  # Lewis wins
    
    return prediction, nodes
```

### Explanation
- **Features Extraction**: The function extracts the values of 'Official' and 'Round' from the input dictionary `X`.
- **Node Evaluation**: It evaluates two conditions: whether the judge is official (`nodes[0]`) and if the round number is 6 or less (`nodes[1]`).
- **Prediction Logic**: 
  - If the judge is official, Lewis is predicted to win.
  - If the judge is not official, it checks the round number. Rounds 1-6 predict Holyfield wins, and rounds 7-12 predict Lewis wins.
- **Return Values**: The function returns the predicted winner (as an integer) and a list of integers representing whether each node's condition was met.

This approach efficiently classifies the winner using a shallow decision tree based on the most predictive features.
