```python
def predict(X: dict):
    """
    Predicts the winner of a boxing round (Lewis or Holyfield) based on provided features.

    Args:
        X (dict): A dictionary containing the feature values.  Keys must be:
            'Judge': (0 = E. Williams, 1 = L. O'Connell, 2 = S. Christodoulu, 3 = HBO-Lederman, 4 = Sportsticker, 5 = Boxing Times, 6 = Sportsline, 7 = Associated Press, 8 = ESPN, 9 = Boxing Monthly-Leach)
            'Official': (1 = Yes, 0 = No)
            'Round': (1 to 12)

    Returns:
        tuple: A tuple containing the prediction (1 = Lewis, 0 = Holyfield) and a list representing
               the truth values of the inner nodes (1 = condition satisfied, 0 = condition not satisfied).
    """

    nodes = [None, None]

    # Node 1: Judge == HBO-Lederman (Judge == 3)
    nodes[0] = X['Judge'] == 3

    if nodes[0]:
        prediction = 1  # Lewis
    else:
        # Node 2: Official Judge == Yes (Official == 1)
        nodes[1] = X['Official'] == 1

        if nodes[1]:
            prediction = 1  # Lewis
        else:
            # Node 3: Round <= 6
            if X['Round'] <= 6:
                prediction = 0  # Holyfield
            else:
                prediction = 1  # Lewis

    return prediction, nodes
```

**Explanation:**

1.  **Feature Encoding:** The code uses the feature encoding specified in the problem description. For example, `X['Judge'] == 3` checks if the Judge is HBO-Lederman (encoded as 3).

2.  **Decision Tree Structure:** The code directly implements the decision tree structure we defined earlier.

3.  **Node Evaluation:**  Each `nodes[i] = ...` line evaluates the condition at an inner node. The result (True or False) is automatically converted to 1 or 0 due to the boolean nature of the condition.

4.  **Prediction:** Based on the evaluation of the nodes, the code makes a prediction (1 for Lewis, 0 for Holyfield).

5.  **Return Value:** The function returns a tuple containing the prediction and the list of node truth values, as requested.
