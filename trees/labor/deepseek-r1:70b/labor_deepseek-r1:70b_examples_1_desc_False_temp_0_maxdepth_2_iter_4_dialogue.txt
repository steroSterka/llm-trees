To solve this problem, we need to create a function that predicts an outcome based on given input features using a decision tree structure. The function will return both the predicted outcome and a list indicating whether each internal node's condition was satisfied (1 if true, 0 otherwise).

### Approach
The problem involves constructing a decision tree of depth 2. The root node checks if the "cost of living adjustment" is 'tc'. If this condition is met, the prediction is directly made as 1. If not, we proceed to check the next internal node which evaluates whether the "wage increase first year" exceeds 5. Based on these conditions, the function returns a prediction and a list of boolean values indicating the satisfaction of each internal node's condition.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    # Evaluate all inner node conditions upfront
    cost_tc = X['cost of living adjustment'] == 'tc'
    wage_high = X['wage increase first year'] > 5

    # Create the nodes list with 1s and 0s
    nodes = [int(cost_tc), int(wage_high)]

    # Determine prediction based on the evaluated conditions
    if cost_tc:
        prediction = 1
    else:
        if wage_high:
            prediction = 1
        else:
            prediction = 0

    return prediction, nodes
```

### Explanation
1. **Evaluate Conditions Upfront**: The function first evaluates both internal node conditions regardless of the path taken in the decision tree. This ensures that all relevant conditions are checked and their results stored for later use.
2. **Construct Nodes List**: Each condition's result is converted to an integer (1 if true, 0 otherwise) and stored in a list called `nodes`.
3. **Determine Prediction**: Using the precomputed conditions, the function then follows the decision tree logic:
   - If "cost of living adjustment" is 'tc', it directly predicts 1.
   - Otherwise, it checks if "wage increase first year" exceeds 5 to decide the prediction.

This approach ensures that all internal nodes are evaluated and their results stored, providing a clear trace of how each decision was made in the tree.
