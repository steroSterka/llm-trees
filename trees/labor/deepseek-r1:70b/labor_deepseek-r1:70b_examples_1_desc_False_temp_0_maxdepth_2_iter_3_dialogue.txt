Here is a Python function that implements the decision tree logic described:

```python
def predict(X: dict):
    # Initialize nodes list to keep track of condition evaluations
    nodes = [None, None]  # Two inner nodes for max depth of 2
    
    # First node: Check if cost_of_living_adjustment is not 'none'
    col_a = X.get('cost_of_living_adjustment', 'none')
    nodes[0] = (col_a != 'none')
    
    # Second node: Check if wage_increase_first_year is greater than or equal to 4
    wage_inc = float(X.get('wage increase first year', 2.0))
    nodes[1] = (wage_inc >= 4)
    
    # Determine the prediction based on the nodes' evaluations
    if not nodes[0]:  # If cost_of_living_adjustment is 'none'
        prediction = 0  # Outcome is bad
    else:
        if nodes[1]:   # Check wage_increase_first_year
            prediction = 1  # Good outcome
        else:
            prediction = 0  # Bad outcome
    
    return prediction, nodes
```

### Explanation:

- **Function Definition**: The function `predict` takes a dictionary `X` containing the features as input.
  
- **Nodes Initialization**: A list `nodes` is initialized to keep track of the boolean outcomes of each condition check within the decision tree.

- **First Condition Check**: The first node evaluates whether the "cost_of_living_adjustment" is not 'none'. This determines if further evaluation is needed.

- **Second Condition Check**: The second node checks if the "wage_increase_first_year" is at least 4. This is used for prediction only if the first condition is true.

- **Prediction Logic**:
  - If the "cost_of_living_adjustment" is 'none', the outcome is directly set to bad (0).
  - Otherwise, the function checks the second node's evaluation to decide between a good (1) or bad (0) outcome.

This function accurately reflects the decision tree logic and ensures that both condition checks are recorded in the `nodes` list for transparency.
