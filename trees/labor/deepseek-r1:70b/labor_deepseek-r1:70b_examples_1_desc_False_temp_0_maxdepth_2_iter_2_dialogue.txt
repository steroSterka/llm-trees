To solve this problem, we need to predict whether a set of economic indicators suggests good outcomes based on specific conditions related to wage increases and cost of living adjustments. The goal is to create a decision tree model that evaluates these conditions and returns both the prediction and the evaluation results of the inner nodes.

### Approach
1. **Extract Features**: Extract the relevant features from the input data, specifically "wage increase first year" and "cost of living adjustment".
2. **Evaluate Conditions**:
   - Check if the wage increase is greater than 5.
   - Check if the cost of living adjustment is equal to 'tc' (total compensation adjustment).
3. **Determine Prediction**: Based on these conditions, determine the prediction:
   - If the wage increase is greater than 5, predict a positive outcome (1).
   - If not, check the cost of living adjustment. If it's 'tc', predict a positive outcome; otherwise, predict a negative outcome (0).
4. **Capture Node Evaluations**: Convert the boolean results of the conditions into integers for recording the evaluation of each inner node in the decision tree.

### Solution Code
```python
def predict(X):
    # Evaluate the first condition: wage increase > 5
    node0 = X["wage increase first year"] > 5
    
    # Evaluate the second condition: cost of living adjustment is 'tc'
    node1 = (X["cost of living adjustment"] == 'tc')
    
    # Determine the prediction based on the conditions
    if node0:
        prediction = 1
    else:
        prediction = 1 if node1 else 0
    
    # Convert boolean values to integers for the nodes list
    nodes_list = [int(node0), int(node1)]
    
    return (prediction, nodes_list)
```

### Explanation
- **Feature Extraction**: The function extracts "wage increase first year" and "cost of living adjustment" from the input dictionary `X`.
- **Condition Evaluation**: It evaluates two conditions:
  - Whether the wage increase is greater than 5 (`node0`).
  - Whether the cost of living adjustment is exactly 'tc' (`node1`).
- **Prediction Logic**: The prediction is made based on these evaluations. If the first condition is true, it predicts a positive outcome (1). Otherwise, it checks the second condition to decide the prediction.
- **Node Evaluation Capture**: Both conditions are converted from boolean values to integers (True becomes 1 and False becomes 0) to capture the evaluation results of each inner node in the decision tree.

This approach ensures that both the prediction and the intermediate evaluations are captured, providing a clear insight into how each condition contributes to the final outcome.
