```python
def predict(X: dict):
    nodes = 7 * [None]
    
    # Node 0: wage increase first year <= 4.5
    nodes[0] = X["wage increase first year"] <= 4.5
    
    # Node 1: duration > 4 (inside node 0)
    if not nodes[0]:
        nodes[1] = True
    else:
        nodes[1] = X["duration"] > 4
    
    # Node 2: vacation == 'gnr' (inside node 0 and node 1)
    if not nodes[0] or nodes[1]:
        nodes[2] = False
    else:
        nodes[2] = X["vacation"] == "gnr"
    
    # Node 3: contribution to health plan == 'full' (inside node 0, node 1 and node 2)
    if not nodes[0] or nodes[1] or nodes[2]:
        nodes[3] = False
    else:
        nodes[3] = X["contribution to health plan"] == "full"
    
    # Node 4: cost of living adjustment == 'tc' (inside node 0, node 1, node 2 and node 3)
    if not nodes[0] or nodes[1] or nodes[2] or nodes[3]:
        nodes[4] = False
    else:
        nodes[4] = X["cost of living adjustment"] == "tc"
    
    # Node 5: duration <= 4 (inside node 0)
    if not nodes[0]:
        nodes[5] = False
    else:
        nodes[5] = X["duration"] <= 4
    
    # Node 6: wage increase first year > 4.5 (root node, always true)
    nodes[6] = True
    
    # Prediction
    if not nodes[0]:
        prediction = 1  # good
    else:
        if nodes[5]:
            if nodes[2]:
                prediction = 1  # good
            elif nodes[3]:
                prediction = 1  # good
            elif nodes[4]:
                prediction = 1  # good
            else:
                prediction = 0  # bad
        else:  # nodes[5] is False, so duration > 4
            prediction = 1  # good
    
    return int(prediction), [int(x) for x in nodes]
```

This function takes a dictionary `X` as input and returns the predicted outcome (either 0 or 1) along with a list of binary values representing the truth values of each inner node. Note that I've filled in the thresholds based on the feature descriptions provided.
