Below is a **sample decision‑tree model** that could be used to decide whether a credit‑card application is **Accepted** or **Rejected**.  
The split thresholds and ordering are illustrative – they reflect what typically turns out to be the most predictive variables in credit‑risk data (derogatory reports, income relative to dependents, credit‑card spending, home ownership, self‑employment, and age).  

---

### Decision Tree (text‑tree format)

```
|--- number_of_derogatory_reports <= 0
||--- income_per_dependent >= 4.0
|||--- monthly_credit_card_expenses <= 500
||||--- class: Accepted
|||--- monthly_credit_card_expenses > 500
||||--- class: Rejected
||--- income_per_dependent < 4.0
|||--- class: Rejected
|--- number_of_derogatory_reports > 0
||--- number_of_derogatory_reports <= 2
|||--- owning_a_home = yes
||||--- class: Accepted
|||--- owning_a_home = no
||||--- class: Rejected
||--- number_of_derogatory_reports > 2
|||--- class: Rejected
```

---

### How the tree was built (feature‑importance rationale)

| Rank | Feature                         | Why it’s high on the list |
|------|--------------------------------|---------------------------|
| 1    | **number_of_derogatory_reports** | Direct evidence of past credit problems; strongest predictor of default. |
| 2    | **income_per_dependent**        | Captures repayment capacity after accounting for household size. |
| 3    | **monthly_credit_card_expenses**| High revolving balances relative to income flag over‑extension. |
| 4    | **owning_a_home**               | Home ownership is a proxy for asset‑based stability. |
| 5    | **self_employed**               | Self‑employment can increase income volatility; used when other signals are borderline. |
| 6    | **age**                         | Younger applicants often have shorter credit histories; older applicants may have more stable patterns. |

---

### Quick “walk‑through” of the tree

1. **Derogatory reports = 0** – No prior negative marks.  
   - If **income per dependent ≥ 4 k** (i.e., the applicant earns at least $4,000 per dependent), we look at spending:  
     - **Monthly credit‑card spend ≤ $500** → **Accepted** (low debt load).  
     - **Spend > $500** → **Rejected** (potential over‑extension).  
   - If **income per dependent < 4 k** → **Rejected** (insufficient earnings).

2. **Derogatory reports > 0** – Some negative history.  
   - If the count is **1‑2** and the applicant **owns a home**, we give a **conditional Accept** (asset cushion).  
   - If they **don’t own a home** or have **> 2 reports**, the risk is deemed too high → **Rejected**.

---

### How to use this tree in practice  

- **Collect** the six input variables for every applicant.  
- **Traverse** the tree from the top, applying each binary test until you hit a leaf node (`Accepted` or `Rejected`).  
- **Adjust thresholds** (e.g., the $500 spending limit or the 4.0 k income per dependent) based on your institution’s historical loss‑given‑default data or regulatory guidelines.  

---

> **Note:** This tree is a **conceptual illustration**.  
> For production use you would:
> 1. Gather a labeled dataset of past applications (Accepted/Rejected).  
> 2. Train a CART (Classification‑and‑Regression‑Tree) model (or an ensemble like Random Forest/Gradient Boosting) to obtain the exact split points and feature importances.  
> 3. Validate performance (AUC, precision/recall, KS‑statistic) on a hold‑out set and calibrate the decision thresholds to meet your risk appetite.

**Python implementation of the credit‑approval decision tree**

```python
def predict(X: dict):
    """
    Predict whether a credit‑card application is accepted (1) or rejected (0).

    Parameters
    ----------
    X : dict
        Dictionary that must contain the following keys (exact spelling):
        - 'Age'
        - 'Income.per.dependent'          # float, 1.5 – 10
        - 'Monthly.credit.card.exp'       # float, dollars
        - 'Own.home'                      # 1 = yes, 0 = no
        - 'Self.employed'                 # 1 = yes, 0 = no   (not used in this tree)
        - 'Derogatory.reports'            # integer (0,1,2,3,4,7)

    Returns
    -------
    prediction : int
        1 → application accepted, 0 → application rejected
    nodes : list[int]
        Truth values (1 = condition satisfied, 0 = not) for each inner node
        in the order they are evaluated:
        0 – Derogatory.reports <= 0
        1 – Income.per.dependent >= 4.0            (only evaluated if node 0 is true)
        2 – Monthly.credit.card.exp <= 500        (only evaluated if nodes 0 & 1 are true)
        3 – Derogatory.reports <= 2               (only evaluated if node 0 is false)
        4 – Own.home == 1                         (only evaluated if nodes 0 & 3 are true)
    """
    # initialise the list of inner‑node results (5 inner nodes in this tree)
    nodes = [0] * 5

    # -----------------------------------------------------------------
    # Node 0 : are there *no* derogatory reports ?
    # -----------------------------------------------------------------
    nodes[0] = 1 if X["Derogatory.reports"] <= 0 else 0

    if nodes[0]:                     # ----- Derogatory.reports == 0 -----
        # Node 1 : is income per dependent high enough ?
        nodes[1] = 1 if X["Income.per.dependent"] >= 4.0 else 0

        if nodes[1]:                 # ----- income >= 4.0 -----
            # Node 2 : does the applicant keep monthly card spend modest ?
            nodes[2] = 1 if X["Monthly.credit.card.exp"] <= 500 else 0

            if nodes[2]:             # ----- spend <= $500 -----
                prediction = 1       # ACCEPT
            else:                    # ----- spend  > $500 -----
                prediction = 0       # REJECT
        else:                        # ----- income < 4.0 -----
            prediction = 0           # REJECT

    else:                            # ----- Derogatory.reports > 0 -----
        # Node 3 : are the reports limited (1‑2) ?
        nodes[3] = 1 if X["Derogatory.reports"] <= 2 else 0

        if nodes[3]:                 # ----- 1‑2 reports -----
            # Node 4 : does the applicant own a home ?
            nodes[4] = 1 if X["Own.home"] == 1 else 0

            if nodes[4]:             # ----- owns a home -----
                prediction = 1       # ACCEPT
            else:                    # ----- does NOT own a home -----
                prediction = 0       # REJECT
        else:                        # ----- > 2 reports -----
            prediction = 0           # REJECT

    # Convert Boolean 0/1 to plain integers (ensures 0/1 output)
    nodes = [int(v) for v in nodes]

    return prediction, nodes
```

### How the function works
1. **Node 0** checks the most predictive feature – the number of derogatory reports.  
2. If the applicant has **no reports**, the tree evaluates income, then spending, to decide acceptance.  
3. If the applicant has **some reports**, the tree checks whether the count is modest (≤ 2) and, if so, whether the applicant owns a home; otherwise the application is rejected.  

The returned `nodes` list lets you see exactly which internal conditions were satisfied for a given applicant (e.g., `[1, 1, 0, 0, 0]` means *no derogatory reports*, *income ≥ 4.0*, but *monthly spend > 500*).
