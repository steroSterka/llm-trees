### How to read the tree

1. **First decision** – look at the applicant’s **number of derogatory reports**.  
   *If it is **0**, the applicant is “clean” and we move to the next test.*  
   *If it is **> 0**, the applicant already carries some risk, so we check how many (≤ 2 vs > 2) and whether they own a home.

2. **Second decision (for clean applicants)** – compare **income per dependent** to **4.0** (units: thousand $ per dependent, or whatever scale you use).  
   *If the ratio is **≥ 4**, the applicant has a comfortable margin; otherwise they are rejected outright.*

3. **Third decision (high‑income, clean applicants)** – examine **monthly credit‑card expenses**.  
   *If the expense is **≤ $500**, the applicant is accepted.  
   *If it is **> $500**, the applicant is considered over‑leveraged and is rejected.*

4. **Second decision (for applicants with ≤ 2 derogatory reports)** – check **home ownership**.  
   *Home‑owners are accepted; renters are rejected.*

5. **Any applicant with > 2 derogatory reports** is automatically rejected.

```python
def predict(X: dict):
    """
    Decision‑tree classifier for credit‑application approval.

    Expected keys in ``X`` (exact spelling):
        'Age'                     – age in years (not used in the tree)
        'Income.per.dependent'    – income per dependent (range 1.5‑10)
        'Monthly.credit.card.exp'– monthly credit‑card expenses (USD)
        'Own.home'                – 1 = owns a home, 0 = does not own
        'Self.employed'           – 1 = self‑employed, 0 = otherwise
        'Derogatory.reports'      – number of derogatory reports (0‑7)

    Returns
    -------
    prediction : int
        1 = application **Accepted**, 0 = **Rejected**
    nodes : list[int]
        Truth values of the five inner‑node tests (1 = condition satisfied,
        0 = not satisfied).  The order of the nodes follows a top‑down,
        left‑to‑right traversal of the tree.

        0 – Derogatory.reports <= 0
        1 – Income.per.dependent >= 4.0
        2 – Monthly.credit.card.exp <= 500
        3 – Derogatory.reports <= 2
        4 – Own.home == 1
    """

    # ------------------------------------------------------------------
    # 1️⃣  Compute the boolean outcome of every inner node (converted to 0/1)
    # ------------------------------------------------------------------
    nodes = [0] * 5
    nodes[0] = int(X['Derogatory.reports'] <= 0)               # node 0
    nodes[1] = int(X['Income.per.dependent'] >= 4.0)           # node 1
    nodes[2] = int(X['Monthly.credit.card.exp'] <= 500)       # node 2
    nodes[3] = int(X['Derogatory.reports'] <= 2)              # node 3
    nodes[4] = int(X['Own.home'] == 1)                         # node 4

    # ------------------------------------------------------------------
    # 2️⃣  Follow the tree logic to produce the final prediction
    # ------------------------------------------------------------------
    if nodes[0]:                     # Derogatory.reports <= 0  (clean applicant)
        if nodes[1]:                 # Income.per.dependent >= 4.0
            if nodes[2]:             # Monthly.credit.card.exp <= 500
                prediction = 1       # ACCEPTED
            else:
                prediction = 0       # REJECTED (high credit‑card spend)
        else:
            prediction = 0           # REJECTED (low income per dependent)
    else:                            # Derogatory.reports > 0
        if nodes[3]:                 # Derogatory.reports <= 2
            if nodes[4]:             # Own.home == 1
                prediction = 1       # ACCEPTED
            else:
                prediction = 0       # REJECTED (no home ownership)
        else:
            prediction = 0           # REJECTED (≥ 3 derogatory reports)

    return prediction, nodes
```

### How the function works

| Node index | Condition (as evaluated)                              | Meaning in the tree |
|-----------|--------------------------------------------------------|----------------------|
| 0 | `Derogatory.reports <= 0` | “clean” applicant (no past derogatory reports) |
| 1 | `Income.per.dependent >= 4.0` | Sufficient income after accounting for dependents |
| 2 | `Monthly.credit.card.exp <= 500` | Low revolving credit‑card usage |
| 3 | `Derogatory.reports <= 2` | Small number of past derogatory reports |
| 4 | `Own.home == 1` | Applicant owns a home (asset‑based stability) |

The list `nodes` contains five integers (`1` = condition true, `0` = false) in the exact order shown above, while `prediction` is the final credit‑approval decision (`1` = Accepted, `0` = Rejected).
