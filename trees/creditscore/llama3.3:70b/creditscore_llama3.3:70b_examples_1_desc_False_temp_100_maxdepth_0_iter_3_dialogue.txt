```python
def predict_credit_application(X: dict):
    """
    Predicts whether an application for credit is accepted or not based on given features.
    
    Parameters:
    X (dict): Dictionary containing the features.
        - Age (years)
        - Income.per.dependent (income per dependent, 1.5 to 10)
        - Monthly.credit.card.exp (monthly credit card expenses in $)
        - Own.home (owning a home, 1 = yes, 0 = no)
        - Self.employed (self employed, 1 = yes, 0 = no)
        - Derogatory.reports (number of derogatory reports)

    Returns:
    prediction (int): 1 if the application is accepted, 0 otherwise.
    nodes (list): A list representing the truth values of the inner nodes.
    """

    # Initialize the nodes with None
    nodes = 7 * [None]

    # Node 0: Number of derogatory reports > 2
    nodes[0] = X['Derogatory.reports'] > 2

    # If number of derogatory reports is more than 2, reject the application
    if nodes[0]:
        prediction = 0
        return prediction, [int(nodes[0]), 0, 0, 0, 0, 0, 0]

    # Node 1: Owning a home == yes
    nodes[1] = X['Own.home'] == 1

    if nodes[1]:
        prediction = 1  # Accept the application
        return prediction, [int(nodes[0]), int(nodes[1]), 0, 0, 0, 0, 0]

    # Node 2: Income per dependent >= 5
    nodes[2] = X['Income.per.dependent'] >= 5

    if not nodes[2]:
        prediction = 0  # Reject the application due to low income
        return prediction, [int(nodes[0]), int(nodes[1]), int(nodes[2]), 0, 0, 0, 0]

    # Node 3: Monthly credit card expenses <= $500
    nodes[3] = X['Monthly.credit.card.exp'] <= 500

    if not nodes[3]:
        prediction = 0  # Reject the application due to high expenses
        return prediction, [int(nodes[0]), int(nodes[1]), int(nodes[2]), int(nodes[3]), 0, 0, 0]

    # Node 4: Self employed == no
    nodes[4] = X['Self.employed'] == 0

    if not nodes[4]:
        prediction = 0  # Reject the application due to self employment
        return prediction, [int(nodes[0]), int(nodes[1]), int(nodes[2]), int(nodes[3]), int(nodes[4]), 0, 0]

    # Node 5: Age >= 30
    nodes[5] = X['Age'] >= 30

    if not nodes[5]:
        prediction = 0  # Reject the application due to young age
        return prediction, [int(nodes[0]), int(nodes[1]), int(nodes[2]), int(nodes[3]), int(nodes[4]), int(nodes[5]), 0]

    # Node 6: Final check - Accept if all conditions met
    nodes[6] = True

    prediction = 1  # Accept the application
    return prediction, [int(node) for node in nodes]
```

This function takes a dictionary `X` as input with the specified features. It evaluates each feature according to the decision tree logic and returns a prediction (0 or 1) along with a list of truth values for the inner nodes. Each element in the list represents whether the condition at that node was met (1 for True, 0 for False).
