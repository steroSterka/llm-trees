The number of derogatory reports is often a critical factor in credit decisions because it directly reflects an individual's credit history and reliability. Therefore, this feature could be considered for the first split.

Here's a Python function that implements the decision tree as per your requirements. This function takes in a dictionary `X` containing the feature values and returns a tuple with the predicted target variable value and a list representing the truth values of the inner nodes.

```python
def predict(X: dict):
    """
    Predicts whether an application for credit is accepted or not based on the given features.
    
    Parameters:
    X (dict): A dictionary containing the feature values. The keys are 'Age', 'Income.per.dependent', 
              'Monthly.credit.card.exp', 'Own.home', 'Self.employed', and 'Derogatory.reports'.
    
    Returns:
    tuple: A tuple containing the predicted target variable value (0 = no, 1 = yes) and a list representing 
           the truth values of the inner nodes.
    """
    nodes = 2 * [None]
    nodes[0] = X["Derogatory.reports"] <= 0
    nodes[1] = X["Monthly.credit.card.exp"] <= 500
    
    if nodes[0]:
        prediction = 1  # Application accepted if no derogatory reports
    else:
        if nodes[1]:
            prediction = 1  # Application accepted if manageable monthly credit card expenses
        else:
            prediction = 0  # Application not accepted if high monthly credit card expenses
    
    return prediction, [int(node) for node in nodes]
```

Example usage:

```python
X = {
    "Age": 30,
    "Income.per.dependent": 5,
    "Monthly.credit.card.exp": 400,
    "Own.home": 1,
    "Self.employed": 0,
    "Derogatory.reports": 0
}

prediction, nodes = predict(X)
print("Prediction:", prediction)  # Output: Prediction: 1
print("Nodes:", nodes)  # Output: Nodes: [1, 1]
```

In this example, the application is accepted (predicted target variable value is 1) because there are no derogatory reports and the monthly credit card expenses are manageable. The inner node truth values are `[1, 1]`, indicating that both conditions (`Derogatory.reports <= 0` and `Monthly.credit.card.exp <= 500`) are satisfied.
