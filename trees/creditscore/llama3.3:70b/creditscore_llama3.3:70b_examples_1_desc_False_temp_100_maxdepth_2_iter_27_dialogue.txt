3. **Second Level (Depth 2):** For applicants with derogatory reports, a stricter criterion might be applied due to the increased risk. def predict_credit_acceptance(X: dict):
    """
    Predicts whether an application for credit is accepted or not based on the given features.

    Args:
        X (dict): A dictionary containing the features.
            - 'Age': age in years
            - 'Income.per.dependent': income per dependent (1.5 to 10)
            - 'Monthly.credit.card.exp': monthly credit card expenses ($)
            - 'Own.home': owning a home (1 = yes, 0 = no)
            - 'Self.employed': self employed (1 = yes, 0 = no)
            - 'Derogatory.reports': number of derogatory reports (0, 1, 2, 3, 4, 7)

    Returns:
        prediction (int): 1 if the application for credit is accepted, 0 otherwise
        nodes (list): A list representing the truth values of the inner nodes
    """

    # Initialize nodes with None
    nodes = 2 * [None]

    # Node 0: Check if the number of derogatory reports is less than or equal to 0
    nodes[0] = X['Derogatory.reports'] <= 0

    # If there are no derogatory reports, check income per dependent
    if nodes[0]:
        # Node 1: Check if income per dependent is greater than 5
        nodes[1] = X['Income.per.dependent'] > 5
        # Prediction based on the nodes
        prediction = 1 if nodes[1] else 0
    else:
        # If there are derogatory reports, check income per dependent with a stricter threshold
        nodes[1] = X['Income.per.dependent'] > 8
        # Prediction based on the nodes
        prediction = 1 if nodes[1] else 0

    # Convert boolean values to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]

    return prediction, nodes
