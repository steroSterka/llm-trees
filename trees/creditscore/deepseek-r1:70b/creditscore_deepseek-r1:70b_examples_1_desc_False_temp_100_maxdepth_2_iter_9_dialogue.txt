To solve this problem, we need to create a function that predicts whether a customer's application should be accepted based on two conditions related to derogatory reports and home ownership. The function will return a binary prediction (1 for acceptance and 0 for rejection) along with a list indicating whether each condition was met.

### Approach
The approach involves evaluating two specific conditions:
1. Whether the number of derogatory reports is less than or equal to 1.
2. Whether the customer owns their home.

Based on these evaluations, we determine the final prediction as follows:
- If there are more than one derogatory reports, the application is rejected (prediction = 0).
- If there is one or zero derogatory reports, then home ownership determines the outcome: ownership leads to acceptance (1), while non-ownership results in rejection (0).

The function returns both the prediction and a list of binary values indicating whether each condition was satisfied.

### Solution Code
```python
def predict(X: dict):
    nodes = [None] * 2
    
    # Evaluate first condition: Derogatory reports <=1?
    nodes[0] = 1 if X['Derogatory.reports'] <= 1 else 0
    
    # Evaluate second condition: Own home ==1?
    nodes[1] = 1 if X['Own.home'] == 1 else 0
    
    # Determine prediction based on decision tree logic
    if nodes[0]:
        prediction = 1 if nodes[1] else 0
    else:
        prediction = 0
    
    return prediction, nodes
```

### Explanation
- **Condition Evaluation**: The function first evaluates two conditions and stores the results in a list (`nodes`). Each condition is converted to a binary value where 1 indicates the condition was met.
  - `nodes[0]` checks if the number of derogatory reports is less than or equal to 1.
  - `nodes[1]` checks if the customer owns their home.

- **Prediction Logic**: Using the evaluated conditions, the function then determines the final prediction:
  - If there are more than one derogatory reports (`nodes[0] == 0`), the application is rejected (prediction = 0).
  - If there are one or zero derogatory reports (`nodes[0] == 1`), home ownership status (`nodes[1]`) determines the outcome.

This approach ensures that both conditions are evaluated and their statuses are recorded, providing a clear and interpretable decision-making process.
