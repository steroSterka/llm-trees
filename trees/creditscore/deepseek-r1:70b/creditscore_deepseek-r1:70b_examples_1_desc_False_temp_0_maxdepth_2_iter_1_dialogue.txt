### Approach

   - If true, proceed to evaluate the left subtree conditions.
   - If false, proceed to evaluate the right subtree conditions.

2. **Left Subtree Conditions**:
   - Check if `Income.per.dependent` is greater than 8.
     - If true, predict approval (1).
     - If false, check if `Own.home` is 1 and then predict approval (1); otherwise, predict rejection (0).

3. **Right Subtree Conditions**:
   - Check if `Monthly.credit.card.exp` is greater than 1500.
     - If true, predict rejection (0).
     - If false, check if `Self.employed` is 0 and then predict approval (1); otherwise, predict rejection (0).

4. **Nodes Tracking**: Collect the results of each condition evaluation in a list to represent the path taken during prediction.

### Solution Code
```python
def predict(X):
    nodes = []
    
    # Root condition: Derogatory reports check
    node1 = X['Derogatory.reports'] <= 0
    nodes.append(1 if node1 else 0)
    
    if node1:
        # Left subtree: Income per dependent check
        node2 = X['Income.per.dependent'] > 8
        nodes.append(1 if node2 else 0)
        
        if node2 or (not node2 and X['Own.home'] == 1):
            prediction = 1  # Approve
        else:
            prediction = 0  # Reject
    else:
        # Right subtree: Monthly credit card expense check
        node3 = X['Monthly.credit.card.exp'] > 1500
        nodes.append(1 if node3 else 0)
        
        if node3:
            prediction = 0  # Reject
        else:
            prediction = 1 if (X['Self.employed'] == 0) else 0
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation
- **Root Condition**: The initial check determines the primary path based on `Derogatory.reports`. This is recorded in `nodes`.
- **Left Subtree Handling**: If the root condition is true, further evaluation is done on `Income.per.dependent` and `Own.home` to decide approval or rejection. Both conditions are tracked in `nodes`.
- **Right Subtree Handling**: If the root condition is false, subsequent checks on `Monthly.credit.card.exp` and `Self.employed` determine the outcome. These evaluations are also recorded.
- **Nodes List**: This list keeps track of all inner node decisions made during prediction, ensuring we capture the path taken while adhering to max_depth constraints.

This approach ensures that the decision tree does not exceed a depth of 2, maintaining efficiency and simplicity in the evaluation process.
