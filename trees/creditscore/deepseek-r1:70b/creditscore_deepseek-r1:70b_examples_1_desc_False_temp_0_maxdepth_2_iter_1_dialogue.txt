To predict whether a credit application is accepted based on the given features and decision tree structure, we can create a Python function that evaluates the conditions step by step. The decision tree uses two main features: "Derogatory.reports" and either "Income.per.dependent" or "Own.home". Here's how to implement it:

### Approach
1. **Primary Condition**: Evaluate if the number of derogatory reports is less than or equal to 1.
   - If true, proceed to check the income per dependent against a high threshold (e.g., 7).
2. **Secondary Conditions**:
   - If the primary condition is true and income per dependent exceeds the threshold, accept the application.
   - If the primary condition is false, evaluate if the applicant owns a home. Accept if they do; otherwise, reject.

### Solution Code
```python
def predict_credit_application(X):
    nodes = [None, None]  # Initialize list to hold truth values of inner nodes
    
    # First condition: Derogatory reports <= 1
    nodes[0] = (X['Derogatory.reports'] <= 1)
    
    if nodes[0]:
        # Second condition for this branch: Income per dependent > high threshold (e.g., 7)
        income_threshold_high = 7.0  # Assuming 'high' is defined as >7
        nodes[1] = (X['Income.per.dependent'] > income_threshold_high)
        prediction = 1 if nodes[1] else 0
    else:
        # Second condition for this branch: Own home == yes
        own_home_yes = X['Own.home'] == 'yes'
        nodes[1] = own_home_yes
        prediction = 1 if nodes[1] else 0
    
    # Convert boolean values in nodes to integers (1 for True, 0 for False)
    nodes_ints = [int(node) for node in nodes]
    
    return prediction, nodes_ints
```

### Explanation
- **Primary Condition Check**: The function starts by checking if the number of derogatory reports is within an acceptable range (<=1). This determines the next evaluation path.
- **Income Threshold Evaluation**: If the primary condition is met, the function then checks if the income per dependent exceeds a high threshold (e.g., 7), indicating a higher likelihood of creditworthiness.
- **Home Ownership Check**: If the primary condition isn't met, the function evaluates home ownership as an alternative indicator of stability and creditworthiness.
- **Prediction Outcome**: Based on these evaluations, the function returns either an acceptance (1) or rejection (0) decision along with a list indicating whether each inner node condition was satisfied (1) or not (0).

This structured approach ensures that the decision tree is traversed efficiently, considering the most impactful features first to make an informed prediction.
