To create a decision tree classifier for credit approval based on the given features, we follow these steps:

### Approach
The goal is to classify whether an application for credit is accepted or not using a decision tree. The function will return a single prediction (0 for rejection, 1 for acceptance) and a list of truth values representing the conditions checked in the inner nodes.

#### Features:
- **Derogatory_reports**: Number of derogatory reports (0, 1, 2, 3, 4, 7)
- **Own_home**: Owning a home (1 = yes, 0 = no)
- **Income_per_dependent**: Income per dependent (scale from 1.5 to 10)

#### Decision Tree Logic:
1. **Root Node: Derogatory_reports**
   - If ≤2: Proceed
   - Else (>2): Reject the application

2. **First Internal Node: Own_home**
   - If yes (1): Accept the application
   - If no (0): Proceed to next check

3. **Second Internal Node: Income_per_dependent**
   - If ≥8: Accept the application
   - Else (<8): Reject the application

### Solution Code
```python
def predict(X: dict):
    nodes = [None] * 3
    
    # Evaluate conditions for each node and convert to integers (1 or 0)
    nodes[0] = X["Derogatory.reports"] <= 2
    nodes[0] = int(nodes[0])
    
    nodes[1] = X["Own.home"] == 1
    nodes[1] = int(nodes[1])
    
    nodes[2] = X["Income.per.dependent"] >= 8
    nodes[2] = int(nodes[2])
    
    # Determine prediction based on the evaluated nodes
    if not nodes[0]:
        prediction = 0
    elif nodes[1]:
        prediction = 1
    elif nodes[2]:
        prediction = 1
    else:
        prediction = 0
    
    return prediction, nodes
```

### Explanation
1. **Node Evaluation**: The function evaluates each condition (node) and converts the boolean results to integers (1 for True, 0 for False).
2. **Prediction Logic**:
   - If there are more than 2 derogatory reports (`nodes[0]` is False), the application is rejected.
   - If the applicant owns a home (`nodes[1]` is True), the application is accepted.
   - If the income per dependent is ≥8 (`nodes[2]` is True), the application is accepted; otherwise, it is rejected.

This approach ensures that each condition is checked in sequence, and the final prediction is made based on the evaluated nodes, providing a clear and structured decision-making process for credit approval.
