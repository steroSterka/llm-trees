Here's a Python function that implements the decision tree logic to predict credit acceptance based on the given features. The function also returns a list representing the truth values of the inner nodes:

```python
def predict(X: dict):
    # Initialize the nodes list with five elements (all set to None initially)
    nodes = [None, None, None, None, None]
    
    # Assign each node condition based on feature values
    nodes[0] = X['Derogatory.reports'] > 2
    nodes[1] = X['Income.per.dependent'] > 5
    nodes[2] = X['Monthly.credit.card.exp'] <= 500
    nodes[3] = X['Own.home'] == 1
    nodes[4] = X['Self.employed'] == 1
    
    # Determine the prediction based on node evaluations
    if nodes[0]:
        prediction = 0  # Reject due to high derogatory reports
    else:
        if nodes[1]:
            prediction = 1  # Accept with sufficient income
        else:
            if nodes[2]:
                prediction = 1  # Accept with manageable expenses
            else:
                if nodes[3]:
                    prediction = 1  # Accept due to owning a home
                else:
                    if nodes[4]:
                        prediction = 0  # Reject if self-employed without home ownership
                    else:
                        prediction = 1  # Accept with lower risk
                        
    return prediction, nodes
```

**Explanation:**

- **Nodes List:** The `nodes` list contains boolean values representing the evaluation of each inner node condition in the decision tree. Each index corresponds to a specific feature condition.
  
- **Conditions Evaluated:**
  - Node 0 checks if the number of derogatory reports exceeds 2.
  - Node 1 checks if income per dependent is greater than 5.
  - Node 2 checks if monthly credit card expenses are less than or equal to $500.
  - Node 3 checks if the applicant owns a home (value = 1).
  - Node 4 checks if the applicant is self-employed (value = 1).

- **Prediction Logic:** The function uses nested if-else statements to traverse through the decision tree, starting with the most significant factor (derogatory reports) and progressing through other features as needed. The prediction is determined based on these evaluations.

**Example Usage:**

