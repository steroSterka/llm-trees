To solve this problem, we need to predict whether an individual will default on a loan based on two criteria: their derogatory reports and either their ownership of a home or their income level. The decision is made using a simple decision tree approach with two levels (depth 2).

### Approach
The approach involves evaluating the given data in a sequential manner using a decision tree structure:

1. **First Level Check (Root Node):** Evaluate if the number of derogatory reports is less than or equal to 1. This determines whether we take the left branch or the right branch of the tree.
2. **Second Level Checks (Child Nodes):**
   - If the first condition is true, check if the individual owns a home.
   - If the first condition is false, check if the individual's income exceeds a certain threshold.

The prediction is made based on these evaluations. Each evaluation step is stored in a list called `nodes` to keep track of the decision-making process.

### Solution Code

    nodes = [None, None]
