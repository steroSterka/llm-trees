```python
def predict(X):
    # Evaluate all node conditions
    nodes = [
        X["aid-to-nicaraguan-contras"] >= 2,   # Node 0: Aid to Nicaraguan contras is yes
        X["mx-missile"] >= 2,                  # Node 1: MX missile is yes
        X["adoption-of-the-budget-resolution"] >= 2  # Node 2: Adoption of budget resolution is yes
    ]

    if nodes[0]:
        prediction = 1
    elif nodes[1]:
        prediction = 1
    else:
        prediction = 0 if nodes[2] else 1

    # Convert boolean values to integers for the nodes list
    nodes_ints = [int(node) for node in nodes]

    return prediction, nodes_ints
```

**Step-by-Step Explanation:**

1. **Node Definitions**: 
   - `nodes[0]` checks if there was a "yes" vote on aid to Nicaraguan contras.
   - `nodes[1]` checks if there was a "yes" vote on the MX missile issue.
   - `nodes[2]` checks if there was a "yes" vote on the adoption of the budget resolution.

2. **Prediction Logic**:
   - If `nodes[0]` is true, predict Republican (1).
   - If `nodes[0]` is false but `nodes[1]` is true, still predict Republican (1).
   - If both `nodes[0]` and `nodes[1]` are false, check `nodes[2]`.
     - If `nodes[2]` is true, predict Democrat (0).
     - Otherwise, default to predicting Republican (1).

3. **Return Values**:
   - The function returns the predicted party affiliation as an integer (0 for Democrat, 1 for Republican).
   - It also returns a list of integers representing whether each node's condition was met (1 if true, 0 otherwise).
