To solve this problem, we need to create a function that predicts whether a political candidate is Republican or Democrat based on their stance on two specific issues: aid to Nicaraguan contras and education spending. The prediction is made using a simple decision tree approach where each node represents a condition check.

### Approach
The approach involves the following steps:
1. **Define Node Conditions**: We have two conditions (nodes) in our decision tree:
   - The first node checks if the candidate supports aid to Nicaraguan contras.
   - The second node checks if the candidate supports increased education spending.
2. **Evaluate Nodes**: Both nodes are evaluated regardless of the branching outcome to ensure consistency with the example provided.
3. **Determine Prediction**: Based on the evaluation of these nodes, we determine whether the candidate is likely to be Republican or Democrat.

### Solution Code
```python
def predict(X: dict) -> tuple:
    # Initialize node conditions
    nodes = [None, None]
    
    # First node: Check if aid-to-nicaraguan-contras is 'yes' (encoded as 2)
    nodes[0] = X["aid-to-nicaraguan-contras"] == 2
    
    # Second node: Check if education-spending is 'yes' (encoded as 2)
    nodes[1] = X["education-spending"] == 2
    
    # Determine prediction based on the decision tree logic
    if nodes[0]:
        prediction = 1  # Republican
    else:
        if nodes[1]:
            prediction = 0  # Democrat
        else:
            prediction = 1  # Republican
    
    # Convert boolean values to integers for the nodes list
    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation
The function `predict` takes a dictionary `X` containing the candidate's stances on various issues. It uses two node conditions to determine the prediction:
- **First Node**: Checks if the candidate supports aid to Nicaraguan contras (encoded as 2 for 'yes'). If true, the prediction is Republican.
- **Second Node**: If the first condition is false, this node checks if the candidate supports increased education spending. If true, the prediction is Democrat; otherwise, it remains Republican.

The function returns a tuple containing the predicted party (1 for Republican, 0 for Democrat) and a list of boolean values indicating the outcome of each node evaluation. This approach ensures that all conditions are evaluated upfront, providing consistent results with the decision tree structure.
