```python
def predict(X: dict) -> tuple[int, list[int]]:
    """
    Predicts the target variable based on the given features using a decision tree.

    Args:
        X (dict): Dictionary containing the feature values with keys as feature names.

    Returns:
        tuple[int, list[int]]: A tuple where the first element is the predicted class (0 for Democrat, 1 for Republican)
                                and the second element is a list of integers representing the evaluation of each inner node's condition.
    """
    aid_to_nicaraguan_contras = X['aid-to-nicaraguan-contras']
    mx_missile = X['mx-missile']
    education_spending = X['education-spending']

    # Evaluate the first inner node condition
    node_0 = (aid_to_nicaraguan_contras == 2)
    
    # Based on the first node, evaluate the second inner node condition
    if node_0:
        node_1 = (mx_missile == 2)
    else:
        node_1 = (education_spending == 2)
    
    nodes = [int(node_0), int(node_1)]
    
    # Determine prediction based on the evaluated conditions
    if node_0:
        prediction = 1 if node_1 else 0
    else:
        prediction = 0 if node_1 else 1
    
    return prediction, nodes
```

- **Function Definition:** The `predict` function takes a dictionary `X` containing feature values and returns a tuple with the predicted class and a list of evaluated inner node conditions.
  
- **Feature Extraction:** Extracts the necessary features from `X` for making predictions based on the decision tree.

- **Inner Node Evaluations:**
  - `node_0`: Checks if aid to Nicaraguan contras is "yes" (2).
  - Based on `node_0`, `node_1` checks either the MX missile stance or education spending, depending on whether `node_0` was true.

- **Nodes List:** Converts boolean evaluations of node conditions into integers (1 for True, 0 for False) and stores them in a list.

- **Prediction Logic:**
  - If both `node_0` and `node_1` are true, predicts Republican (1).
