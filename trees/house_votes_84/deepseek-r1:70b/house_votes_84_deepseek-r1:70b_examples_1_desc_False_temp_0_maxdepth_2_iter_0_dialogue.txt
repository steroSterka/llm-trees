Here's a Python function that predicts party affiliation based on the given decision tree structure:

```python
def predict_party_affiliation(X: dict):
    # List to hold the truth values of inner nodes (2 nodes since max depth is 2)
    nodes = [None, None]
    
    # First node: Vote on MX missile
    mx_missile_vote = X["mx-missile"]
    nodes[0] = mx_missile_vote == 2  # 1 if "yes", else 0
    
    prediction = 0  # Default to Democrat (0)
    
    if nodes[0]:  # If vote on MX missile is "yes"
        aid_to_contras_vote = X["aid-to-nicaraguan-contras"]
        nodes[1] = aid_to_contras_vote == 2
        prediction = 1 if nodes[1] else 0  # Republican if "yes", else Democrat
    else:  # If vote on MX missile is "no"
        religious_groups_in_schools_vote = X["religious-groups-in-schools"]
        nodes[1] = religious_groups_in_schools_vote == 1  # 1 if "no", else 0
        prediction = 0 if nodes[1] else 1
    
    # Convert boolean values in nodes to integers (1 for True, 0 for False)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
```
