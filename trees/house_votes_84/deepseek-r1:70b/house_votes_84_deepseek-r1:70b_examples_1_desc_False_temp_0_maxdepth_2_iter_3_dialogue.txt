Here's a Python function that implements the decision tree for predicting party affiliation based on votes:

```python
def predict(X: dict):
    # Initialize nodes list to store condition evaluations
    nodes = [None, None]
    
    # First node evaluates if vote on MX missile was 'yes' (encoded as 2)
    nodes[0] = X["mx-missile"] == 2
    
    # Second node evaluates if vote on education spending was 'yes' (encoded as 2)
    nodes[1] = X["education-spending"] == 2
    
    # Determine the prediction based on the decision tree logic
    if nodes[0]:
        # If MX missile vote was yes, check El Salvador aid vote
        if X["el-salvador-adi"] == 2:
            prediction = 1  # Republican
        else:
            prediction = 0  # Democrat
    else:
        # If MX missile vote wasn't yes, check education spending vote
        if nodes[1]:
            prediction = 0  # Democrat
        else:
            prediction = 1  # Republican
    
    # Convert boolean values in nodes to integers (True -> 1, False -> 0)
    nodes_as_int = [int(node) for node in nodes]
    
    return prediction, nodes_as_int
```

**Explanation:**

- **Function Definition:** The function `predict` takes a dictionary `X` containing the feature values.
- **Nodes Initialization:** A list `nodes` is initialized to keep track of the evaluation of each inner node condition.
- **First Node Evaluation:** Checks if the vote on the MX missile was 'yes' (encoded as 2).
- **Second Node Evaluation:** Checks if the vote on education spending was 'yes' (encoded as 2).
- **Prediction Logic:**
  - If the first node is true, it further checks the vote on aid to El Salvador.
    - A 'yes' vote here results in a Republican prediction.
    - A 'no' vote results in a Democrat prediction.
  - If the first node is false, it evaluates the second node regarding education spending.
    - A 'yes' vote leads to a Democrat prediction.
    - A 'no' vote results in a Republican prediction.
- **Nodes Conversion:** The boolean values in `nodes` are converted to integers for output consistency.

**Example Usage:**

```python
# Sample input dictionary

    "mx-missile": 2,
    "el-salvador-adi": 1,
    "education-spending": 2
}

```
