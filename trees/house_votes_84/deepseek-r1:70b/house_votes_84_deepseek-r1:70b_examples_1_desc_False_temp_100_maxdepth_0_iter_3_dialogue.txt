To implement the decision tree for predicting party affiliation based on votes, we'll follow a structured approach where each inner node's condition is evaluated and stored. The prediction is then determined by traversing these conditions according to the tree structure.

### Approach
1. **Decision Tree Structure**: The decision tree uses three features sequentially:
   - Vote on aid to Nicaraguan contras (`aid-to-nicaraguan-contras`)
   - Vote on MX missile (`mx-missile`)
   - Vote on education spending (`education-spending`)

2. **Node Evaluation**: Each feature is evaluated in sequence, starting from the root node and moving to the next level only if necessary.

3. **Prediction Logic**:
   - If aid to Nicaraguan contras is approved (yes), predict Republican.
   - If not approved, check MX missile vote; if approved, predict Republican.
   - If neither is approved, check education spending; approval predicts Democrat, otherwise Republican.

4. **Nodes List**: A list of boolean values representing whether each feature condition was met during the prediction path.

### Solution Code
```python
def predict(X: dict):
    nodes = 3 * [None]
    
    # Evaluate all inner node conditions upfront
    nodes[0] = X["aid-to-nicaraguan-contras"] == 2
    nodes[1] = X["mx-missile"] == 2
    nodes[2] = X["education-spending"] == 2
    
    if nodes[0]:
        prediction = 1  # Republican
    else:
        if nodes[1]:
            prediction = 1  # Republican
        else:
            prediction = 0 if nodes[2] else 1  # Democrat if education-spending is yes, otherwise Republican
            
    # Convert boolean values to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
```

### Explanation
- **Node Evaluation**: The function starts by evaluating each feature's condition and stores the results in a list called `nodes`.
- **Prediction Logic**: Using nested conditional checks based on the evaluated nodes, the function determines the predicted party affiliation.
- **Efficiency**: While all inner node conditions are evaluated upfront for simplicity, only necessary nodes influence the prediction path, reflecting an efficient decision tree traversal.

This approach ensures that each feature's condition is captured and used appropriately to determine the final prediction while maintaining clarity and alignment with the decision tree structure.
