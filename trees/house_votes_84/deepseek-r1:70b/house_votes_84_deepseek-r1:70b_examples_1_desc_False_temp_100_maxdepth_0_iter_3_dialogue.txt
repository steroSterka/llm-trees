Here's a Python function that implements the decision tree to predict party affiliation based on the given features:

```python
def predict(X: dict) -> tuple[int, list[int]]:
    # Extract relevant features
    aid_to_nicaraguan_contras = X["aid-to-nicaraguan-contras"]
    religious_groups_in_schools = X["religious-groups-in-schools"]

    # Determine the inner node conditions (True/False)
    nodes = [
        aid_to_nicaraguan_contras == 2,  # Node 0: Aid to Nicaraguan contras is 'yes'?
        religious_groups_in_schools == 2   # Node 1: Religious groups in schools is 'yes'?
    ]

    # Convert conditions to integers (True -> 1, False -> 0)
    nodes_list = [int(condition) for condition in nodes]

    # Predict party affiliation based on the decision tree
    if nodes[0]:
        prediction = 1  # Republican
    else:
        if nodes[1]:
            prediction = 1  # Republican
        else:
            prediction = 0  # Democrat

    return prediction, nodes_list
```

**Explanation:**

- **Feature Extraction:** The function extracts the values of "aid-to-nicaraguan-contras" and "religious-groups-in-schools" from the input dictionary `X`.
  
- **Node Conditions:** It checks if each feature is 'yes' (encoded as 2). These checks are stored in a list called `nodes`.

- **Conversion to Integers:** Each boolean condition in `nodes` is converted to an integer (1 for True, 0 for False) to form `nodes_list`, which represents the truth values of the inner nodes.

- **Prediction Logic:** 
  - If "aid-to-nicaraguan-contras" is 'yes', it predicts Republican (1).
  - Otherwise, it checks "religious-groups-in-schools". If that's 'yes', it also predicts Republican (1); otherwise, it predicts Democrat (0).

This function accurately follows the decision tree logic and returns both the predicted party affiliation and the list of node evaluations.
