Treat “yes” = 1 and “no” = 0, and split on the binary threshold 0.5 (≤ 0.5 → *no*, > 0.5 → *yes*).

```

|--- aid to Nicaraguan contras (yes/no) > 0.5
```

**Interpretation**

- **Root node** – If a legislator **did not** vote for aid to the Nicaraguan Contras, the model classifies the legislator as a **Democrat**.  
- **Right branch** – If the legislator **did** vote for aid to the Contras, the decision depends on the immigration vote:  
  - A **no** vote on immigration → **Republican**.  
  - A **yes** vote on immigration → **Democrat**.

This tree respects the requested maximum depth of 2 and uses the two most informative features for separating the two parties.

```python
def predict(X: dict):

    Returns
    -------
    prediction : int
        0 → Democrat, 1 → Republican
    nodes : list[int]
        Truth values of the two inner nodes (1 = condition satisfied, 0 = not satisfied)
        nodes[0] → (aid‑to‑nicaraguan‑contras == 1)
        nodes[1] → (immigration == 1)   # evaluated only when node 0 is false
    """

    # ---- inner‑node evaluations ------------------------------------------------
    # Node 0 : "aid-to-nicaraguan-contras" == 1  (did NOT vote for aid)
    nodes = [0, 0]                       # placeholder for the two inner nodes
    nodes[0] = 1 if X["aid-to-nicaraguan-contras"] == 1 else 0

    # Node 1 : "immigration" == 1  (voted NO on immigration)
    # This node is only relevant when node 0 is false, but we compute it anyway.
    nodes[1] = 1 if X["immigration"] == 1 else 0

    if nodes[0]:                     # No aid to Nicaraguan Contras → Democrat
        prediction = 0
```
