**Python implementation of the party‑affiliation decision tree**

```python
def predict(X: dict):
    """
    Predict party affiliation (0 = Democrat, 1 = Republican) from the
    16 binary vote features supplied in the problem statement.

    Parameters
    ----------
    X : dict
        Dictionary that contains **exactly** the keys shown below
        (case‑sensitive, hyphens included).  Each vote is encoded as
        2 = *yes* , 1 = *no*.

        Required keys
        -------------
        'handicapped-infants', 'water-project-cost-sharing',
        'adoption-of-the-budget-resolution', 'physician-fee-freeze',
        'el-salvador-adi', 'religious-groups-in-schools',
        'anti-satellite-test-ban', 'aid-to-nicaraguan-contras',
        'mx-missile', 'immigration', 'synfuels-corporation-cutback',
        'education-spending', 'superfund-right-to-sue', 'crime',
        'duty-free-exports',
        'export-administration-act-south-africa'

    Returns
    -------
    prediction : int
        0 → Democrat, 1 → Republican
    nodes      : list[int]
        Truth values (1 = condition satisfied, 0 = not) for each inner
        node of the tree, in the order they are evaluated:
        0 – immigration, 1 – mx‑missile, 2 – aid‑to‑nicaraguan‑contras,
        3 – education‑spending.
    """

    # ------------------------------------------------------------------
    # 1️⃣  Evaluate the inner‑node conditions (store 1/0 for the output list)
    # ------------------------------------------------------------------
    nodes = [None] * 4                     # four inner nodes
    nodes[0] = 1 if X['immigration'] == 2 else 0
    nodes[1] = 1 if X['mx-missile'] == 2 else 0
    nodes[2] = 1 if X['aid-to-nicaraguan-contras'] == 2 else 0
    nodes[3] = 1 if X['education-spending'] == 2 else 0

    # ------------------------------------------------------------------
    # 2️⃣  Follow the tree to obtain the prediction
    # ------------------------------------------------------------------
    if X['immigration'] == 2:               # immigration = Yes
        prediction = 0                       # Democrat
    else:                                   # immigration = No
        if X['mx-missile'] == 2:             # mx‑missile = Yes
            prediction = 1                   # Republican
        else:                               # mx‑missile = No
            if X['aid-to-nicaraguan-contras'] == 2:   # Contras = Yes
                prediction = 1               # Republican
            else:                           # Contras = No
                if X['education-spending'] == 2:      # Education = Yes
                    prediction = 0           # Democrat
                else:                       # Education = No
                    prediction = 1           # Republican

    return prediction, nodes
```

### How the function works

| Node index | Feature (condition)                              | Meaning of `1` in `nodes` |
|------------|--------------------------------------------------|---------------------------|
| 0          | `immigration == 2` (vote **Yes**)                | The legislator voted *yes* on immigration |
| 1          | `mx-missile == 2` (vote **Yes**)                 | The legislator voted *yes* on the MX‑missile |
| 2          | `aid-to-nicaraguan-contras == 2` (vote **Yes**)  | The legislator voted *yes* on funding the Contras |
| 3          | `education-spending == 2` (vote **Yes**)        | The legislator voted *yes* on increasing education spending |

The tree’s logic (written in plain English) is:

1. **Immigration = Yes** → Democrat  
2. **Immigration = No** and **MX‑missile = Yes** → Republican  
3. **Immigration = No**, **MX‑missile = No**, **Aid‑to‑Contras = Yes** → Republican  
4. **Immigration = No**, **MX‑missile = No**, **Aid‑to‑Contras = No**, **Education‑spending = Yes** → Democrat  
5. All other combinations → Republican  

The function returns both the party prediction (`0` = Democrat, `1` = Republican) and the list `nodes` that records which inner‑node conditions were satisfied for the given input record.
