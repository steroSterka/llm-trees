```python
def predict(X: dict):
    nodes = 2 * [None]
    nodes[0] = X['EBIT/TA'] <= 0.05
    nodes[1] = X['Equity/TL'] <= 1.20
    
    if not nodes[0]:
        prediction = 1 if not nodes[1] else 0
    else:
        prediction = 0

    return int(prediction), [int(node) for node in nodes]
```

*   The first node checks if the value of 'EBIT/TA' (Earnings Before Interest and Taxes/Total Assets) is less than or equal to 0.05.
