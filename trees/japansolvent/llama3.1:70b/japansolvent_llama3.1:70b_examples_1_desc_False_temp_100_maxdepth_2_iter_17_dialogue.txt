```python
def predict(X: dict):
    nodes = 2 * [None]
    
    # Determine threshold values based on feature description and domain knowledge
    ebit_ta_threshold = 0.12
    ni_tc_threshold = 0.20
    
    nodes[0] = X["EBIT/TA"] <= ebit_ta_threshold
    nodes[1] = X["NI/TC"] <= ni_tc_threshold
    
    if not nodes[0]:
        prediction = 0  # insolvent
    else:
        if nodes[1]:
            prediction = 1  # solvent
        else:
            prediction = 1  # solvent

    return prediction, [int(node) for node in nodes]
```

In this function:

*   We first define the threshold values based on feature description and domain knowledge.
*   Then we evaluate the conditions at each inner node using these thresholds.
*   Finally, we determine the prediction based on the truth values of the inner nodes.
