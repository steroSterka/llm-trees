```python
def predict(X: dict):
    nodes = 2 * [None]
    nodes[0] = X["Equity/TL"] <= 1.5
    nodes[1] = X["WC/TA"] <= 0.10
    
    if nodes[0]:
        prediction = 0  # Insolvent

            prediction = 1  # Solvent

    return prediction, nodes
```

The decision tree has two inner nodes:

* The first node checks if the equity-to-liability ratio (`Equity/TL`) is less than or equal to 1.5. If this condition is true, the company is considered insolvent.
* The second node checks if the working capital-to-total assets ratio (`WC/TA`) is less than or equal to 0.10. If this condition is true and the first node was false, the company is also considered insolvent.
