* If the Equity/TL ratio is low (<= 1.50), the next split is based on Working Capital/Total Assets, which measures the company's liquidity. If this ratio is low (<= 0.20), the company is more likely to be insolvent.

def predict(X: dict):

    nodes[1] = X["Equity/TL"] <= 1.50
    nodes[2] = X["WC/TA"] <= 0.20

    if not nodes[0]:
        prediction = 1  # Solvent
    else:
        if not nodes[1]:
            prediction = 1  # Solvent
        else:

                prediction = 1  # Solvent
