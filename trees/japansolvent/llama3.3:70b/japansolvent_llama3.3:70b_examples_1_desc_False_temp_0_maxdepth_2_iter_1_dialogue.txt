The function `predict_solvency` takes a dictionary `X` containing the financial features of a company and returns a tuple where the first element is the predicted solvency status (1 = solvent, 0 = insolvent) and the second element is a list representing the truth values of the inner nodes.

```python
def predict_solvency(X: dict):
    """
    Predicts whether a company is solvent or not based on its financial ratios.
    
    Parameters:
    X (dict): A dictionary containing the financial features of the company.
              The keys should match the feature names exactly, including case and spacing.
              Required keys: 'EBIT/TA', 'Equity/TL'
              
    Returns:
    tuple: A tuple where the first element is the predicted solvency status (1 = solvent, 0 = insolvent)
           and the second element is a list representing the truth values of the inner nodes.
    """
    
    # Initialize nodes with None
    nodes = 2 * [None]
    
    # First split: EBIT/TA <= 0.10
    nodes[0] = X['EBIT/TA'] <= 0.10
    
    # Second split, conditional on the first: Equity/TL <= 1.00
    if not nodes[0]:  # If EBIT/TA > 0.10
        nodes[1] = X['Equity/TL'] <= 1.00
    else:
        nodes[1] = False  # This node is only relevant when the first condition is false
    
    # Prediction logic
    if nodes[0]:  # EBIT/TA <= 0.10, company likely insolvent
        prediction = 0
    else:  # EBIT/TA > 0.10
        if nodes[1]:  # Equity/TL <= 1.00, company might be insolvent due to high leverage
            prediction = 0
        else:  # Equity/TL > 1.00, company likely solvent with good profitability and leverage position
            prediction = 1
    
    # Convert boolean nodes to integers (True -> 1, False -> 0)
    node_values = [int(node) for node in nodes]
    
    return prediction, node_values

# Example usage:
```
