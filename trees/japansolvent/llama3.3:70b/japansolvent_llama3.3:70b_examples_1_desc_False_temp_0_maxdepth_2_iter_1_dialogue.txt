```python
def predict(X: dict):
    """
    Predicts whether a company is solvent or not based on its financial features.

    Parameters:
    X (dict): A dictionary containing the company's financial features.
              The keys should include 'EBIT/TA', 'NI/TC', 'Sales/TA', 
              'EBIT/Sales', 'NI/Sales', 'WC/TA', 'Equity/TL', and 'Equity/TA'.

    Returns:
    prediction (int): 1 if the company is predicted to be solvent, 0 otherwise.
    nodes (list): A list of boolean values representing the truth values of the inner nodes.
                  The first element corresponds to the condition EBIT/TA <= 0.05,
                  and the second element corresponds to the condition Equity/TL <= 1.5.
    """
    nodes = 2 * [None]
    # Check if EBIT/TA is less than or equal to 0.05
    nodes[0] = X['EBIT/TA'] <= 0.05
    
    # If the company has low profitability, check its debt-to-equity ratio
    if nodes[0]:
        # Check if Equity/TL is less than or equal to 1.5
        nodes[1] = X['Equity/TL'] <= 1.5
        
        # If both conditions are met, the company is likely insolvent
        prediction = 0
    else:
        # If the company has higher profitability, check its debt-to-equity ratio
        nodes[1] = X['Equity/TL'] <= 1.5
        
        # If the debt-to-equity ratio is not met but EBIT/TA is high, the company might still be insolvent
        if nodes[1]:
            prediction = 0
        else:
            # Otherwise, the company is likely solvent
            prediction = 1

    return prediction, [int(node) for node in nodes]
```

This function takes a dictionary `X` containing the company's financial features and returns a tuple where the first element is the prediction (1 if the company is predicted to be solvent, 0 otherwise) and the second element is a list of boolean values representing the truth values of the inner nodes. The `nodes` list contains two elements: the first corresponds to the condition `EBIT/TA <= 0.05`, and the second corresponds to the condition `Equity/TL <= 1.5`.
