```python
def predict_solvency(X: dict):
    """
    Predicts whether a company is solvent or not based on its financial features.
    
    Parameters:
    X (dict): A dictionary containing the financial features of the company.
              The keys should match the feature names exactly, including case and spacing.
              The required features are:
              - EBIT/TA
              - NI/TC
              - Equity/TL
    
    Returns:
    tuple: A tuple containing the prediction (1 for solvent, 0 for insolvent) and a list of truth values for the inner nodes.
    """

    # Initialize the list to store the truth values of the inner nodes
    nodes = 2 * [None]

    # Node 0 condition: EBIT/TA > 0.10
    nodes[0] = X['EBIT/TA'] > 0.10

    if nodes[0]:
        # If EBIT/TA is high, check NI/TC for further confirmation of solvency
        nodes[1] = X['NI/TC'] > 0.15
        prediction = 1  # Default to solvent unless conditions suggest otherwise
    else:
        # If EBIT/TA is low, check Equity/TL for leverage and potential insolvency
        nodes[1] = X['Equity/TL'] > 1.00
        if nodes[1]:
            prediction = 1  # Company has good equity to liability ratio, likely solvent
        else:
            prediction = 0  # Company has high leverage, likely insolvent

    return prediction, [int(node) for node in nodes]
```

This function takes a dictionary `X` containing the financial features of a company and returns a tuple. The first element of the tuple is the prediction (1 if the company is predicted to be solvent, 0 otherwise), and the second element is a list where each element corresponds to the truth value of an inner node in the decision tree, with 1 indicating the condition was met and 0 indicating it was not.
