```python
def predict_solvent(X: dict):
    """
    Predicts whether a company is solvent based on its financial metrics.
    
    Parameters:
    X (dict): A dictionary containing the company's financial metrics, including
             'EBIT/TA', 'NI/TC', 'Sales/TA', 'EBIT/Sales', 'NI/Sales', 
             'WC/TA', 'Equity/TL', and 'Equity/TA'.
    
    Returns:
    prediction (int): 1 if the company is predicted to be solvent, 0 otherwise.
    nodes (list): A list of boolean values representing the truth values of the inner nodes.
    """
    nodes = 2 * [None]
    nodes[0] = X["EBIT/TA"] > 0.05  # Threshold for EBIT/TA
    nodes[1] = X["Equity/TL"] > 1.00  # Threshold for Equity/TL
    
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Solvent
        else:
            prediction = 0  # Insolvent due to high leverage
    else:
        prediction = 0  # Insolvent due to poor profitability
    
    return int(prediction), [int(node) for node in nodes]

# Example usage:
company_metrics = {
    "EBIT/TA": 0.08,
    "NI/TC": 0.10,
    "Sales/TA": 1.20,
    "EBIT/Sales": 0.07,
    "NI/Sales": 0.05,
    "WC/TA": 0.15,
    "Equity/TL": 1.50,
    "Equity/TA": 0.60
}

prediction, nodes = predict_solvent(company_metrics)
print("Prediction:", prediction)
print("Nodes:", nodes)

```

In this function, the decision tree first checks if the company's `EBIT/TA` ratio is greater than 0.05. If it is, then it proceeds to check if the company's `Equity/TL` ratio is greater than 1.00.
