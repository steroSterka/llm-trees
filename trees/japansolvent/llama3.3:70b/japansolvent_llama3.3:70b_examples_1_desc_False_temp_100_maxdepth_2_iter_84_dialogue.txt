**Feature Selection**:
- **EBIT/TA**: Reflects a company's profitability in relation to its asset base.
- **E/TL**: Indicates a company's leverage and ability to meet long-term obligations.
- **WC/TA**: Represents a company's liquidity and ability to meet short-term obligations.

These three features provide a comprehensive view of a company's financial health: profitability (EBIT/TA), solvency in terms of leverage (E/TL), and liquidity (WC/TA).

**Decision Tree Construction**:
With a maximum depth of 2, our tree will have one primary decision node at the first level and up to two secondary decision nodes at the second level. We'll use the most critical feature for the first split.

1. **First Split**: Use **E/TL (Equity/Total Liabilities)** as it directly reflects a company's ability to cover its debts, which is crucial for solvency.
   - **Condition**: E/TL > 1 indicates that equity exceeds liabilities, suggesting good financial health and likely solvency.
   - **Class**: Solvent

2. For companies where E/TL <= 1:
   - **Second Split**: Use **WC/TA (Working Capital/Total Assets)** to assess liquidity, which is vital for meeting short-term obligations.
     - **Condition**: WC/TA > 0.20 (as an example threshold) could indicate sufficient liquidity to cover immediate debts.
     - **Class**: Solvent
   - If WC/TA <= 0.20:
     - **Class**: Insolvent, due to potential liquidity issues.

**Decision Tree**:
```
|--- E/TL > 1
||--- class: Solvent
|--- E/TL <= 1
||--- WC/TA > 0.20
|||--- class: Solvent
||--- WC/TA <= 0.20
|||--- class: Insolvent
```

This decision tree provides a simple, interpretable model for predicting company solvency based on financial health indicators. The thresholds used (e.g., E/TL > 1, WC/TA > 0.20) are examples and may need adjustment based on specific industry norms or further analysis of the dataset.

```python
def predict(X: dict):
    """
    Predicts whether a company is solvent or not based on its financial features.

    Parameters:
    X (dict): A dictionary containing the company's financial features.
              The keys are 'EBIT/TA', 'NI/TC', 'Sales/TA', 'EBIT/Sales',
              'NI/Sales', 'WC/TA', 'Equity/TL', and 'Equity/TA'.

    Returns:
    prediction (int): 1 if the company is predicted to be solvent, 0 otherwise.
    nodes (list): A list of boolean values representing the conditions at each inner node.
                  The first element corresponds to the condition E/TL > 1,
                  and the second element corresponds to the condition WC/TA > 0.20.
    """

    # Initialize the list to store the truth values of the inner nodes
    nodes = 2 * [None]

    # First split: E/TL > 1
    nodes[0] = X['Equity/TL'] > 1

    # If the first condition is met, predict the company as solvent
    if nodes[0]:
        prediction = 1
        # Since we've already predicted the company as solvent,
        # we don't need to check the second condition
        nodes[1] = None
    else:
        # Second split: WC/TA > 0.20
        nodes[1] = X['WC/TA'] > 0.20

        # Predict based on the second condition
        if nodes[1]:
            prediction = 1
        else:
            prediction = 0

    return prediction, [int(nodes[0]), int(nodes[1]) if nodes[1] is not None else 0]
```

In this function, we first check if the company's equity-to-liabilities ratio (`Equity/TL`) is greater than 1. If it is, we predict the company as solvent and set the second node to `None`, since we don't need to check the second condition.

If the first condition is not met, we then check the working capital-to-total assets ratio (`WC/TA`). If this ratio is greater than 0.20, we predict the company as solvent; otherwise, we predict it as insolvent.

The function returns a tuple containing the predicted solvency (1 for solvent or 0 for insolvent) and a list of boolean values representing the conditions at each inner node. The `int()` function is used to convert the boolean values to integers (1 for `True` and 0 for `False`). If the second node is `None`, we replace it with 0 to maintain consistency in the output format.
