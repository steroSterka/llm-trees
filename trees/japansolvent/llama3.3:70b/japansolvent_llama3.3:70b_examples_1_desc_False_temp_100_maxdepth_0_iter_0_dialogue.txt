This function takes in a dictionary `X` containing the feature values and returns a tuple with the predicted class (0 for insolvent, 1 for solvent) and a list representing the truth values of the inner nodes.

```python
def predict_solvency(X: dict):
    """
    Predicts whether a company is solvent or not based on financial features.
    
    Parameters:
    X (dict): A dictionary containing the feature values.
        - 'EBIT/TA': Earnings Before Interest and Taxes/Total Assets
        - 'NI/TC': Net Income/Total Capital
        - 'Sales/TA': Sales/Total Assets
        - 'EBIT/Sales': Earnings Before Interest and Taxes/Sales
        - 'NI/Sales': Net Income/Sales
        - 'WC/TA': Working Capital/Total Assets
        - 'Equity/TL': Equity/Total Liabilities
        - 'Equity/TA': Equity/Total Assets
    
    Returns:
    tuple: A tuple containing the predicted class (0 for insolvent, 1 for solvent) and a list representing the truth values of the inner nodes.
    """

    # Initialize the list to store the truth values of the inner nodes
    nodes = [None] * 4

    # Node 0: Equity/Total Liabilities > 1.0
    nodes[0] = X['Equity/TL'] > 1.0
    
    # Node 1: EBIT/Total Assets > 0.10 (given that Equity/Total Liabilities > 1.0)
    nodes[1] = X['EBIT/TA'] > 0.10 if nodes[0] else False
    
    # Node 2: Working Capital/Total Assets > 0.20 (given that EBIT/Total Assets > 0.10)
    nodes[2] = X['WC/TA'] > 0.20 if nodes[1] else False
    
    # Node 3: Net Income/Sales >= 0.05 (given that Working Capital/Total Assets > 0.20)
    nodes[3] = X['NI/Sales'] >= 0.05 if nodes[2] else False

    # Convert boolean values in the nodes list to integers (1 for True, 0 for False)
    nodes = [int(node) if node is not None else None for node in nodes]

    # Predicted class based on the decision tree
    prediction = 1 if all([node == 1 for node in nodes if node is not None]) else 0

    return prediction, nodes
```
