- **Earnings Before Interest and Taxes/Total Assets (EBIT/TA)** measures profitability from operations relative to total assets. Low values might suggest inefficiency in asset utilization, potentially leading to insolvency.
- **Working Capital/Total Assets (WC/TA)** reflects the liquidity position of a company. A higher ratio suggests better liquidity and ability to meet short-term obligations, indicating solvency.
- **Net Income/Sales (NI/S)** indicates profitability from sales. Even with sufficient working capital, low or negative profitability could signal underlying issues leading towards insolvency.

def predict(X: dict):
    """
    Predicts whether a company is solvent (1) or insolvent (0) based on financial features.
    
    Parameters:
    X (dict): Dictionary containing the financial features of the company.
        - EBIT/TA: Earnings Before Interest and Taxes/Total Assets
        - NI/TC: Net Income/Total Capital
        - Sales/TA: Sales/Total Assets
        - EBIT/Sales: Earnings Before Interest and Taxes/Sales
        - NI/Sales: Net Income/Sales
        - WC/TA: Working Capital/Total Assets
        - Equity/TL: Equity/Total Liabilities
        - Equity/TA: Equity/Total Assets
    
    Returns:
    prediction (int): 1 if the company is predicted to be solvent, 0 otherwise.
    nodes (list): List of boolean values representing the truth values of the inner nodes in the decision tree.
    """
    
    # Initialize the list to store the truth values of the inner nodes
    nodes = [None] * 4
    
    # Check if Equity/Total Liabilities is greater than 1.0
    nodes[0] = X['Equity/TL'] > 1.0
    
    # If Equity/TL is greater than 1.0, check EBIT/TA
    nodes[1] = X['EBIT/TA'] > 0.05 if nodes[0] else None
    
    # Check Working Capital/Total Assets if previous conditions are met
    nodes[2] = X['WC/TA'] >= 0.2 if nodes[0] and nodes[1] else None
    
    # Check Net Income/Sales if previous conditions are partially met
    nodes[3] = X['NI/Sales'] >= 0.01 if (nodes[0] and not nodes[1]) or (nodes[0] and nodes[1] and not nodes[2]) else None
    
    # Determine the prediction based on the node values
    if nodes[0]:
        if nodes[1]:
            if nodes[2]:
                prediction = 1  # Solvent
            else:
                if nodes[3]:
                    prediction = 1  # Solvent
                else:
                    prediction = 0  # Insolvent
        else:
            if nodes[3]:
                prediction = 1  # Solvent
            else:
                prediction = 0  # Insolvent
    else:
        prediction = 0  # Insolvent
    
    # Convert boolean values to integers (1 for True, 0 for False) in the nodes list
    nodes = [int(node) if node is not None else None for node in nodes]
    
    return prediction, nodes
