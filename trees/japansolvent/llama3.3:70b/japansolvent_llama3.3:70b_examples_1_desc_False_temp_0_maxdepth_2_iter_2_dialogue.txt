### Feature Importance

In financial analysis:
- **Earnings Before Interest and Taxes/Total Assets (EBIT/TA)**: Reflects a company's profitability from its assets.
- **Net Income/Total Capital**: Indicates how well a company utilizes its capital to generate profits.
- **Equity/Total Liabilities**: A higher ratio suggests lower debt and greater financial stability.

These three features are often critical in assessing a company's solvency because they directly relate to profitability, efficiency of capital use, and leverage (debt levels).

### Decision Tree Construction

Let's construct a decision tree with a maximum depth of 2, using the selected features:

1. **Root Node**: Equity/Total Liabilities
   - This ratio is crucial for initial assessment as it reflects the company's ability to meet its long-term obligations.

2. **First Level**:
   - **Equity/Total Liabilities <= 1.0**
     - Indicates higher debt levels compared to equity, potentially suggesting financial stress.
       - **Second Level (Depth 2)**: EBIT/TA
         - **EBIT/TA > 0.10**: Suggests the company is generating sufficient profit from its assets to potentially service its debt and invest in growth, indicating solvency.
         - **EBIT/TA <= 0.10**: Indicates low profitability, which could compromise the company's ability to meet its obligations, suggesting insolvency.
   - **Equity/Total Liabilities > 1.0**
     - Suggests a healthier balance sheet with more equity than debt.
       - **Second Level (Depth 2)**: Net Income/Total Capital
         - **Net Income/Total Capital > 0.20**: Indicates efficient use of capital to generate profits, supporting solvency.
         - **Net Income/Total Capital <= 0.20**: May suggest underperformance in utilizing capital for generating income, potentially indicating a need for improvement but not necessarily insolvency.

|--- Equity/Total Liabilities <= 1.0
||--- EBIT/TA > 0.10: Solvent

```python
def predict(X: dict):
    """
    Predicts whether a company is solvent or not based on its financial health indicators.
    
    Parameters:
    X (dict): A dictionary containing the financial features of the company.
        - 'EBIT/TA': Earnings Before Interest and Taxes/Total Assets
        - 'NI/TC': Net Income/Total Capital
        - 'Sales/TA': Sales/Total Assets
        - 'EBIT/Sales': Earnings Before Interest and Taxes/Sales
        - 'NI/Sales': Net Income/Sales
        - 'WC/TA': Working Capital/Total Assets
        - 'Equity/TL': Equity/Total Liabilities
        - 'Equity/TA': Equity/Total Assets
    
    Returns:
    prediction (int): A binary value indicating whether the company is solvent (1) or not (0).
    nodes (list): A list of boolean values representing the truth values of the inner nodes.
    """

    # Initialize the nodes with None
    nodes = 2 * [None]

    # First node: Equity/Total Liabilities <= 1.5
    nodes[0] = X['Equity/TL'] <= 1.5
    
    # Second node (under first node): EBIT/TA > 0.05 if first node is True, otherwise Net Income/Total Capital > 0.10
    if nodes[0]:
        nodes[1] = X['EBIT/TA'] > 0.05
    else:
        nodes[1] = X['NI/TC'] > 0.10

    # Prediction based on the nodes
    if not nodes[0]:  # If Equity/TL > 1.5, check NI/TC
        prediction = int(nodes[1])  # Solvent if NI/TC > 0.10, otherwise insolvent
    else:  # If Equity/TL <= 1.5, check EBIT/TA
        prediction = int(not nodes[1])  # Insolvent if EBIT/TA <= 0.05, otherwise solvent

    # Convert boolean values in nodes to integers (1 for True, 0 for False)
    nodes = [int(node) for node in nodes]

    return prediction, nodes
```
