```python
def predict(X: dict):
    """
    Predicts whether a company is solvent or not based on its financial features.
    
    Parameters:
    X (dict): Dictionary containing the financial features of the company.
        - EBIT/TA: Earnings Before Interest and Taxes/Total Assets
        - NI/TC: Net Income/Total Capital
        - Sales/TA: Sales/Total Assets
        - EBIT/Sales: Earnings Before Interest and Taxes/Sales
        - NI/Sales: Net Income/Sales
        - WC/TA: Working Capital/Total Assets
        - Equity/TL: Equity/Total Liabilities
        - Equity/TA: Equity/Total Assets
    
    Returns:
    prediction (int): 1 if the company is predicted to be solvent, 0 otherwise.
    nodes (list): List of boolean values representing the truth values of the inner nodes in the decision tree.
    """

    # Initialize the list to store the truth values of the inner nodes
    nodes = 2 * [None]
    
    # First node: Check if EBIT/TA is greater than 0.10
    nodes[0] = X["EBIT/TA"] > 0.10
    
    # Second node (under the first node): Check if Equity/TL is greater than 1.00
    # This condition is only relevant if the first node's condition is True
    if nodes[0]:
        nodes[1] = X["Equity/TL"] > 1.00
    else:
        # If the first node's condition is False, then we check Sales/TA under the second branch
        nodes[1] = X["Sales/TA"] > 1.50
    
    # Make the prediction based on the nodes' conditions
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Solvent: High EBIT/TA and low leverage (Equity/TL > 1)
        else:
            prediction = 0  # Insolvent: Despite high EBIT/TA, high leverage poses risk
    else:
        if nodes[1]:
            prediction = 1  # Potentially Solvent: Low EBIT/TA but efficient asset use (Sales/TA > 1.50)
        else:
            prediction = 0  # Insolvent: Low EBIT/TA and inefficient asset use
    
    return prediction, [int(node) for node in nodes]

# Example usage
X = {
    "EBIT/TA": 0.12,
    "NI/TC": 0.20,
    "Sales/TA": 1.80,
    "EBIT/Sales": 0.10,
    "NI/Sales": 0.05,
    "WC/TA": 0.30,
    "Equity/TL": 1.20,
    "Equity/TA": 0.60
}

prediction, nodes = predict(X)
print(f"Prediction: {prediction}")

```

This code implements a decision tree with two inner nodes based on the `EBIT/TA` and either `Equity/TL` (if `EBIT/TA` is high) or `Sales/TA` (if `EBIT/TA` is low). The prediction and the truth values of the inner nodes are returned.
