```python
def predict(X: dict):
    """
    Decision Tree Classifier to predict whether a company is solvent or not.

    Parameters:
    X (dict): Dictionary containing the financial features of the company.
             Keys: 'EBIT/TA', 'NI/TC', 'Sales/TA', 'EBIT/Sales', 'NI/Sales',
                   'WC/TA', 'Equity/TL', 'Equity/TA'

    Returns:
    prediction (int): 1 if the company is predicted to be solvent, 0 otherwise.
    nodes (list): List of boolean values representing the conditions at each inner node.
                  1 if the condition is satisfied, 0 otherwise.
    """

    # Initialize the list to store the truth values of the inner nodes
    nodes = 2 * [None]

    # First inner node: EBIT/TA <= 0.05 (Threshold chosen based on general financial analysis principles)
    nodes[0] = X['EBIT/TA'] <= 0.05

    # Second inner node: Equity/TL <= 1.0 (Threshold chosen to distinguish between high and low leverage)
    if not nodes[0]:
        nodes[1] = X['Equity/TL'] <= 1.0
    else:
        nodes[1] = False  # This value won't be used but is set for consistency

    # Prediction based on the decision tree
    if nodes[0]:  # Low profitability, likely insolvent
        prediction = 0
    else:  # Profitable, check leverage
        if nodes[1]:  # High leverage, high risk but still solvent
            prediction = 1
        else:  # Healthy leverage, low risk and solvent
            prediction = 1

    return prediction, [int(node) for node in nodes]
```

This function implements a decision tree classifier with two inner nodes. The first node checks the company's profitability (EBIT/TA), and if it's below a certain threshold (0.05 in this case), the company is predicted to be insolvent. If the company is profitable, the second node checks its leverage (Equity/TL) to further assess its solvency.

The function returns both the prediction (1 for solvent, 0 for insolvent) and a list representing the truth values of the inner nodes (1 if the condition is satisfied, 0 otherwise). The `int(node)` conversion is used to convert boolean values to integers.
