Here's a step-by-step explanation of how the Python function works:

1. **Feature Mapping**: The function uses specific financial features to evaluate solvency:
   - `Equity/TL` (Equity/Total Liabilities)
   - `EBIT/TA` (Earnings Before Interest and Taxes/Total Assets)
   - `NI/Sales` (Net Income/Sales)

2. **Decision Tree Logic**:
   - First, check if `Equity/TL` is less than or equal to 1.50.
     - If true, evaluate `EBIT/TA` against the threshold of 0.15.
       - Above or equal to 0.15: Company is solvent (returns 1).
       - Below 0.15: Company is insolvent (returns 0).
   - If `Equity/TL` is greater than 1.50, evaluate `NI/Sales` against the threshold of 0.05.
     - Above or equal to 0.05: Company is solvent (returns 1).
     - Below 0.05: Company is insolvent (returns 0).

3. **Node Tracking**: Each condition check is recorded in a list (`nodes`) where:
   - `True` conditions are represented by `1`.
   - `False` conditions are represented by `0`.

4. **Function Output**: The function returns both the prediction (1 for solvent, 0 for insolvent) and the nodes list indicating the evaluation path through the decision tree.

```python
def predict(X: dict):
    nodes = [None] * 3  # Initialize a list to store the truth values of the inner nodes
    
    # First condition: Equity/Total Liabilities <= 1.50
    nodes[0] = X['Equity/TL'] <= 1.50
    
    if nodes[0]:
        # Second condition: EBIT/TA >= 0.15
        nodes[1] = X['EBIT/TA'] >= 0.15
        
        if nodes[1]:
            prediction = 1  # Solvent
        else:
            prediction = 0  # Insolvent
    else:
        # Third condition: Net Income/Sales >= 0.05
        nodes[2] = X['NI/Sales'] >= 0.05
        
        if nodes[2]:
            prediction = 1  # Solvent
        else:
            prediction = 0  # Insolvent
    
    # Convert boolean values in nodes to 1 (True) or 0 (False)
    nodes = [1 if node else 0 for node in nodes]
    
    return prediction, nodes
```
