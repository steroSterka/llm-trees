To solve this problem, we need to create a Python function that predicts whether a company is solvent or insolvent based on specific financial features. The function should return both a prediction and a list of boolean values indicating the evaluation path taken through the decision tree.

### Approach
The approach involves constructing a decision tree using three key financial ratios to determine solvency:
1. **Equity/Total Liabilities (Equity/TL):** This ratio assesses the company's leverage. A higher value indicates better solvency.
2. **Earnings Before Interest and Taxes/Total Assets (EBIT/TA):** This measures the profitability generated from assets.
3. **Net Income/Sales (NI/Sales):** This evaluates the profitability relative to sales.

The decision tree follows these steps:
1. Check if Equity/TL > 0.5. If true, the company is solvent.
2. If not, check if EBIT/TA > 0.10. If true, the company is solvent.
3. If neither condition is met, check if NI/Sales > 0.05 to determine solvency.

### Solution Code

```python
def predict(X: dict):
    nodes = [False] * 3  # Initialize all inner node evaluations to False
    
    # First inner node evaluation: Equity/Total Liabilities > 0.5
    nodes[0] = X['Equity/TL'] > 0.5
    if nodes[0]:
        prediction = 1
    else:
        # Second inner node evaluation: EBIT/TA > 0.10
        nodes[1] = X['EBIT/TA'] > 0.10
        if nodes[1]:
            prediction = 1
        else:
            # Third inner node evaluation: NI/Sales > 0.05
            nodes[2] = X['NI/Sales'] > 0.05
            prediction = 1 if nodes[2] else 0
    
    # Convert boolean values to integers (True -> 1, False -> 0)
    nodes_as_int = [int(node) for node in nodes]
    
    return prediction, nodes_as_int
```

### Explanation
The function `predict` takes a dictionary `X` containing financial features of a company. It evaluates the solvency based on a decision tree with three inner nodes:

1. **Equity/TL > 0.5:** Indicates if the company's equity exceeds half of its total liabilities.
2. **EBIT/TA > 0.10:** Measures asset efficiency in generating earnings before interest and taxes.
3. **NI/Sales > 0.05:** Assesses profitability relative to sales.

Each condition is evaluated in sequence, storing whether each node's condition was met (True or False). The function returns a prediction (1 for solvent, 0 for insolvent) and a list of integers representing the evaluation path through the decision tree nodes. This structured approach ensures that each critical aspect of solvency is assessed efficiently.
