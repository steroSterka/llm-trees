To solve this problem, we need to classify a company as solvent or insolvent based on three financial metrics using a decision tree approach. The classification is determined by evaluating specific thresholds for these metrics in a predefined order.

### Approach
The solution involves evaluating three key financial metrics in sequence:
1. **EBIT/TA (Earnings Before Interest and Taxes divided by Total Assets):** If this metric exceeds 0.10, the company is classified as solvent.
2. **Equity/TL (Equity divided by Total Liabilities):** If EBIT/TA does not exceed 0.10 but Equity/TL exceeds 1.00, the company is classified as solvent.
3. **NI/Sales (Net Income divided by Sales):** If neither of the previous conditions are met but NI/Sales exceeds 0.05, the company is classified as solvent.

If none of these conditions are met, the company is classified as insolvent.

### Solution Code
```python
def predict(X: dict) -> tuple:
    # Initialize nodes with None values
    nodes = [None] * 3
    
    # Node 0: Check if EBIT/TA exceeds 0.10
    ebit_ta = X['EBIT/TA']
    nodes[0] = ebit_ta > 0.10
    
    # Node 1: Check if Equity/TL exceeds 1.00
    equity_tl = X['Equity/TL']
    nodes[1] = equity_tl > 1.00
    
    # Node 2: Check if NI/Sales exceeds 0.05
    ni_sales = X['NI/Sales']
    nodes[2] = ni_sales > 0.05
    
    # Convert boolean values to integers for the nodes list
    nodes = [int(node) for node in nodes]
    
    # Determine the prediction based on the decision tree logic
    if nodes[0]:
        prediction = 1
    else:
        if nodes[1]:
            prediction = 1
        else:
            if nodes[2]:
                prediction = 1
            else:
                prediction = 0
    
    return prediction, nodes
```

### Explanation
The function `predict` takes a dictionary `X` containing the financial metrics of a company. It evaluates each metric against predefined thresholds in a specific order to determine solvency:

1. **EBIT/TA Check:** The first check determines if EBIT/TA is greater than 0.10. If true, the company is solvent.
2. **Equity/TL Check:** If the first condition fails, the function checks if Equity/TL exceeds 1.00. If true, the company is solvent.
3. **NI/Sales Check:** If both previous conditions fail, the function checks if NI/Sales exceeds 0.05. If true, the company is solvent.

Each condition's result is stored in a list `nodes` as boolean values, which are then converted to integers (1 for True, 0 for False) before returning along with the final prediction (1 for solvent, 0 for insolvent).

This approach ensures that each financial metric is evaluated in sequence, and the company is classified based on the first condition met, providing a clear and efficient decision-making process.
