To solve this problem, we need to determine if an investment should be recommended based on specific financial metrics. The decision is made by evaluating these metrics in a hierarchical manner, using predefined thresholds.

### Approach
The approach involves evaluating three key financial metrics in sequence:
1. **Equity-to-Total Assets Ratio (Equity/TA):** If this ratio exceeds 0.50, the investment is recommended.
2. **Equity-to-Total Liabilities Ratio (Equity/TL):** If the first condition is not met, we check if this ratio exceeds 1.00.
3. **Working Capital-to-Total Assets Ratio (WC/TA):** If neither of the above conditions are met, we check if this ratio exceeds 0.20.

The process stops as soon as a condition is satisfied, ensuring that each subsequent condition is only evaluated if necessary. This approach ensures efficiency by minimizing the number of evaluations needed to reach a decision.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    nodes = [False, False, False]
    
    # Check first condition
    if X['Equity/TA'] > 0.50:
        nodes[0] = True
        prediction = 1
    else:
        # Check second condition
        if X['Equity/TL'] > 1.00:
            nodes[1] = True
            prediction = 1
        else:
            # Check third condition
            if X['WC/TA'] > 0.20:
                nodes[2] = True
                prediction = 1
            else:
                prediction = 0
                
    # Convert boolean values to integers (True -> 1, False -> 0)
    nodes = [int(n) for n in nodes]
    
    return prediction, nodes
```

### Explanation
The function `predict` takes a dictionary `X` containing financial metrics and returns a tuple with two elements: an integer indicating whether the investment is recommended (1 for yes, 0 for no), and a list of integers representing which conditions were met in order.

- **nodes[0]:** Indicates if the Equity/TA ratio exceeds 0.50.
- **nodes[1]:** Indicates if the Equity/TL ratio exceeds 1.00 (only checked if nodes[0] is False).
- **nodes[2]:** Indicates if the WC/TA ratio exceeds 0.20 (only checked if both previous conditions are False).

The function efficiently evaluates each condition in sequence, stopping as soon as a recommendation can be made. This hierarchical approach ensures that each subsequent condition is only evaluated when necessary, optimizing performance and decision-making accuracy.
