Decision Tree:

|--- Equity/TL <= 0.80

||--- NI/TC > 0.20 → Solvent (1)

||--- Sales/TA > 0.50 → Solvent (1)

This tree effectively classifies a company's solvency by first evaluating the equity relative to liabilities, then considering either profitability or sales efficiency based on the initial evaluation.

Now, here is the Python function that implements this decision tree:

```python
def predict(X: dict):
    nodes = [None] * 2
    
    # Root node condition
    nodes[0] = X['Equity/TL'] <= 0.80
    
    if nodes[0]:
        # First inner node condition when Equity/TL is low
        nodes[1] = X['NI/TC'] <= 0.20
        prediction = 0 if nodes[1] else 1
    else:
        # Second inner node condition when Equity/TL is high
        nodes[1] = X['Sales/TA'] <= 0.50
        prediction = 0 if nodes[1] else 1
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

This function evaluates the company's solvency by first checking if Equity/TL is less than or equal to 0.80. If true, it then checks the profitability ratio NI/TC; if false, it assesses the sales efficiency through Sales/TA. The function returns a prediction (0 for insolvent, 1 for solvent) and a list of boolean values indicating whether each inner node condition was met.
