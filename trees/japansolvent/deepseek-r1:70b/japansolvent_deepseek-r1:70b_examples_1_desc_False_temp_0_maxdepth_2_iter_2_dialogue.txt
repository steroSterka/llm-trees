To create a function that predicts solvency based on financial ratios with specific conditions, we can follow these steps:

### Approach
The goal is to determine if a company is solvent based on two key financial metrics: Equity to Total Liabilities (Equity/TL) and Net Income/Sales. The decision tree evaluates these metrics in sequence.

1. **First Condition**: Check if the ratio of Equity to Total Liabilities is less than or equal to 1.0. This indicates whether the company's equity is at least equal to its total liabilities.
2. **Second Condition**: If the first condition is met, further check if the Net Income/Sales ratio is at least 0.10 (10%). This ensures that the company generates sufficient profit from its sales.

The prediction logic is as follows:
- If both conditions are satisfied, the company is considered solvent (prediction = 1).
- If only the first condition is met but not the second, the company is deemed insolvent (prediction = 0).
- If the first condition is not met, the company is still considered solvent because its equity exceeds total liabilities.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    nodes = [None, None]
    
    # Evaluate the first node condition
    nodes[0] = X["Equity/TL"] <= 1.0
    
    # Evaluate the second node condition regardless of the first outcome
    nodes[1] = X["NI/Sales"] >= 0.10
    
    # Convert boolean values to integers (1 for True, 0 for False)
    nodes = [int(nodes[0]), int(nodes[1])]
    
    if nodes[0]:
        prediction = 1 if nodes[1] else 0
    else:
        prediction = 1
    
    return prediction, nodes
```

### Explanation
- **Nodes Initialization**: Two nodes are initialized to `None` to store the evaluation of each condition.
- **First Condition Check**: The function checks if the company's Equity/TL ratio is less than or equal to 1.0 and stores this as a boolean in `nodes[0]`.
- **Second Condition Check**: Regardless of the first condition, the function evaluates whether Net Income/Sales is at least 0.10 and stores this in `nodes[1]`.
- **Conversion to Integers**: Boolean values in nodes are converted to integers (True becomes 1, False becomes 0).
- **Prediction Logic**: Based on the node evaluations, the prediction determines solvency. If the first condition is met but the second isn't, it predicts insolvency; otherwise, it predicts solvency.

This structured approach ensures that each financial metric is evaluated in sequence, providing a clear and logical determination of the company's solvency status.
