```python
def predict(X: dict):
    nodes = 2 * [None]
    # First condition: EBIT/TA <= 0.10
    nodes[0] = X["EBIT/TA"] <= 0.10
    # Second condition: NI/Sales <= 0.05
    nodes[1] = X["NI/Sales"] <= 0.05

    if nodes[0]:
        prediction = 0  # Insolvent
    else:
        if nodes[1]:

        else:
            prediction = 1  # Solvent

    return prediction, nodes
```

- **Nodes List:** The list `nodes` has two elements corresponding to the conditions at each level of the decision tree.
  - `nodes[0]`: Checks if EBIT/TA is less than or equal to 0.10.
  - `nodes[1]`: Checks if NI/Sales is less than or equal to 0.05.

- **Prediction Logic:**
  - If the first condition (`EBIT/TA <= 0.10`) is true, the company is classified as insolvent (prediction = 0).
  - If the first condition is false, it proceeds to check the second condition:
    - If `NI/Sales <= 0.05` is true, the company is classified as insolvent.
    - Otherwise, the company is classified as solvent.
