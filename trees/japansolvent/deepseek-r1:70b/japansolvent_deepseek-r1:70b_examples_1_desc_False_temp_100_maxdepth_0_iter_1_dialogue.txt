To implement a function that predicts whether a company is solvent or insolvent based on financial features using a decision tree approach, we need to evaluate each feature against specific thresholds and determine the outcome by following the hierarchical structure of the decision tree. The function should return both the prediction (1 for solvent, 0 for insolvent) and a list indicating which conditions were met at each node.

### Approach
The decision tree is structured as follows:
1. Check if Equity/Total Liabilities (E/TCL) is greater than 0.50.
2. If not, check if Net Income/Total Capital (NI/TC) is greater than 0.10.
3. If NI/TC is not sufficient, check Working Capital/Total Assets (WC/TA).
4. If WC/TA is insufficient, evaluate Equity/Total Assets (E/TA).
5. If E/TA doesn't meet the threshold, examine Sales/Total Assets (S/TA).
6. Finally, if all previous conditions fail, assess EBIT/Sales.

Each condition corresponds to a node in the decision tree, and we need to evaluate each node's condition based on actual feature values before determining the final prediction. This ensures that the 'nodes' list accurately reflects the state of each condition regardless of the path taken through the tree.

### Solution Code
```python
def predict(X):
    # Initialize all nodes as False
    nodes = [False] * 6

    # Evaluate each node's condition based on feature values
    nodes[0] = X['Equity/TL'] <= 0.50  # Node 0: Equity/TL <= 0.50
    nodes[1] = X['NI/TC'] > 0.10      # Node 1: NI/TC > 0.10
    nodes[2] = X['WC/TA'] > 0.25      # Node 2: WC/TA > 0.25
    nodes[3] = X['Equity/TA'] > 0.30   # Node 3: Equity/TA > 0.30
    nodes[4] = X['Sales/TA'] > 0.60    # Node 4: Sales/TA > 0.60
    nodes[5] = X['EBIT/Sales'] > 0.05  # Node 5: EBIT/Sales > 0.05

    # Determine prediction based on the decision tree logic
    if not nodes[0]:  # If Equity/TL > 0.50, solvent
        prediction = 1
    else:
        if nodes[1]:  # NI/TC > 0.10 indicates solvent
            prediction = 1
        else:
            if nodes[2]:  # WC/TA > 0.25 indicates solvent
                prediction = 1
            else:
                if nodes[3]:  # Equity/TA > 0.30 indicates solvent
                    prediction = 1
                else:
                    if nodes[4]:  # Sales/TA > 0.60 indicates solvent
                        prediction = 1
                    else:
                        if nodes[5]:  # EBIT/Sales > 0.05 indicates solvent
                            prediction = 1
                        else:  # If all fail, insolvent
                            prediction = 0

    # Convert boolean nodes to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]

    return prediction, nodes
```

### Explanation
The function begins by initializing a list of six boolean values (`nodes`) to track each condition's evaluation. Each feature is then checked against its respective threshold and assigned to the corresponding node. After evaluating all conditions, the function follows the hierarchical decision tree logic to determine if the company is solvent (1) or insolvent (0). The final result includes both the prediction and a list of integers representing whether each condition was met.

This approach ensures that all conditions are evaluated based on actual feature values, providing an accurate reflection of each node's state in the decision-making process.
