Here is a structured and elegant solution to create a decision tree classifier that predicts whether a company is solvent based on the given financial features:

### Approach
The decision tree classifier will use two key financial ratios:
1. **Equity/Total Liabilities (Equity/TL)**: This ratio indicates the company's leverage. A higher value suggests better solvency.
2. **Earnings Before Interest and Taxes/Total Assets (EBIT/TA)**: This ratio measures profitability. A higher value indicates better profitability.

The decision tree will have a maximum depth of 2, with the following structure:
1. The first split is based on Equity/TL <= 0.50.
   - If true, further evaluate EBIT/TA.
     - EBIT/TA > 0.10: Classify as Solvent (1).
     - EBIT/TA <= 0.10: Classify as Insolvent (0).
2. The second split is based on Equity/TL > 0.50, which directly classifies the company as Solvent (1).

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    """
    Predicts whether a company is solvent or insolvent based on financial features.
    
    Args:
        X (dict): A dictionary containing the financial features of the company.
        
    Returns:
        tuple[int, list[int]]: A tuple where the first element is the prediction (1 for solvent, 0 for insolvent)
                               and the second element is a list of truth values (1 if condition met, 0 otherwise) 
                               representing the inner nodes of the decision tree.
    """
    
    # Initialize the list to keep track of the inner node conditions
    nodes = [None] * 2
    
    # First split: Check if Equity/TL <= 0.50
    equity_tl = X.get('Equity/TL', None)
    if equity_tl is not None:
        nodes[0] = 1 if equity_tl <= 0.50 else 0
    else:
        raise ValueError("Feature 'Equity/TL' is missing from the input.")
    
    prediction = 0  # Default to insolvent
    
    # Second split: If Equity/TL <= 0.50, check EBIT/TA > 0.10
    if nodes[0] == 1:
        ebit_ta = X.get('EBIT/TA', None)
        if ebit_ta is not None:
            nodes[1] = 1 if ebit_ta > 0.10 else 0
            # Determine the prediction based on EBIT/TA
            if nodes[1] == 1:
                prediction = 1  # Solvent
            else:
                prediction = 0  # Insolvent
        else:
            raise ValueError("Feature 'EBIT/TA' is missing from the input.")
    else:
        # If Equity/TL > 0.50, classify as solvent without further checks
        prediction = 1
    
    return prediction, nodes
```

### Explanation
- **Initialization**: The function initializes a list `nodes` to track whether each inner node condition is met (1 for true, 0 for false).
- **First Split**: It checks if the company's Equity/TL ratio is less than or equal to 0.50. This determines leverage.
- **Second Split**: If the first condition is true, it further evaluates profitability using EBIT/TA to determine solvency.
- **Prediction**: Based on these evaluations, the function classifies the company as solvent (1) or insolvent (0).

This approach ensures that the decision tree effectively balances leverage and profitability within a maximum depth of 2, providing clear classification criteria for solvency.
