Here's how you can format the decision tree as a Python function that returns both the prediction and a list of truth values for the inner nodes:

```python
def predict(X: dict) -> tuple[int, list[int]]:
    # Evaluate conditions based on the decision tree structure
    condition1 = X["WC/TA"] > 0.20
    condition2 = X["Equity/TL"] > 0.50
    
    # Convert boolean values to integers (1 for True, 0 for False)
    nodes = [int(condition1), int(condition2)]
    
    if condition1:
        prediction = 1
    else:
        if condition2:
            prediction = 1
        else:
            prediction = 0
    
    return prediction, nodes
```

### Explanation:

1. **Function Definition**: The function `predict` takes a dictionary `X` containing the feature values and returns a tuple with the predicted class (either 0 for insolvent or 1 for solvent) and a list of integers representing whether each inner node condition was met.

2. **Condition Evaluation**:
   - `condition1`: Checks if "Working Capital/Total Assets" (`WC/TA`) is greater than 0.20.
   - `condition2`: Checks if "Equity/Total Liabilities" (`Equity/TL`) is greater than 0.50.

3. **Node Truth Values**: The results of these conditions are converted to integers (1 for True, 0 for False) and stored in the `nodes` list.

4. **Prediction Logic**:
   - If `condition1` is true, the company is classified as solvent (prediction = 1).
   - If `condition1` is false, then `condition2` determines the prediction: 
     - True results in a solvent classification.
     - False results in an insolvent classification.

This function effectively captures both the decision-making process of the tree and provides insight into which conditions were met during the prediction.
