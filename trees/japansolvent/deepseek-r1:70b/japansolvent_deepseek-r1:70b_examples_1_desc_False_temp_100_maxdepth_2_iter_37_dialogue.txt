```python
def predict(X):
    nodes = [None, None]
    
    # Evaluate conditions for each inner node
    nodes[0] = X['Equity/TL'] <= 0.8
    nodes[1] = X['WC/TA'] <= 0.3
    
    if nodes[0]:
        prediction = 0  # Insolvent
    else:
        if nodes[1]:
            prediction = 0  # Insolvent
        else:
            prediction = 1  # Solvent
    
    # Convert boolean values to integers for the nodes list
    nodes = [int(nodes[0]), int(nodes[1])]
    
    return prediction, nodes
```

- **Function Definition:** The `predict` function takes a dictionary `X` containing the company's financial features.
  
- **Node Evaluation:** 
  - `nodes[0]` checks if the Equity/Total Liabilities ratio (`Equity/TL`) is less than or equal to 0.8.
  - `nodes[1]` checks if the Working Capital/Total Assets ratio (`WC/TA`) is less than or equal to 0.3.

- **Prediction Logic:**
  - If `nodes[0]` is true, the company is classified as insolvent (0).
  - If `nodes[0]` is false, then check `nodes[1]`. If `nodes[1]` is true, classify as insolvent; otherwise, classify as solvent.

- **Return Values:** The function returns a tuple where:
  - The first element is the prediction (0 for insolvent, 1 for solvent).
