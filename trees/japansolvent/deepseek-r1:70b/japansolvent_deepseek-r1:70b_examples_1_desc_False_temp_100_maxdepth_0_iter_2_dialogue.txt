```python
def predict(X: dict):
    # Extract relevant features
    e_tl = X['Equity/TL']
    ni_tc = X['NI/TC']
    wc_ta = X['WC/TA']

    # Initialize nodes list with truth values of each condition (1 for True, 0 for False)
    nodes = [
        int(e_tl > 0.50),           # Node 0: Equity/TL > 0.50
        int(ni_tc > 0.10),          # Node 1: NI/TC > 0.10
        int(wc_ta > 0.20)           # Node 2: WC/TA > 0.20
    ]

    # Determine prediction based on the decision tree logic
    if nodes[0] == 1:
        prediction = 1  # Solvent (E/TLiab > 0.50)
    else:
        if nodes[1] == 1:
            prediction = 1  # Solvent (NI/TC > 0.10)
        else:
            if nodes[2] == 1:
                prediction = 1  # Solvent (WC/TA > 0.20)
            else:
                prediction = 0  # Insolvent

    return prediction, nodes
```

### Explanation:

1. **Feature Extraction:**
   - The function begins by extracting the relevant financial features from the input dictionary `X`. These are `Equity/TL`, `NI/TC`, and `WC/TA`.

2. **Node Evaluation:**
   - Each condition in the decision tree is evaluated to determine its truth value (1 for True, 0 for False). The conditions correspond to:
     - Node 0: Whether Equity/Total Liabilities ratio exceeds 0.50.
     - Node 1: Whether Net Income/Total Capital ratio exceeds 0.10.
     - Node 2: Whether Working Capital/Total Assets ratio exceeds 0.20.

3. **Prediction Logic:**
   - The prediction is made by following the hierarchical structure of the decision tree:
     - If `Node 0` is True, the company is classified as solvent.
     - If `Node 0` is False but `Node 1` is True, the company remains solvent.
     - If both `Node 0` and `Node 1` are False but `Node 2` is True, the company is still considered solvent.
     - Only when all three nodes are False is the company classified as insolvent.

This function ensures that each condition is evaluated upfront and their truth values are stored in the `nodes` list. The prediction is then determined by navigating through these conditions following the predefined decision tree structure.
