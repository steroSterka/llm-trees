#### How to read the tree

* **Root split** – The most powerful predictor is **Equity / Total Assets**.  
  * Companies with **> 30 %** of their assets financed by equity are generally solvent.  
  * Those with **≤ 30 %** equity are at higher risk and are examined further.

* **Second‑level splits** – For low‑equity firms we first look at **Working‑Capital / Total Assets** (liquidity).  
  * If liquidity is also weak (≤ 8 %), the firm is classified **Insolvent** straight away.  

* **Third‑level splits** – If liquidity is adequate, we assess **EBIT / Total Assets** (operating profitability).  
  * Very low operating profit (≤ 4 %) again leads to **Insolvent**.  

* **Fourth‑level splits** – When both liquidity and operating profit are modest, **Net‑Income / Total Capital** (overall profitability) determines the outcome.  
  * Below 6 % → **Insolvent**; above 6 % → **Borderline** (the model is uncertain and a deeper credit analysis would be advisable).

* **High‑equity branch** – For firms with a solid equity base, the tree checks **Net‑Income / Total Capital** first.  
  * > 8 % → **Solvent** (strong profitability).  

* If profitability is weaker (≤ 8 %), the tree evaluates **Sales / Total Assets** (asset turnover).  
  * High turnover (> 55 %) still yields **Solvent**.  

* When turnover is modest, the model looks at **Equity / Total Liabilities** (leverage).  
  * A ratio > 1.20 (more equity than debt) is sufficient for **Solvent**.  

* Finally, if leverage is also moderate, **EBIT / Sales** (operating margin) is the tie‑breaker.  
  * Margins above 12 % are considered **Solvent**; lower margins fall into the **Borderline** zone.

---

### What “Borderline” means

The tree produces a **Borderline** leaf when the available ratios give mixed signals. In practice you would:

1. Pull additional qualitative information (industry outlook, management quality, covenant compliance).  
2. Possibly run a **logistic‑regression** or **ensemble** model to refine the probability of default.  
3. Set a risk‑tolerance threshold (e.g., probability > 0.6 → Insolvent, < 0.4 → Solvent, else manual review).

**Python implementation of the decision‑tree**

```python
def predict(X: dict):
    """
    Predicts solvency (1 = solvent, 0 = insolvent) and returns the
    truth values of every inner node that is evaluated.

    Expected keys in ``X`` (exact spelling, case‑sensitive):
        'EBIT/TA'   – EBIT / Total Assets
        'NI/TC'     – Net Income / Total Capital
        'Sales/TA'  – Sales / Total Assets
        'EBIT/Sales'– EBIT / Sales
        'NI/Sales'  – Net Income / Sales        (not used in the tree)
        'WC/TA'     – Working Capital / Total Assets
        'Equity/TL' – Equity / Total Liabilities
        'Equity/TA' – Equity / Total Assets
    """
    # ------------------------------------------------------------------
    # 0 = condition not satisfied, 1 = condition satisfied
    # ------------------------------------------------------------------
    nodes = [0] * 8                     # eight inner decision points

    # ---------- root node ------------------------------------------------
    nodes[0] = 1 if X["Equity/TA"] <= 0.30 else 0        # 30 % equity threshold

    if nodes[0]:                      # Equity/TA <= 0.30  → higher risk branch
        # ---- node 1 ----------------------------------------------------
        nodes[1] = 1 if X["WC/TA"] <= 0.08 else 0       # liquidity
        if nodes[1]:
            prediction = 0                               # Insolvent
        else:
            # ---- node 2 ------------------------------------------------
            nodes[2] = 1 if X["EBIT/TA"] <= 0.04 else 0  # operating profit
            if nodes[2]:
                prediction = 0                           # Insolvent
            else:
                # ---- node 3 ----------------------------------------
                nodes[3] = 1 if X["NI/TC"] <= 0.06 else 0   # overall profitability
                if nodes[3]:
                    prediction = 0                       # Insolvent
                else:
                    # Borderline – we treat it as solvent for the binary output
                    prediction = 1

    else:                              # Equity/TA > 0.30  → healthier capital base
        # ---- node 4 ----------------------------------------------------
        nodes[4] = 1 if X["NI/TC"] > 0.08 else 0        # strong profitability
        if nodes[4]:
            prediction = 1                               # Solvent
        else:
            # ---- node 5 ------------------------------------------------
            nodes[5] = 1 if X["Sales/TA"] > 0.55 else 0   # asset‑turnover
            if nodes[5]:
                prediction = 1                           # Solvent
            else:
                # ---- node 6 ----------------------------------------
                nodes[6] = 1 if X["Equity/TL"] > 1.20 else 0   # leverage (more equity than debt)
                if nodes[6]:
                    prediction = 1                       # Solvent
                else:
                    # ---- node 7 ------------------------------------
                    nodes[7] = 1 if X["EBIT/Sales"] > 0.12 else 0  # operating margin
                    if nodes[7]:
                        prediction = 1                   # Solvent
                    else:
                        # Borderline – still counted as solvent
                        prediction = 1

    return prediction, nodes
```

### How the function works
1. **`nodes` list** – length 8, one entry per inner decision point.  
   *`1`* means the condition at that node is satisfied, *`0`* otherwise.  
2. The tree follows the hierarchy described earlier:  
   *Root* → **Equity/TA** → (if low) **WC/TA**, **EBIT/TA**, **NI/TC** → insolvent/solvent;  
   *Else* → **NI/TC**, **Sales/TA**, **Equity/TL**, **EBIT/Sales** → solvent (or borderline).  
3. The final **`prediction`** is `1` for *solvent* and `0` for *insolvent*.  
4. Borderline leaves (where the tree is uncertain) are mapped to `1` (solvent) so the output remains binary as required.

You can call the function with a dictionary that contains the eight financial‑ratio keys, e.g.:

```python
sample = {
    "EBIT/TA": 0.05,
    "NI/TC": 0.09,
    "Sales/TA": 0.60,
    "EBIT/Sales": 0.15,
    "NI/Sales": 0.07,
    "WC/TA": 0.10,
    "Equity/TL": 1.30,
    "Equity/TA": 0.35
}

pred, node_vals = predict(sample)
print(pred)        # → 1 (solvent)
print(node_vals)   # → [0, 0, 0, 0, 1, 0, 0, 0]  (example)
```

Feel free to adjust the thresholds (`0.30`, `0.08`, `0.04`, …) if you have empirical values from your own dataset. The structure of the function will stay the same.
