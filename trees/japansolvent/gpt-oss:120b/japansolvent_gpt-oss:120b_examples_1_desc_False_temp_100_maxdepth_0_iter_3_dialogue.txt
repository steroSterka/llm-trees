**Python function that implements the decision‑tree classifier**

```python
def predict(X: dict):
    """
    Predict whether a company is solvent (1) or insolvent (0) using the
    handcrafted decision‑tree described in the prompt.

    Parameters
    ----------
    X : dict
        Dictionary that must contain the following keys (exact spelling):
        'EBIT/TA', 'NI/TC', 'Sales/TA', 'EBIT/Sales',
        'NI/Sales', 'WC/TA', 'Equity/TL', 'Equity/TA'.

        The values are the numeric ratios for the company.

    Returns
    -------
    prediction : int
        1 → solvent, 0 → insolvent
    nodes : list[int]
        Truth values (1 = condition satisfied, 0 = not satisfied) for each
        inner node of the tree, in the order they are evaluated.
    """

    # --------------------------------------------------------------
    # 1️⃣  Compute the Boolean result of every inner‑node condition.
    # --------------------------------------------------------------
    # The order of the entries in the list corresponds to the order
    # used later in the branching logic.
    nodes = [None] * 6                     # we have 6 inner nodes
    nodes[0] = X["Equity/TA"]   <= 0.30    # Node 0
    nodes[1] = X["WC/TA"]       <= 0.05    # Node 1
    nodes[2] = X["EBIT/TA"]     <= 0.02    # Node 2
    nodes[3] = X["NI/TC"]       <= 0.04    # Node 3
    nodes[4] = X["Sales/TA"]    <= 0.20    # Node 4
    nodes[5] = X["EBIT/Sales"]  <= 0.08    # Node 5

    # --------------------------------------------------------------
    # 2️⃣  Follow the tree using the Boolean values above.
    # --------------------------------------------------------------
    if nodes[0]:                     # Equity/TA ≤ 0.30
        if nodes[1]:                 # WC/TA ≤ 0.05
            prediction = 0           # Insolvent
        else:                        # WC/TA  > 0.05
            if nodes[2]:             # EBIT/TA ≤ 0.02
                prediction = 0       # Insolvent
            else:                    # EBIT/TA  > 0.02
                prediction = 1       # Solvent
    else:                            # Equity/TA  > 0.30
        if nodes[3]:                 # NI/TC ≤ 0.04
            prediction = 0           # Insolvent
        else:                        # NI/TC  > 0.04
            if nodes[4]:             # Sales/TA ≤ 0.20
                prediction = 0       # Insolvent
            else:                    # Sales/TA  > 0.20
                if nodes[5]:         # EBIT/Sales ≤ 0.08
                    prediction = 0   # Insolvent
                else:                # EBIT/Sales  > 0.08
                    prediction = 1   # Solvent

    # --------------------------------------------------------------
    # 3️⃣  Return the prediction together with the node‑truth list.
    # --------------------------------------------------------------
    # Convert the Boolean values to 0/1 as requested.
    nodes_int = [int(b) for b in nodes]

    return prediction, nodes_int
```

### How the function works

| Index | Condition (inner node)                              | Meaning in finance                                                                 |
|------|------------------------------------------------------|-------------------------------------------------------------------------------------|
| 0    | `Equity/TA ≤ 0.30`                                   | Low equity cushion → higher risk.                                                   |
| 1    | `WC/TA ≤ 0.05`                                       | Very thin working‑capital buffer.                                                   |
| 2    | `EBIT/TA ≤ 0.02`                                     | Poor operating profitability per asset.                                            |
| 3    | `NI/TC ≤ 0.04`                                       | Low return on total capital.                                                        |
| 4    | `Sales/TA ≤ 0.20`                                    | Weak asset turnover.                                                                |
| 5    | `EBIT/Sales ≤ 0.08`                                  | Thin operating margin.                                                              |

The function evaluates **all six conditions** first (so the returned `nodes` list always has length 6), then follows the tree to produce a single binary prediction (`1 = solvent`, `0 = insolvent`).
