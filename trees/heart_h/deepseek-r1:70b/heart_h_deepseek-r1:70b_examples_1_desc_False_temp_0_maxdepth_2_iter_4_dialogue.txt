```python
def predict(X: dict):
    nodes = [None, None]
    
    # First node: Check if chest_pain is Typical angina (3)
    chest_pain_typical = X['chest_pain'] == 3
    nodes[0] = chest_pain_typical
    
    if chest_pain_typical:
        # Second condition: Resting Blood Pressure > 130 mmHg
        trestbps_high = X['trestbps'] > 130
        nodes[1] = trestbps_high
        
        prediction = 1 if trestbps_high else 0
    else:
        # Second condition: Age > 50 years
        age_over_50 = X['age'] > 50
        nodes[1] = age_over_50
        
        prediction = 1 if age_over_50 else 0
    
    return prediction, nodes
```

**Explanation of the Function:**

- **Nodes List:** The `nodes` list keeps track of the boolean evaluation of each condition in the decision tree. There are two conditions corresponding to the maximum depth of 2.

  - `nodes[0]`: Indicates whether the chest pain type is 'Typical angina' (3).
  
  - `nodes[1]`: Depending on `nodes[0]`, it checks either if resting blood pressure exceeds 130 mmHg or if age is greater than 50 years.

- **Prediction Logic:**
  
  - If `chest_pain` is 'Typical angina' (`nodes[0]` is True):
    - Check if `trestbps` > 130. If true, predict heart disease (1). Otherwise, predict no heart disease (0).
  
  - If `chest_pain` is not 'Typical angina':
    - Check if age > 50. If true, predict heart disease (1). Otherwise, predict no heart disease (0).

This function accurately reflects the decision tree structure provided and returns both the prediction and the evaluation of each inner node condition in the form of a list of boolean values.
