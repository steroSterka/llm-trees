```python
def predict(X: dict):
    # Initialize nodes with None
    nodes = [None] * 5

    # Node 0: age <= 45
    nodes[0] = X["age"] <= 45

    if nodes[0]:
        prediction = 0  # No Heart Disease
    else:
        # Node 1: thalach <= 120
        nodes[1] = X["thalach"] <= 120

        if nodes[1]:
            # Node 2: exang == "yes" (encoded as 2)
            nodes[2] = X["exang"] == 2

            if nodes[2]:
                # Node 3: oldpeak > 0.5
                nodes[3] = X["oldpeak"] > 0.5

                if nodes[3]:
                    prediction = 1  # Heart Disease
                else:
                    prediction = 0  # No Heart Disease
            else:
                prediction = 0  # No Heart Disease
        else:
            # Node 4: ca == 0
            nodes[4] = X["ca"] == 0

            if nodes[4]:
                prediction = 1  # Heart Disease
            else:
                # Check oldpeak > 1.5 for node 3 reevaluation
                nodes[3] = X["oldpeak"] > 1.5

                if nodes[3]:
                    prediction = 1  # Heart Disease
                else:
                    prediction = 0  # No Heart Disease

    # Convert boolean values to 1 (True) or 0 (False)
    nodes = [1 if node else 0 for node in nodes]

    return prediction, nodes
```

### Explanation:
- **Nodes**: The function evaluates each condition in sequence and stores whether the condition was met (1 for True, 0 for False).
  - Node 0: Checks if the patient's age is less than or equal to 45.
  - Node 1: Checks if the maximum heart rate achieved during exercise is less than or equal to 120 bpm.
  - Node 2: Determines if exercise-induced angina is present (encoded as 2).
  - Node 3: Evaluates if ST depression induced by exercise relative to rest exceeds 0.5.
  - Node 4: Checks if the number of major vessels colored by fluoroscopy is zero.

- **Prediction**: Based on these conditions, the function predicts whether the patient has heart disease (1) or not (0).

This structured approach ensures that each condition in the decision tree is methodically checked, providing a clear and logical pathway to the prediction.
