To solve this problem, we need to create a decision tree model that predicts whether a person has heart disease based on their age and cholesterol levels. The decision tree is structured into two main checks: one for individuals aged 50 or younger and another for those older than 50.

### Approach
The approach involves creating a decision tree with the following structure:
1. **Root Node (Age Check):** Split the data based on whether the individual's age is 50 years or younger.
   - If true, proceed to check if they have exercise-induced angina.
2. **Left Child Node (Exercise-Induced Angina Check):** For individuals aged 50 or younger, check if they experience chest pain during exercise (exang).
3. **Right Child Node (Cholesterol Check):** For individuals older than 50, check if their cholesterol level exceeds a threshold of 240 mg/dL.

The decision tree will return a prediction based on these checks:
- If an individual aged 50 or younger has exercise-induced angina, they are predicted to have heart disease.
- If an individual older than 50 has high cholesterol (above 240 mg/dL), they are also predicted to have heart disease.
- Otherwise, the prediction is that they do not have heart disease.

### Solution Code

```python
def predict_heart_disease(X):
    age = X['age']
    exang = X['exang']  # 1 for no, 2 for yes
    chol = X['chol']
    
    # Root node condition: age <=50
    nodes = [False, False]
    nodes[0] = (age <= 50)
    
    if nodes[0]:
        # Check exercise-induced angina for younger individuals
        exang_yes = (exang == 2)  # since exang is encoded as 1 for no and 2 for yes
        nodes[1] = exang_yes
    else:
        # Check cholesterol level for older individuals
        chol_high = (chol > 240)
        nodes[1] = chol_high
    
    prediction = 0
    if nodes[0]:
        if nodes[1]:
            prediction = 1
    else:
        if nodes[1]:
            prediction = 1
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation
- **Root Node Check:** The first condition checks if the individual's age is 50 or younger. This determines which subsequent check to perform.
- **Left Child Node (Exercise-Induced Angina):** If the individual is aged 50 or younger, we then check for exercise-induced angina. This is encoded as `exang == 2` in our dataset.
- **Right Child Node (Cholesterol Level):** For individuals older than 50, we check if their cholesterol level exceeds 240 mg/dL (`chol > 240`).
- **Prediction:** Based on these checks, the function returns a prediction where heart disease is present (1) or absent (0), along with a list indicating whether each condition was met.

This approach efficiently structures the decision-making process using two simple checks, making it easy to interpret and apply to new data points.
