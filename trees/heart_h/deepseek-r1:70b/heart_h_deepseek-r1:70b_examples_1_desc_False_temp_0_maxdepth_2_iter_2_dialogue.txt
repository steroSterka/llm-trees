To solve this problem, we need to create a function that predicts an outcome based on given medical conditions using a decision tree approach. The function will return both the prediction and a list indicating whether each inner node's condition was satisfied.

### Approach
The solution involves constructing a simple decision tree with two levels (depth 2) to predict the outcome based on chest pain type and exertion angina (exang). Here’s a detailed breakdown of the approach:

1. **Decision Tree Structure**: The decision tree is structured such that:
   - At the first level, we check if the chest pain type is typical (chest_pain == 3).
   - If the first condition is not met, we move to the second level and check for exertion angina (exang == 2).

2. **Node Evaluation**: Each node in the tree will be evaluated to determine if its condition is satisfied. These evaluations are stored in a list where each entry is either 1 (condition satisfied) or 0 (condition not satisfied).

3. **Prediction Logic**: Based on the evaluation of these nodes, we make a prediction:
   - If chest pain is typical, predict 1.
   - If chest pain is not typical but exertion angina is present, predict 1.
   - Otherwise, predict 0.

### Solution Code
```python
def predict(X):
    # Evaluate both inner nodes
    chest_pain_node = (X['chest_pain'] == 3)
    exang_node = (X['exang'] == 2)
    
    # Convert boolean results to integers for the nodes list
    nodes = [int(chest_pain_node), int(exang_node)]
    
    # Determine prediction based on node evaluations
    if chest_pain_node:
        prediction = 1
    else:
        prediction = 1 if exang_node else 0
    
    return prediction, nodes
```

### Explanation
- **Node Evaluation**: The function evaluates two conditions (nodes) to determine the prediction. Each condition is checked and converted into an integer value where True becomes 1 and False becomes 0.
- **Prediction Logic**: The first node checks if chest pain is typical. If true, it predicts 1 immediately. If not, it proceeds to check the second node for exertion angina. Based on this second check, it either predicts 1 or 0.

This approach ensures that we efficiently traverse a simple decision tree and return both the prediction and the evaluation of each inner node's condition.
