def predict(X: dict):
    """
    Predicts whether a patient has heart disease or not based on their features.

    Parameters:
    X (dict): A dictionary containing the patient's features.
        - 'age': age in years
        - 'sex': sex (male, female)
        - 'chest_pain': Chest Pain Type (3 = Typical angina, 0 = Asymptomatic, 2 = Non-anginal pain, 1 = Atypical angina)
        - 'trestbps': Resting Blood Pressure in mmHg
        - 'chol': Serum Cholesterol in mg/dl
        - 'fbs': Fasting Blood Sugar (1 = false, 2 = true)
        - 'restecg': Resting Electrocardiographic Results (2 = Normal, 3 = Having ST-T wave abnormality, 1 = Showing probable or definite left ventricular hypertrophy by Estes' criteria)
        - 'thalach': Maximum Heart Rate Achieved in bpm
        - 'exang': Exercise Induced Angina (1 = no, 2 = yes)
        - 'oldpeak': ST Depression Induced by Exercise Relative to Rest (0 to 5)
        - 'slope': Slope of the Peak Exercise ST Segment (3 = Upsloping, 2 = Flat, 1 = Downsloping)
        - 'ca': Number of Major Vessels Colored by Fluoroscopy (0, 1, 2, 3)
        - 'thal': Thalassemia (2 = Normal, 1 = Fixed defect, 3 = Reversible defect)

    Returns:
    prediction (int): Whether the patient has heart disease or not (yes = 1, no = 0)
    nodes (list): A list of boolean values representing the inner nodes of the decision tree
    """

    # Initialize the nodes list with None values
    nodes = 2 * [None]

    # First node: Age <= 50
    nodes[0] = X['age'] <= 50

    # Second node: If age <= 50, then Serum Cholesterol <= 200; otherwise, Resting Blood Pressure <= 140
    if nodes[0]:
        nodes[1] = X['chol'] <= 200
    else:
        nodes[1] = X['trestbps'] <= 140

    # Make the prediction based on the nodes
    if nodes[0]:
        if nodes[1]:
            prediction = 0  # Low risk, no heart disease
        else:
            prediction = 1  # High risk, heart disease likely
    else:
        if nodes[1]:
            prediction = 0  # Moderate risk, further evaluation needed; for simplicity, classify as no heart disease
        else:
            prediction = 1  # High risk, heart disease likely

    # Convert boolean values in nodes to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]

    return prediction, nodes


# Example usage:

This decision tree first checks if the patient's age is less than or equal to 50. If it is, then it checks if their serum cholesterol level is less than or equal to 200 mg/dl. If both conditions are met, the patient is classified as low risk and unlikely to have heart disease. Otherwise, they are classified as high risk and likely to have heart disease.

Otherwise, they are classified as high risk and likely to have heart disease.

The `predict` function takes a dictionary of patient features as input and returns a prediction (0 or 1) and a list of boolean values representing the inner nodes of the decision tree. The boolean values are converted to integers (True -> 1, False -> 0) before being returned.
