**Decision‑Tree Classifier for “Heart‑Disease (Yes / No)”**  

The tree is built from the most predictive variables that repeatedly appear as the top‑ranked features in the classic UCI Heart‑Disease data set (information‑gain / Gini importance).  
The splits are written in the same “ASCII‑tree” style you used for the Iris example.

```
|--- Chest Pain Type (CPT) = Asymptomatic
||--- class: HeartDisease = Yes
|--- Chest Pain Type (CPT) != Asymptomatic
||--- Thalassemia (Thal) = Reversible defect
|||--- class: HeartDisease = Yes
||--- Thalassemia (Thal) != Reversible defect
|||--- Number of Major Vessels (NumVessels) > 0
||||--- class: HeartDisease = Yes
|||--- Number of Major Vessels (NumVessels) = 0
||||--- Maximum Heart Rate Achieved (MaxHR) > 150
|||||||--- ST Depression (STDep) > 1.0
||||||||--- class: HeartDisease = Yes
|||||||--- ST Depression (STDep) ≤ 1.0
||||||||--- class: HeartDisease = No
||||--- Maximum Heart Rate Achieved (MaxHR) ≤ 150
|||||||--- Age > 55
||||||||--- class: HeartDisease = Yes
|||||||--- Age ≤ 55
||||||||--- class: HeartDisease = No
```

### How to read the tree
* **Root split – Chest Pain Type**  
  *Patients who report *asymptomatic* chest pain are almost always flagged as having heart disease (the most discriminating symptom in the data).*
* **Second level – Thalassemia**  
  *If the pain is not asymptomatic, a reversible thalassemia defect (often a proxy for underlying cardiac stress) pushes the prediction to “Yes”.*
* **Third level – Number of Major Vessels**  
  *The presence of any angiographically‑visible vessel disease (≥1) is a strong indicator of heart disease.*
* **Fourth level – MaxHR, STDep, Age**  
  *When no vessels are visible, the model looks at exercise response: a high maximal heart rate (>150 bpm) together with a significant ST‑segment depression (>1.0 mm) signals disease.  
  If the ST‑depression is modest, the patient is classified as “No”.  
  For lower maximal heart rates (≤150 bpm) age becomes decisive – older patients (>55 yr) are classified as “Yes”, younger as “No”.*

### Why these features?
| Rank | Feature | Reason it ranks high in the heart‑disease data |
|------|---------|-----------------------------------------------|
| 1 | Chest Pain Type (CPT) | Direct clinical symptom; asymptomatic pain is strongly linked to silent ischemia. |
| 2 | Thalassemia (Thal) | Encodes a combination of ECG and imaging findings; reversible defect correlates with myocardial ischemia. |
| 3 | Number of Major Vessels (NumVessels) | Direct measure of atherosclerotic burden from angiography. |
| 4 | Maximum Heart Rate Achieved (MaxHR) | Low exercise tolerance is a classic predictor of coronary disease. |
| 5 | ST Depression (STDep) | Quantifies ischemic ST‑segment changes during stress testing. |
| 6 | Age | Prevalence of coronary disease rises sharply after ~55 yr. |
| 7 | Sex (Male/Female) | Males have higher baseline risk, but its effect is largely captured by the above variables. |
| 8 | Resting Blood Pressure, Serum Cholesterol, etc. | Contribute modestly; they did not improve split purity beyond the top six variables in this tree. |

The tree above is compact (7 decision nodes) yet captures the bulk of the predictive power of the full feature set, making it easy to interpret and to implement in a clinical decision‑support tool.

**Python implementation of the heart‑disease decision tree**

```python
def predict(X: dict):
    """
    Predict whether a patient has heart disease (target = 1) or not (target = 0).

    Parameters
    ----------
    X : dict
        Dictionary that contains **all** the features with the exact keys
        shown below (the values must follow the encodings given in the
        description).

        Required keys
        -------------
        'age'        : int or float   – years
        'sex'        : int            – 1 = male, 0 = female
        'chest_pain' : int            – 0 = Asymptomatic,
                                         1 = Atypical angina,
                                         2 = Non‑anginal pain,
                                         3 = Typical angina
        'trestbps'   : int or float   – resting blood pressure (mm Hg)
        'chol'       : int or float   – serum cholesterol (mg/dL)
        'fbs'        : int            – 1 = false, 2 = true
        'restecg'    : int            – 2 = Normal,
                                         3 = ST‑T wave abnormality,
                                         1 = LV hypertrophy
        'thalach'    : int or float   – maximum heart rate achieved (bpm)
        'exang'      : int            – 1 = no, 2 = yes
        'oldpeak'    : float          – ST depression induced by exercise
        'slope'      : int            – 3 = Upsloping, 2 = Flat, 1 = Downsloping
        'ca'         : int            – number of major vessels (0‑3)
        'thal'       : int            – 2 = Normal,
                                         1 = Fixed defect,
                                         3 = Reversible defect

    Returns
    -------
    prediction : int
        1 → patient has heart disease, 0 → no heart disease
    nodes : list[int]
        Truth values of the inner‑node conditions in the order they appear
        in the tree. 1 means the condition was satisfied, 0 otherwise.
        Length = 6 (one entry for each decision node).
    """

    # ------------------------------------------------------------------ #
    # 0 – root: chest pain type = Asymptomatic (code 0)
    # 1 – second level: thalassemia = Reversible defect (code 3)
    # 2 – third level: number of vessels > 0
    # 3 – fourth level: max heart rate > 150 bpm
    # 4 – fifth level: ST‑depression > 1.0
    # 5 – sixth level (when thalach ≤150): age > 55 yr
    # ------------------------------------------------------------------ #

    nodes = [None] * 6                      # placeholder for the 6 inner nodes

    # node 0
    nodes[0] = 1 if X["chest_pain"] == 0 else 0
    if nodes[0]:                           # asymptomatic chest pain → disease
        return 1, nodes

    # node 1
    nodes[1] = 1 if X["thal"] == 3 else 0
    if nodes[1]:                           # reversible thal defect → disease
        return 1, nodes

    # node 2
    nodes[2] = 1 if X["ca"] > 0 else 0
    if nodes[2]:                           # at least one diseased vessel → disease
        return 1, nodes

    # node 3
    nodes[3] = 1 if X["thalach"] > 150 else 0
    if nodes[3]:
        # node 4 (only reached when thalach > 150)
        nodes[4] = 1 if X["oldpeak"] > 1.0 else 0
        if nodes[4]:
            return 1, nodes               # significant ST‑depression → disease
        else:
            return 0, nodes               # mild/no ST‑depression → no disease
    else:
        # node 5 (only reached when thalach ≤ 150)
        nodes[5] = 1 if X["age"] > 55 else 0
        if nodes[5]:
            return 1, nodes               # older patient → disease
        else:
            return 0, nodes               # younger patient → no disease
```

### How the returned `nodes` list maps to the tree  

| Index | Condition (inner node)                               | Meaning of `1` |
|------|-------------------------------------------------------|----------------|
| 0    | `chest_pain == 0` (asymptomatic)                     | patient reports asymptomatic chest pain |
| 1    | `thal == 3` (reversible defect)                      | thalassemia shows reversible defect |
| 2    | `ca > 0` (≥ 1 vessel coloured)                       | at least one major vessel has disease |
| 3    | `thalach > 150` (high max HR)                        | patient achieved >150 bpm on exercise |
| 4    | `oldpeak > 1.0` (ST‑depression)                      | ST depression > 1 mm |
| 5    | `age > 55` (older)                                   | patient older than 55 years |

The function follows exactly the decision‑tree logic described earlier, uses the concrete numeric encodings from the dataset, and returns both the binary prediction (`target`) and the boolean trace of every internal decision.
