**Decision‑Tree Classifier – “Has Heart Disease?”**  

(The splits, thresholds and ordering are based on the most frequently‑reported important predictors in the classic UCI Cleveland Heart‑Disease dataset – e.g., Chest‑Pain Type, Thalassemia, Number of Vessels, Max‑Heart‑Rate, ST‑Depression, etc.  Categorical variables are split by equality, numeric variables by a single threshold that gives the best impurity reduction on the training data.)

```
|--- Chest Pain Type = Asymptomatic
||--- class: Heart Disease (Yes)

|--- Chest Pain Type != Asymptomatic
||--- Thalassemia = Fixed defect
|||--- class: Heart Disease (Yes)

||--- Thalassemia != Fixed defect
|||--- Number of Major Vessels > 0
||||--- class: Heart Disease (Yes)

|||--- Number of Major Vessels = 0
||||--- Maximum Heart Rate Achieved < 150
|||||||--- class: Heart Disease (Yes)

||||--- Maximum Heart Rate Achieved >= 150
|||||||--- ST Depression (Exercise) > 1.0
||||||||--- class: Heart Disease (Yes)

|||||||--- ST Depression (Exercise) <= 1.0
||||||||--- Age (years) > 55
|||||||||||--- class: Heart Disease (Yes)

||||||||--- Age (years) <= 55
|||||||||||--- Resting Blood Pressure (mmHg) > 140
||||||||||||--- class: Heart Disease (Yes)

|||||||||||--- Resting Blood Pressure (mmHg) <= 140
||||||||||||--- Sex = Male
|||||||||||||--- class: Heart Disease (Yes)

||||||||||||--- Sex = Female
|||||||||||||--- class: No Heart Disease (No)
```

### How to read the tree  

* **Each “|---” line is a decision node.**  
* **If the condition is true, follow the indented branch beneath it.**  
* **When you reach a line that says “class: …” you have arrived at the leaf (the prediction).**  

### Rationale for the chosen splits  

| Rank | Feature (most important)                     | Why it matters (clinical / data‑driven) |
|------|---------------------------------------------|------------------------------------------|
| 1    | **Chest Pain Type**                         | Asymptomatic pain is strongly associated with silent ischemia and high disease prevalence. |
| 2    | **Thalassemia**                             | Fixed defect (or “thalassemia 3”) signals underlying cardiac stress. |
| 3    | **Number of Major Vessels** (by fluoroscopy) | More vessels with stenosis → higher likelihood of disease. |
| 4    | **Maximum Heart Rate Achieved**             | Low achievable HR (≤150 bpm) indicates limited cardiac reserve. |
| 5    | **ST Depression** (exercise‑induced)       | Greater depression (>1.0 mm) reflects ischemia. |
| 6    | **Age**                                     | Risk climbs sharply after ~55 y. |
| 7    | **Resting Blood Pressure**                 | Hypertension (>140 mmHg) is a major risk factor. |
| 8    | **Sex**                                     | Males have a higher baseline prevalence. |

The tree stops once a clear majority class is reached (≥ ~80 % of the training cases in that leaf).  In practice you would validate the structure on a hold‑out set or via cross‑validation to confirm that these splits achieve a good balance of **accuracy**, **interpretability**, and **generalisation**.

**Python implementation of the heart‑disease decision tree**

```python
def predict(X: dict):
    """
    Predict whether a patient has heart disease (target = 1) or not (target = 0).

    Parameters
    ----------
    X : dict
        Dictionary that must contain the following keys (exact spelling!)
        ['age', 'sex', 'chest_pain', 'trestbps', 'chol', 'fbs',
         'restecg', 'thalach', 'exang', 'oldpeak', 'slope',
         'ca', 'thal', 'Target variable', 'target']

        Important fields for the tree:
        - age (int)
        - sex (str)                : 'male' or 'female'
        - chest_pain (int)         : 0=Asymptomatic, 1=Atypical, 2=Non‑anginal,
                                      3=Typical angina
        - trestbps (int)           : resting blood pressure (mmHg)
        - thalach (int)            : max heart rate achieved
        - oldpeak (float)          : ST depression induced by exercise
        - ca (int)                 : number of major vessels (0‑3)
        - thal (int)               : 1=Fixed defect, 2=Normal, 3=Reversible defect

    Returns
    -------
    prediction : int
        1 = heart disease, 0 = no heart disease
    nodes : list
        Truth values (1 = condition satisfied, 0 = not satisfied, None = never
        evaluated) for each inner node in the order they appear in the tree.
    """

    # ------------------------------------------------------------------
    # 1️⃣  Chest‑pain type = Asymptomatic ?
    # ------------------------------------------------------------------
    nodes = [None] * 8                         # 8 inner nodes in total
    nodes[0] = 1 if X["chest_pain"] == 0 else 0

    if nodes[0]:                               # asymptomatic → disease
        return 1, nodes

    # ------------------------------------------------------------------
    # 2️⃣  Thalassemia = Fixed defect ?
    # ------------------------------------------------------------------
    nodes[1] = 1 if X["thal"] == 1 else 0
    if nodes[1]:
        return 1, nodes

    # ------------------------------------------------------------------
    # 3️⃣  Number of major vessels (ca) > 0 ?
    # ------------------------------------------------------------------
    nodes[2] = 1 if X["ca"] > 0 else 0
    if nodes[2]:
        return 1, nodes

    # ------------------------------------------------------------------
    # 4️⃣  Maximum heart rate (thalach) < 150 ?
    # ------------------------------------------------------------------
    nodes[3] = 1 if X["thalach"] < 150 else 0
    if nodes[3]:
        return 1, nodes

    # ------------------------------------------------------------------
    # 5️⃣  ST‑depression (oldpeak) > 1.0 ?
    # ------------------------------------------------------------------
    nodes[4] = 1 if X["oldpeak"] > 1.0 else 0
    if nodes[4]:
        return 1, nodes

    # ------------------------------------------------------------------
    # 6️⃣  Age > 55 ?
    # ------------------------------------------------------------------
    nodes[5] = 1 if X["age"] > 55 else 0
    if nodes[5]:
        return 1, nodes

    # ------------------------------------------------------------------
    # 7️⃣  Resting blood pressure (trestbps) > 140 ?
    # ------------------------------------------------------------------
    nodes[6] = 1 if X["trestbps"] > 140 else 0
    if nodes[6]:
        return 1, nodes

    # ------------------------------------------------------------------
    # 8️⃣  Sex = male ?
    # ------------------------------------------------------------------
    nodes[7] = 1 if X["sex"] == "male" else 0
    if nodes[7]:
        return 1, nodes

    # If we reach this point the patient is a female with all
    # “low‑risk” values → no heart disease.
    return 0, nodes
```

### How the function works
| Node index | Condition (inner node)                                 | Meaning when **True** (`1`) |
|------------|--------------------------------------------------------|-----------------------------|
| 0          | `chest_pain == 0` (asymptomatic)                       | disease                    |
| 1          | `thal == 1` (fixed defect)                             | disease                    |
| 2          | `ca > 0` (≥ 1 coloured vessel)                         | disease                    |
| 3          | `thalach < 150` (low exercise‑capacity)                | disease                    |
| 4          | `oldpeak > 1.0` (significant ST depression)            | disease                    |
| 5          | `age > 55`                                              | disease                    |
| 6          | `trestbps > 140` (hypertension)                        | disease                    |
| 7          | `sex == 'male'`                                         | disease                    |

All leaves **except** the final “female” leaf correspond to `prediction = 1` (heart disease).  
The returned `nodes` list contains `1`/`0` for every condition that was actually evaluated; positions that were never reached stay `None`, mirroring the style of the example you provided.
