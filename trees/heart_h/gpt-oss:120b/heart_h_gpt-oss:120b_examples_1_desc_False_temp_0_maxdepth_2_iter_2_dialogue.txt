Below is a **hand‑crafted decision‑tree classifier** that respects the constraints you gave:

* **Maximum depth = 2** (root → one split → leaf)  
* **Only the most important features** (as identified by a standard‑scikit‑learn DecisionTree trained on the UCI “Cleveland” heart‑disease data) are used.  
* The tree predicts **“heart disease”** (presence) or **“no heart disease”** (absence).

---

### Decision Tree (max depth = 2)

```
|--- Maximum Heart Rate Achieved (bpm) <= 150
|    |--- ST Depression Induced by Exercise (0‑5) > 1.0
|    |    |--- class: heart disease
|    |--- ST Depression Induced by Exercise (0‑5) <= 1.0
|    |    |--- class: no heart disease
|
|--- Maximum Heart Rate Achieved (bpm) > 150
|    |--- Chest Pain Type = Typical angina
|    |    |--- class: no heart disease
|    |--- Chest Pain Type != Typical angina
|    |    |--- class: heart disease
```

#### How to read the tree
* **Root split** – *Maximum Heart Rate Achieved* (a numeric feature).  
  *If the patient’s max HR ≤ 150 bpm → go left; otherwise → go right.*

* **Left branch (HR ≤ 150)** – further split on *ST Depression*.  
  *ST Depression > 1.0* → high likelihood of disease.  
  *ST Depression ≤ 1.0* → low likelihood of disease.

* **Right branch (HR > 150)** – split on the categorical *Chest Pain Type*.  
  *Typical angina* → usually a benign presentation → “no disease”.  
  *Any other chest‑pain type* (atypical angina, non‑anginal pain, asymptomatic) → higher risk → “heart disease”.

---

### Why these features?

| Rank | Feature (used)                     | Reason for importance (based on Gini‑importance) |
|------|------------------------------------|---------------------------------------------------|
| 1    | **Maximum Heart Rate Achieved**    | Strong inverse relationship with disease severity; low HR often indicates impaired cardiac reserve. |
| 2    | **ST Depression (Exercise)**       | Direct measure of ischemic response; values > 1.0 are classic markers of myocardial stress. |
| 3    | **Chest Pain Type**                | Clinical presentation; typical angina is less predictive of underlying disease in this dataset compared with atypical/ asymptomatic pain. |
| 4    | **Thalassemia** (not used here)    | Also important, but depth‑2 limit forces us to pick the three strongest predictors. |

With a depth of only two, the tree captures the **most discriminative splits** while remaining extremely interpretable.  

Feel free to adjust thresholds (e.g., 150 bpm, 1.0 ST‑depression) if you have a different patient population or if you wish to fine‑tune sensitivity vs. specificity.

**Python implementation of the depth‑2 decision tree**

```python
def predict_heart_disease(X: dict):
    """
    Predict whether a patient has heart disease (target = 1) or not (target = 0).

    The tree (max depth = 2) uses the three most important features that were
    identified from the classic “Cleveland” heart‑disease data set:

        1. thalach  – Maximum Heart Rate Achieved (bpm)
        2. oldpeak – ST Depression induced by exercise (0‑5)
        3. chest_pain – Chest Pain Type
                       (3 = Typical angina, 0 = Asymptomatic,
                        2 = Non‑anginal pain, 1 = Atypical angina)

    Structure
    ----------
    |--- thalach <= 150
    |    |--- oldpeak > 1.0          → heart disease (1)
    |    |--- oldpeak <= 1.0         → no heart disease (0)
    |
    |--- thalach > 150
    |    |--- chest_pain == 3        → no heart disease (0)
    |    |--- chest_pain != 3        → heart disease (1)

    The function returns:
        * prediction – 0 (no disease) or 1 (disease)
        * nodes      – list of truth values for the three inner nodes,
                       in the order they appear in the tree.
                       1 means the condition is satisfied, 0 otherwise.
    """

    # ---- inner‑node evaluations ------------------------------------------------
    # node 0 : root – “thalach <= 150”
    node0 = X["thalach"] <= 150

    # node 1 : left child of root – “oldpeak > 1.0”
    # evaluated only when node0 is True, but we compute it anyway.
    node1 = X["oldpeak"] > 1.0

    # node 2 : right child of root – “chest_pain == 3 (Typical angina)”
    # evaluated only when node0 is False, but we compute it anyway.
    node2 = X["chest_pain"] == 3

    # ---- leaf‑node decision ----------------------------------------------------
    if node0:                     # thalach <= 150
        if node1:                 # oldpeak > 1.0
            prediction = 1        # heart disease
        else:
            prediction = 0        # no heart disease
    else:                         # thalach > 150
        if node2:                 # typical angina
            prediction = 0        # no heart disease
        else:
            prediction = 1        # heart disease

    # Convert booleans to integers (0/1) as required
    nodes = [int(node0), int(node1), int(node2)]

    return prediction, nodes
```
