```python
def predict(X: dict):
    """
    Predicts the boxing round winner using a decision tree.

    Args:
        X (dict): A dictionary containing the feature values for a single round. 
                   Keys are feature names, and values are their corresponding values.

    Returns:
        tuple: A tuple containing:
            - The predicted winner (0 = Trinidad, 1 = de la Hoya).
            - A list of integers representing the truth values of the inner nodes 
              (1 if the condition is met, 0 otherwise).
    """

    nodes = []  # List to store the truth values of inner nodes

    # Node 1: Judge (Split based on Judge - prioritizing certain judges)
    # Assuming Judges 0, 1, 2 tend to favor Trinidad, others de la Hoya
    judge = X["Judge"]
    node1_condition = judge in [0, 1, 2]  # Trinidad favored judges
    nodes.append(int(node1_condition))

    if node1_condition:
        # Node 2: Official (Yes favors Trinidad)
        official = X["Official"]
        node2_condition = official == 1
        nodes.append(int(node2_condition))
        
        if node2_condition:
            prediction = 0  # Trinidad
        else:
            prediction = 1  # De la Hoya
    else:
        # Node 3: Round (Earlier rounds favor Trinidad)
        round_num = X["Round"]
        node3_condition = round_num <= 6
        nodes.append(int(node3_condition))

        if node3_condition:
            prediction = 0 #Trinidad
        else:
            prediction = 1 #De la Hoya
    
    return prediction, nodes
```

**Explanation:**

1.  **Feature Access:** The function takes a dictionary `X` as input, which contains the feature values for a given round.  It accesses these values using the feature names as keys.
2.  **Node 1: Judge:** This node splits based on the `Judge`. I've assumed that Judges 0, 1 and 2 are more likely to favor Trinidad.
3.  **Node 2: Official:** If the Judge is one of those favoring Trinidad, it checks if the round was officially judged (Official = 1). If so, it predicts Trinidad (0). Otherwise, De la Hoya (1).
4.  **Node 3: Round**: If the judge does not favor Trinidad, it checks the round number.  An assumption is made that in earlier rounds, Trinidad is favored (rounds 1 to 6).

5.  **Node Tracking:**  A list `nodes` stores the truth values (1 or 0) of the conditions evaluated at each inner node. This list is returned along with the prediction.
