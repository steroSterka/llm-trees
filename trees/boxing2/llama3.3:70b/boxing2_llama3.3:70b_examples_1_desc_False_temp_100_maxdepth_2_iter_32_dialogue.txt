```python
def predict(X: dict):
    """
    Decision Tree Function to Predict which boxer won the round.
    
    Parameters:
    X (dict): Dictionary containing features 'Judge', 'Official', 'Round'.
    
    Returns:
    prediction (int): 0 if Trinidad won, 1 if de la Hoya won.
    nodes (list): List of boolean values representing inner node conditions.
    """
    
    # Initialize nodes list with None
    nodes = 2 * [None]
    
    # Node 0: Check if Judge is G. Hamada or B. Logist (0 or 1)
    nodes[0] = X["Judge"] <= 1
    
    # Node 1: Check if Round is less than or equal to 6
    nodes[1] = X["Round"] <= 6
    
    # Prediction based on decision tree
    if nodes[0]:
        if nodes[1]:
            prediction = 0  # Trinidad wins in early rounds with G. Hamada or B. Logist
        else:
            prediction = 1  # de la Hoya wins in late rounds with G. Hamada or B. Logist
    else:
        if X["Official"] == 1:  # Official judge
            prediction = 1  # de la Hoya wins with other judges and official judge
        else:
            prediction = 0  # Trinidad wins with other judges and non-official judge
    
    # Convert boolean nodes to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes

# Example usage:
X = {
    "Judge": 0,  # G. Hamada
    "Official": 1,  # Official judge
    "Round": 5
}
prediction, nodes = predict(X)
print("Prediction:", prediction)  # 0 if Trinidad won, 1 if de la Hoya won
print("Nodes:", nodes)  # List of boolean values representing inner node conditions
```

This decision tree function uses the following logic:

- Node 0: If the judge is G. Hamada or B. Logist (Judge <= 1), proceed to Node 1.
- Node 1: If the round is less than or equal to 6, predict Trinidad wins; otherwise, predict de la Hoya wins.
- If the judge is not G. Hamada or B. Logist (Judge > 1), check if the judge is official.
  - If the judge is official, predict de la Hoya wins.
  - If the judge is not official, predict Trinidad wins.
