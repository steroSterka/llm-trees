```python
def predict_boxing_winner(X: dict):
    """
    Predicts which boxer won a round based on the given features.
    
    Parameters:
    X (dict): A dictionary containing the features 'Judge', 'Official', 'Round', and their respective values.
    
    Returns:
    prediction, nodes: The predicted winner of the round (0 = Trinidad, 1 = de la Hoya) and a list representing the truth values of the inner nodes.
    """
    # Initialize the list to store node truth values
    nodes = 2 * [None]
    
    # Node 0 condition: Judge is HBO-Lederman (3)
    nodes[0] = X["Judge"] == 3
    
    # Node 1 condition: Round is less than or equal to 6
    nodes[1] = X["Round"] <= 6
    
    if nodes[0]:
        if nodes[1]:
            prediction = 0  # Trinidad wins if HBO-Lederman judges and round is early (<= 6)
        else:
            prediction = 1  # de la Hoya wins if HBO-Lederman judges and round is late (> 6)
    else:
        if X["Official"] == 1:  # Official judge
            prediction = 0  # Trinidad wins if not HBO-Lederman but official judge
        else:
            prediction = 1  # de la Hoya wins otherwise
    
    return prediction, [int(node) for node in nodes]

# Example usage

    "Judge": 3,  # HBO-Lederman

print("Nodes:", nodes)  # List of truth values for inner nodes (1 if condition met, 0 otherwise)

```

This decision tree uses the judge and round as primary conditions to predict which boxer won a round. If HBO-Lederman is judging, the outcome depends on whether it's an early or late round.
