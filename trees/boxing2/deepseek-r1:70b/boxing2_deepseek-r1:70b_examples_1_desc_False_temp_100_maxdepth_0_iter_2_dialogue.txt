To solve this problem, we need to create a function that predicts an outcome based on given conditions and also tracks the evaluation of these conditions as boolean values (represented as 1 or 0). The function should return both the prediction and a list indicating which conditions were met.

### Approach
The approach involves creating a decision tree with two inner nodes:
1. Check if the value of "Official" is true.
2. If the first condition is false, check if the value of "Round" is less than or equal to 6.

Based on these checks, we will determine the prediction and track which conditions were evaluated. The function will return both the prediction result and a list indicating whether each condition was met (1) or not (0).

### Solution Code
```python
def predict(X):
    # Initialize all possible inner nodes to None
    nodes = [None, None]
    
    # Node 0: Check if Official is yes
    nodes[0] = X["Official"] == 1
    
    if nodes[0]:
        prediction = 0
    else:
        # Node 1: Check Round <=6
        nodes[1] = X["Round"] <= 6
        
        if nodes[1]:
            prediction = 1
        else:
            prediction = 0
    
    # Convert None to 0, others to int (True=1, False=0)
    nodes = [int(n) if n is not None else 0 for n in nodes]
    
    return prediction, nodes
```

### Explanation
The function starts by initializing a list `nodes` with two elements set to `None`. These elements will track whether each condition was met. 

1. **First Condition (Node 0)**: The function checks if the value of "Official" is true. If this condition is met, it sets `prediction` to 0 and stops further evaluations since the outcome is already determined.
2. **Second Condition (Node 1)**: If the first condition is not met, the function proceeds to check if the value of "Round" is less than or equal to 6. Depending on this result, it sets the `prediction` to either 1 or 0.

After evaluating the necessary conditions, the function converts the boolean values in the `nodes` list to integers (where `True` becomes 1 and `False` or `None` becomes 0). This conversion ensures that each condition's evaluation is accurately represented as a binary value.

This approach efficiently follows the decision tree structure, ensuring that only necessary conditions are evaluated while keeping track of all inner node evaluations for clarity.
