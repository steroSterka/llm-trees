To solve this problem, we need to create a decision tree classifier that predicts which boxer won each round based on specific features. The decision tree will be implemented as a Python function that takes a dictionary of features and returns both a prediction and a list of truth values representing the conditions evaluated in the inner nodes of the tree.

### Approach
1. **Decision Tree Structure**: We design a decision tree with a maximum depth of 2, focusing on two main features: `Round` and `Official`. The tree structure is as follows:
   - If the round number is less than or equal to 6 (`Round <= 6`):
     - If the judge is official (`Official == 1`), Trinidad wins.
     - Otherwise, De La Hoya wins.
   - If the round number is greater than 6 (`Round > 6`):
     - If the judge is official (`Official == 1`), De La Hoya wins.
     - Otherwise, Trinidad wins.

2. **Feature Encoding**: The `Official` feature is encoded as a binary value where 1 represents "Yes" (official judge) and 0 represents "No".

3. **Function Implementation**: The function will evaluate the conditions for each node in the decision tree, convert boolean results to integers, and return the prediction along with the list of truth values.

### Solution Code
```python
def predict(X: dict):
    nodes = [None, None]
    # First split: Check if Round <= 6
    nodes[0] = X['Round'] <= 6
    # Second split: Check if Official is 'Yes' (1)
    nodes[1] = X['Official'] == 1
    
    # Convert boolean values to integers for the nodes list
    nodes = [int(node) for node in nodes]
    
    # Determine prediction based on the decision tree logic
    if nodes[0]:
        if nodes[1]:
            prediction = 0  # Trinidad wins
        else:
            prediction = 1  # De La Hoya wins
    else:
        if nodes[1]:
            prediction = 1  # De La Hoya wins
        else:
            prediction = 0  # Trinidad wins
    
    return prediction, nodes
```

### Explanation
- **Decision Tree Logic**: The decision tree first checks the round number. If it's within the first six rounds, it then checks if the judge is official to determine the winner. For later rounds, it applies similar logic but with a different outcome based on whether the judge is official.
- **Node Evaluation**: Each condition evaluated in the decision tree nodes (round and official status) is converted from boolean values to integers (1 for true, 0 for false).
- **Prediction**: The function returns both the predicted winner (as an integer) and the list of truth values representing the evaluation of each inner node.

This approach efficiently classifies the winner of each round using a simple yet effective decision tree structure, ensuring clarity and interpretability.
