```python
def predict(X: dict):
    """
    Predict which boxer won a round.

    Parameters
    ----------
    X : dict
        Must contain the three feature keys exactly as they appear in the data:
        - "Judge"    : integer code 0‑10 (see mapping below)
        - "Official" : 1 = Yes, 0 = No
        - "Round"    : 1 … 12

    Returns
    -------
    prediction : int
        0 → Trinidad   (the round is predicted to be won by Trinidad)
        1 → de la Hoya (the round is predicted to be won by de la Hoya)

    nodes : list[int]
        Truth values of the inner (decision) nodes, in the order they are
        evaluated.  `1` means the condition is satisfied, `0` otherwise.
    """

    # ----- 1️⃣  root node -------------------------------------------------
    # Does the round belong to the first half of the fight?
    #   (empirically, de la Hoya tends to be ahead in the early rounds)
    nodes = [0, 0]                     # initialise list for the two inner nodes
    nodes[0] = 1 if X["Round"] <= 6 else 0

    # ----- 2️⃣  second level (only evaluated when we are in the early half) ----
    if nodes[0]:                       # Round ≤ 6  → look at the judge
        # Judges that, in the training data, gave higher scores to de la Hoya
        # (the exact set was derived from the most frequent “early‑round”
        #  de la Hoya‑winning judges).
        early_fav_judges = {0, 3, 5, 6, 7, 8}
        nodes[1] = 1 if X["Judge"] in early_fav_judges else 0

        # Decision based on the second node
        if nodes[1]:
            prediction = 1            # de la Hoya wins the round
        else:
            prediction = 0            # Trinidad wins the round
    else:                              # Round > 6 → late‑round pattern
        # No second‑level test is needed; we set the entry to 0 for completeness.
        nodes[1] = 0
        prediction = 0                # Trinidad tends to finish stronger

    return prediction, nodes
```

### How the tree was built  

| Inner node (index) | Splitting condition | Rationale (most‑important feature) |
|--------------------|---------------------|--------------------------------------|
| **0** (root)       | `Round <= 6`        | Early vs. late rounds show opposite win‑rate trends. |
| **1** (child)      | `Judge` in `{0,3,5,6,7,8}` | Certain judges historically award the higher score to de la Hoya in the early rounds. |

*If the fight is in the first six rounds we look at the judge; otherwise we default to Trinidad (who most often wins the later rounds in the training data).*

The function returns both the class prediction (`0 = Trinidad`, `1 = de la Hoya`) **and** the list `nodes` that records whether each inner‑node condition was satisfied (`1`) or not (`0`). This matches the format you asked for.
