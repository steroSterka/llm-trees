### Interpreting the tree

* **If the score is coming from a *non‑official* judge**, the model predicts that **de la Hoya** will be the round winner.  
* **If the score is from an *official* judge**, we first look at **who** the judge is:  
  * The three judges **G. Hamada, B. Logist, J. Roth** have historically favoured **Trinidad** in every round.  
  * All other official judges are more “neutral”; for them the **round number** matters: early rounds (1‑6) lean toward **de la Hoya**, while rounds 7‑12 tend to be awarded to **Trinidad**.

### Why these features are “most important”

1. **Official judge** is a binary flag that cleanly separates two scoring regimes, giving the biggest impurity reduction.  
2. **Judge identity** captures systematic bias that a handful of judges exhibit.  
3. **Round** is a continuous variable that, once the major biases are accounted for, explains the remaining variance (fighters often gain momentum as the fight progresses).

```python
def predict(X: dict):
    """
    Predict which fighter won a given round.

    Parameters
    ----------
    X : dict
        A dictionary that contains the three input features exactly as they appear
        in the dataset:

        - "Judge"      : int  (0 = G. Hamada, 1 = B. Logist, 2 = J. Roth,
                              3 = HBO‑Lederman, 4 = Sportsticker,
                              5 = Los Angeles Times‑Kawakami, 6 = USA Today,
                              7 = Associated Press, 8 = Las Vegas Review‑Journal,
                              9 = Los Angeles Times‑Springer, 10 = van de Wiele)

        - "Official"   : int  (1 = Yes, 0 = No) – tells whether the judge is an
                          official judge.

        - "Round"      : int  (1 … 12) – the round number.

    Returns
    -------
    prediction : int
        0 → Trinidad won the round  
        1 → de la Hoya won the round

    nodes : list[int]
        Truth values (1 = True, 0 = False) of the three inner‑node conditions,
        in the order they are evaluated in the tree:

        0.  Official == 0 ?
        1.  Judge ∈ {0, 1, 2} ?
        2.  Round ≤ 6 ?
    """

    # -------------------------------------------------
    # 1️⃣  Evaluate inner‑node conditions (store as 0/1)
    # -------------------------------------------------
    nodes = [None] * 3                     # placeholder for three inner nodes

    # node 0 : is the judge *not* official ?
    nodes[0] = 1 if X["Official"] == 0 else 0

    # node 1 : (only relevant if node0 == 0) is the judge one of the three
    #          that historically favoured Trinidad ?
    nodes[1] = 1 if X["Judge"] in (0, 1, 2) else 0

    # node 2 : (only relevant if node0 == 0 and node1 == 0) early round ?
    nodes[2] = 1 if X["Round"] <= 6 else 0

    # -------------------------------------------------
    # 2️⃣  Follow the tree to obtain the prediction
    # -------------------------------------------------
    if nodes[0] == 1:                 # Official == 0  → de la Hoya
        prediction = 1
    else:                             # Official == 1
        if nodes[1] == 1:             # Judge ∈ {0,1,2} → Trinidad
            prediction = 0
        else:                         # Other official judges
            if nodes[2] == 1:         # Round ≤ 6 → de la Hoya
                prediction = 1
            else:                     # Round > 6 → Trinidad
                prediction = 0

    return prediction, nodes
```

### How the function works

| Node index | Condition (human readable)                     | Python code (`nodes[i]`) | Meaning when **1** |
|------------|-----------------------------------------------|--------------------------|---------------------|
| 0          | *Official judge?* (`Official == 0`)           | `nodes[0] = 1 if X["Official"] == 0 else 0` | The judge is **not** an official judge → de la Hoya wins. |
| 1          | *Judge is one of the three “Trinidad‑biased”* (`Judge ∈ {0,1,2}`) | `nodes[1] = 1 if X["Judge"] in (0,1,2) else 0` | The (official) judge historically scores for **Trinidad**. |
| 2          | *Early round?* (`Round ≤ 6`)                  | `nodes[2] = 1 if X["Round"] <= 6 else 0` | In early rounds the default swings to **de la Hoya**; later rounds to **Trinidad**. |

The list `nodes` therefore records the truth value of every inner decision made while traversing the tree, exactly as required.
