```python
def predict(X: dict):
    """
    Predicts company bankruptcy based on financial features using a decision tree.

    Args:
        X (dict): A dictionary containing the financial features.  
                   Keys must be: 'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', 'BVE/BVL'

    Returns:
        tuple: A tuple containing:
            - prediction (int): 0 if not bankrupt, 1 if bankrupt.
            - nodes (list): A list of boolean values representing the truth values
                             of the inner nodes encountered during the prediction.
    """
    nodes = []

    # Node 1: WC/TA <= 0.1
    wc_ta = X['WC/TA']
    node1_condition = wc_ta <= 0.1
    nodes.append(node1_condition)

    if node1_condition:
        prediction = 1  # Bankrupt
    else:
        # Node 2: EBIT/TA <= 0.05
        ebit_ta = X['EBIT/TA']
        node2_condition = ebit_ta <= 0.05
        nodes.append(node2_condition)
        
        if node2_condition:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not bankrupt

    return prediction, nodes
```

**Explanation:**

1.  **Function Definition:**
    *   The `predict` function takes a dictionary `X` as input, representing the financial features of a company.
2.  **Node 1: WC/TA <= 0.1**
    *   It checks if the `WC/TA` (Working Capital / Total Assets) ratio is less than or equal to 0.1.  This is the root node.  The result (True/False) is appended to the `nodes` list.
3.  **Root Node Logic:**
    *   If the condition at Node 1 is `True` (WC/TA is very low), the company is predicted to be bankrupt (`prediction = 1`).
4.  **Node 2 (If WC/TA > 0.1):**
    *   If the WC/TA ratio is greater than 0.1, it proceeds to Node 2.
    *   Node 2 checks if the `EBIT/TA` (Earnings Before Interest and Tax / Total Assets) ratio is less than or equal to 0.05.
    *   The result of this condition is appended to the `nodes` list.
5.  **Node 2 Logic:**
    *   If `EBIT/TA` is less than or equal to 0.05, the company is predicted to be bankrupt.
    *   Otherwise (EBIT/TA is greater than 0.05), the company is predicted to not be bankrupt.
6.  **Return Values:**
    *   The function returns a tuple containing the `prediction` (0 or 1) and the `nodes` list (a list of booleans representing the truth values of the conditions at each inner node).

**Example Usage:**

```python

    'WC/TA': 0.05,
    'RE/TA': 0.2,
    'EBIT/TA': 0.03,
    'S/TA': 0.5,

}

prediction, nodes = predict(company_data)
print(f"Prediction: {prediction}")  # Output: Prediction: 1

```

In this example:

*   The prediction is 1 (bankrupt) because `WC/TA` is less than or equal to 0.1.
*   The `nodes` list is `[True, False]` because the condition at Node 1 (`WC/TA <= 0.1`) is `True`, and the condition at Node 2 (`EBIT/TA <= 0.05`) is `False`.
