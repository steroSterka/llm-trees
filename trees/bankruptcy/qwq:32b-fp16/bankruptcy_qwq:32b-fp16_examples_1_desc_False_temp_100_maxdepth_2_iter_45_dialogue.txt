```python
def predict(X: dict):
    nodes = [None, None]
    # First node: Check if EBIT/TA is too low
    nodes[0] = X["EBIT/TA"] <= 0.05
    # Second node: Check if WC/TA is too low if EBIT/TA was low
    if nodes[0]:
        nodes[1] = X["WC/TA"] <= 0.1
        prediction = 1 if nodes[1] else 0
    else:
        prediction = 0  # EBIT is sufficient, so no bankruptcy
    return prediction, nodes
```

### Explanation:
1. **First Node (nodes[0])** checks if the EBIT (Earnings Before Interest and Taxes) over Total Assets ratio is less than or equal to 0.05. A low EBIT/TA indicates poor profitability.
2. **Second Node (nodes[1])** is only evaluated if the first node's condition is met (EBIT/TA is low). It checks if the Working Capital over Total Assets ratio is less than or equal to 0.1, indicating low liquidity.
3. **Prediction Logic**:
   - If both conditions are true (low profitability and low liquidity), the prediction is 1 (bankruptcy risk).
   - If only the first condition is true (low profitability but sufficient liquidity), the prediction is 0 (no bankruptcy risk).
   - If the first condition is false (sufficient profitability), the prediction is 0 regardless of other factors.

This decision tree uses profitability and liquidity as key indicators of bankruptcy risk, applying thresholds based on financial health benchmarks.
