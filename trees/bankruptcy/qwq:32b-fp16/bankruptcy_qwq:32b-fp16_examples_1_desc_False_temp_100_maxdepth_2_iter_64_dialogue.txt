```python
def predict(X):
    nodes = [0, 0]
    
    # First node: WC/TA <= 0.25 (low working capital indicates risk)
    if X['WC/TA'] <= 0.25:
        nodes[0] = 1
        # Second node: RE/TA <= 0.1 (low retained earnings indicates risk)
        if X['RE/TA'] <= 0.1:
            nodes[1] = 1
            prediction = 1  # Predict bankruptcy
        else:
            nodes[1] = 0
            prediction = 0  # No bankruptcy
    else:
        prediction = 0  # No bankruptcy
    
    return prediction, nodes
```

### Explanation:
1. **First Node (WC/TA):** Checks if the Working Capital to Total Assets ratio is ≤ 0.25. A lower WC/TA indicates potential liquidity issues.
2. **Second Node (RE/TA):** If the first condition is true, this node checks the Retained Earnings to Total Assets ratio. A value ≤ 0.1 suggests insufficient retained earnings, increasing bankruptcy risk.
