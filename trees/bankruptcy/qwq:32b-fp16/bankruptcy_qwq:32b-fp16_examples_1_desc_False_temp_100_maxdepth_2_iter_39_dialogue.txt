
2. **Second Check (WC/TA):** If EBIT/TA is not problematic, it checks if WC/TA is ≤ 0.2. Low working capital suggests liquidity issues, resulting in a prediction of default (1).
3. **No Default:** If neither condition is met, the prediction is no default (0).
