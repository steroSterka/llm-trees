To solve this problem, we need to create a decision tree model that predicts bankruptcy based on two financial ratios: BVE/BVL (Book Value to Market Value) and WC/TA (Working Capital to Total Assets). The decision tree will use simple thresholds to determine the prediction.

### Approach
1. **Problem Analysis**: The goal is to predict bankruptcy (1) or non-bankruptcy (0) based on two financial ratios. We assume that a low BVE/BVL ratio (≤0.95) indicates a higher risk of bankruptcy. If BVE/BVL is not low, we then check if WC/TA is very low (≤0.1), which might also indicate bankruptcy risk.
2. **Model Design**: The decision tree will first check the BVE/BVL ratio. If it's below the threshold, bankruptcy is predicted. If not, it checks the WC/TA ratio. If WC/TA is very low, bankruptcy is predicted; otherwise, it is not.
3. **Implementation**: We implement this logic using a simple Python function that evaluates these conditions step-by-step.

### Solution Code
```python
def predict(X):
    nodes = [False, False]
    # Check BVE/BVL <= 0.95 (first condition)
    nodes[0] = X['BVE/BVL'] <= 0.95
    # Check WC/TA <= 0.1 (second condition)
    nodes[1] = X['WC/TA'] <= 0.1
    
    if nodes[0]:
        prediction = 1  # Bankruptcy if BVE/BVL is too low
    else:
        if nodes[1]:
            prediction = 1  # Bankruptcy if WC/TA is too low
        else:
            prediction = 0  # Non-bankruptcy
    
    return prediction, nodes
```

### Explanation
- **Step 1**: Evaluate the BVE/BVL ratio. If it is ≤0.95, the model immediately predicts bankruptcy (1) because a low book value relative to market value is a strong indicator.
- **Step 2**: If the BVE/BVL ratio is not low, the model then checks the WC/TA ratio. If this is ≤0.1, indicating very low liquidity, the model predicts bankruptcy (1).
- **Step 3**: If neither condition is met, the model predicts non-bankruptcy (0).

This approach uses a straightforward decision tree structure with two nodes, making it easy to interpret and apply based on the given financial metrics. The thresholds (0.95 and 0.1) are chosen as example values and can be adjusted based on further analysis or domain knowledge.
