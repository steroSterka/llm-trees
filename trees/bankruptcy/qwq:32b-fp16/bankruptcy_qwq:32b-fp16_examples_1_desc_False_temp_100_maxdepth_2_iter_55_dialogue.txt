To address the problem, we need to design a simple decision tree classifier using two features to predict bankruptcy. The decision tree should have a depth of 2, meaning there are two decision nodes along the longest path from the root to a leaf.

### Approach
1. **Feature Selection**: Choose two financial ratios that are strong indicators of bankruptcy. Here, we use:
   - **WC/TA (Working Capital to Total Assets)**: A low ratio may indicate liquidity issues.
   - **BVE/BVL (Book Value of Equity to Book Value of Liabilities)**: A ratio less than 1 suggests negative net worth, a strong bankruptcy indicator.

2. **Decision Nodes**:
   - **First Node (Root)**: Check if WC/TA is less than or equal to 0.2. If true, predict bankruptcy (1).
   - **Second Node**: If WC/TA is above 0.2, check if BVE/BVL is less than or equal to 1.0. If true, predict bankruptcy (1); otherwise, predict non-bankruptcy (0).

### Solution Code
```python
def predict(X):
    nodes = [None, None]
    # First decision node: WC/TA <= 0.2
    nodes[0] = X["WC/TA"] <= 0.2
    if nodes[0]:
        return 1, nodes
    
    # Second decision node: BVE/BVL <= 1.0
    nodes[1] = X["BVE/BVL"] <= 1.0
    return (1 if nodes[1] else 0), nodes
```

### Explanation
- **First Decision Node**: The function first checks if the Working Capital to Total Assets ratio (WC/TA) is ≤ 0.2. If true, the prediction is bankruptcy (1).
- **Second Decision Node**: If the first condition is false, the function then evaluates the Book Value of Equity to Book Value of Liabilities ratio (BVE/BVL). If this ratio is ≤ 1.0, it indicates negative net worth, leading to a bankruptcy prediction (1). Otherwise, it predicts non-bankruptcy (0).

This approach ensures the decision tree has a depth of 2, with each decision node addressing a critical financial health indicator. The function returns both the prediction and the evaluation results of the nodes for transparency.
