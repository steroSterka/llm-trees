To address the problem of predicting bankruptcy using a decision tree model with given financial ratios, we can construct a simple decision tree with two decision nodes. The decision nodes are based on the Working Capital to Total Assets (WC/TA) ratio and the Sales to Total Assets (S/TA) ratio. The goal is to determine if a company is likely to be bankrupt (1) or not (0) based on these ratios.

### Approach
1. **First Decision Node (WC/TA ≤ 0.0)**: 
   - If the Working Capital to Total Assets ratio is less than or equal to zero, it indicates negative working capital, which is a strong sign of financial distress. In this case, the prediction is bankruptcy (1).
   
2. **Second Decision Node (S/TA ≤ 0.1)**:
   - If the first condition is not met (i.e., WC/TA is positive), we then check the Sales to Total Assets ratio. A low sales-to-assets ratio (≤0.1) might indicate poor revenue generation relative to assets, suggesting potential bankruptcy. If this condition is met, the prediction is bankruptcy (1). Otherwise, the prediction is no bankruptcy (0).

### Solution Code
```python
def predict(X):
    nodes = []
    # First node: WC/TA <= 0.0
    nodes.append(X['WC/TA'] <= 0.0)
    # Second node: S/TA <= 0.1
    nodes.append(X['S/TA'] <= 0.1)
    
    if nodes[0]:
        prediction = 1  # Bankrupt
    else:
        if nodes[1]:
            prediction = 1
        else:
            prediction = 0  # Not bankrupt
    return prediction, nodes
```

### Explanation
- **WC/TA Check**: The first node checks if the company has negative working capital. If true, it is classified as bankrupt.
- **S/TA Check**: If the working capital is positive, the second node evaluates the sales-to-assets ratio. A low ratio here (≤0.1) might still indicate severe financial issues, leading to a bankruptcy prediction.
- **Output**: The function returns a tuple where the first element is the prediction (1 for bankruptcy, 0 otherwise) and the second element is a list indicating the results of each decision node.

This approach uses two simple yet effective financial ratios to make a prediction, ensuring clarity and interpretability in the decision-making process.
