```python
def predict(X: dict):
    nodes = [0, 0]
    # Node 0: Check if Working Capital over Total Assets is low (<=0.2)
    nodes[0] = X["WC/TA"] <= 0.2
    # Node 1: Check if EBIT over Total Assets is low (<=0.03) only if Node 0 is true
    nodes[1] = X["EBIT/TA"] <= 0.03 if nodes[0] else False
    
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Both conditions indicate higher risk of bankruptcy
        else:
            prediction = 0  # EBIT is okay, so lower risk
    else:
        prediction = 0  # Working Capital is sufficient, lower risk
    
    return prediction, nodes
```

### Explanation:
1. **Node 0 Check (WC/TA ≤ 0.2):** 
   - This evaluates whether the ratio of working capital to total assets is low. A low ratio might indicate liquidity issues, which is a red flag for bankruptcy risk.

2. **Node 1 Check (EBIT/TA ≤ 0.03 if Node 0 is True):**
   - If Node 0 is true (low working capital), this checks the profitability via EBIT (Earnings Before Interest and Taxes) over total assets. A low EBIT/TA ratio suggests poor profitability, further increasing bankruptcy risk.

3. **Prediction Logic:**
   - **Both conditions (Nodes 0 and 1) true:** High risk (1), as both liquidity and profitability are weak.
   - **Node 0 true but Node 1 false:** Moderate risk (0), as liquidity is an issue but profitability is acceptable.
   - **Node 0 false:** Low risk (0), since working capital is sufficient, regardless of EBIT.

This structure prioritizes critical financial health indicators and uses a stepwise approach to assess bankruptcy risk based on their interplay.
