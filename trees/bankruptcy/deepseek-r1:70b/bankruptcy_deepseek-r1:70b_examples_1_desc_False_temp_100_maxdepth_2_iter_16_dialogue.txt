If only the first condition is met but not the second, it survived (prediction = 0). If EBIT/TA > 0.15, regardless of other factors, the company survived.

Here's a Python function that implements your decision tree:

```python
def predict(X: dict):
    nodes = 2 * [None]
    
    # First condition: EBIT/TA <= 0.15
    ebit_condition = X["EBIT/TA"] <= 0.15
    
    if ebit_condition:
        # Second condition: WC/TA <= 0.20
        wc_condition = X["WC/TA"] <= 0.20
        
        nodes[0] = int(ebit_condition)
        nodes[1] = int(wc_condition)
        
        prediction = 1 if (ebit_condition and wc_condition) else 0
    else:
        # Survived if EBIT/TA > 0.15
        nodes[0] = int(ebit_condition)
        nodes[1] = 0
        
        prediction = 0

    return prediction, nodes
```

### Explanation:

- The function `predict` takes a dictionary `X` with the feature keys as input.
- It initializes a list called `nodes` to store whether each condition in the decision tree is satisfied (1 if true, 0 otherwise).
- The first condition checks if EBIT/TA <= 0.15.
  - If true, it proceeds to check the second condition: WC/TA <= 0.20.
    - If both conditions are true, the prediction is that the company went bankrupt (`prediction = 1`).
    - If only the first condition is true but not the second, the prediction is that the company survived (`prediction = 0`).
- If the first condition (EBIT/TA <= 0.15) is false, it means EBIT/TA > 0.15, and we classify the company as survived (`prediction = 0`).
