```python
def predict(X: dict):
    nodes = [None, None]  # Initialize list for two inner node conditions
    
    # First condition: Check if Working Capital/Total Assets is less than or equal to 0.15
    wc_ta_condition = X['WC/TA'] <= 0.15
    nodes[0] = 1 if wc_ta_condition else 0
    
    if wc_ta_condition:
        # Second condition under the first subtree: Check Retained Earnings/Total Assets
        re_ta_condition = X['RE/TA'] <= -0.20
        nodes[1] = 1 if re_ta_condition else 0
    else:
        # Second condition under the second subtree: Check Sales/Total Assets
        s_ta_condition = X['S/TA'] <= 0.40
        nodes[1] = 1 if s_ta_condition else 0
    
    # Determine the final prediction based on the conditions
    if wc_ta_condition:
        prediction = 1 if re_ta_condition else 0
    else:
        prediction = 1 if s_ta_condition else 0
    
    return prediction, nodes
```

### Explanation:

- **Initialization:** The function starts by initializing a list `nodes` with two elements set to `None`. This list will store whether each inner node condition was satisfied (1) or not (0).

- **First Condition:** It checks if the ratio of Working Capital to Total Assets (`WC/TA`) is less than or equal to 0.15. The result of this condition is stored in `nodes[0]`.

- **Second Condition:** Depending on whether the first condition was true, it proceeds to check either Retained Earnings/Total Assets (`RE/TA`) or Sales/Total Assets (`S/TA`). Specifically:
  - If `WC/TA` was ≤ 0.15, it checks if `RE/TA` is ≤ -0.20 and stores the result in `nodes[1]`.
  - Otherwise, it checks if `S/TA` is ≤ 0.40 and stores the result in `nodes[1]`.

- **Prediction:** The final prediction of whether the company went bankrupt (1) or not (0) is determined based on these conditions.

This function accurately represents the decision tree logic, ensuring that each inner node's condition is evaluated appropriately to classify the bankruptcy status of a company.
