```python
def predict(X: dict):
    nodes = [None, None]
    
    # First condition: WC/TA <= 0.25
    nodes[0] = X['WC/TA'] <= 0.25
    
    if nodes[0]:
        # Second condition: RE/TA <= -0.20
        nodes[1] = X['RE/TA'] <= -0.20
        
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    else:
        # Second condition: S/TA <= 1.10
        nodes[1] = X['S/TA'] <= 1.10
        
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

This function first checks the liquidity condition using 'WC/TA'. If the company's working capital to total assets ratio is below or equal to 0.25, it then evaluates the profitability through 'RE/TA'. A negative retained earnings to total assets ratio further indicates potential bankruptcy. If either condition is not met, the function assesses operational efficiency via 'S/TA', with lower sales relative to assets signaling possible financial distress.
