To create a Python function that implements the decision tree for classifying whether a company went bankrupt based on financial features, we will follow these steps:

1. **Evaluate Inner Nodes**: Compute the conditions for each inner node in the decision tree and store their boolean results in a list. Convert these booleans to integers (1 for True, 0 for False) as required.

2. **Determine Prediction**: Use the evaluated conditions to make the final prediction according to the structure of the decision tree.

Here is the implementation:

```python
def predict(X: dict):
    nodes = [None] * 2  # Initialize a list to hold the truth values of inner nodes
    
    # Evaluate the first inner node condition
    nodes[0] = X['BVE/BVL'] <= 0.80
    
    # Evaluate the second inner node condition
    nodes[1] = X['EBIT/TA'] <= 0.10
    
    if nodes[0]:
        prediction = 1  # Company is classified as bankrupt
    else:
        if nodes[1]:
            prediction = 1  # Company is classified as bankrupt
        else:
            prediction = 0  # Company is not bankrupt
            
    return prediction, [int(nodes[0]), int(nodes[1])]
```

**Explanation:**

- **Inner Node Evaluation**: The function first evaluates the two inner node conditions based on the provided financial ratios. The results of these evaluations are stored in a list called `nodes`.
  
- **Conversion to Integers**: The boolean values in `nodes` are converted to integers (1 for True, 0 for False) to meet the requirement of returning a list of truth values as 1s and 0s.

- **Prediction Logic**: The function then uses these evaluated conditions to determine whether the company went bankrupt. If the first condition (`BVE/BVL <= 0.80`) is met, it directly classifies the company as bankrupt. Otherwise, it checks the second condition (`EBIT/TA <= 0.10`) to make the final classification.

This function accurately reflects the structure of the decision tree and returns both the prediction and the list of evaluated inner node conditions in the required format.
