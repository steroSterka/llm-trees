Here's a Python function that implements the decision tree logic to predict whether a company went bankrupt based on the given financial features:

```python
def predict(X: dict) -> tuple:
    """
    Predicts whether a company went bankrupt using a decision tree classifier.

    Args:
        X (dict): A dictionary containing the feature values. The keys must be:
            'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', 'BVE/BVL'

    Returns:
        tuple: A tuple where the first element is the prediction (0 for not bankrupt, 1 for bankrupt)
              and the second element is a list of truth values for each inner node condition.
    """

    # Initialize nodes to track the conditions
    nodes = [None, None]  # Two inner nodes in this tree

    # First decision: EBIT/TA <= 0.05?
    ebit_ta = X['EBIT/TA']
    nodes[0] = ebit_ta <= 0.05

    if nodes[0]:
        # If condition met, company is bankrupt
        prediction = 1
    else:
        # Check the second condition: WC/TA <= 0.10?
        wc_ta = X['WC/TA']
        nodes[1] = wc_ta <= 0.10

        if nodes[1]:
            prediction = 1
        else:
            prediction = 0

    return (prediction, nodes)
```

### Explanation of the Function:

1. **Function Definition:**
   - The function `predict` takes a dictionary `X` as input, which contains the feature values for a company.

2. **Node Initialization:**
   - A list `nodes` is initialized with two elements set to `None`. This list will store boolean values representing whether each condition in the decision tree was met (1 if True, 0 if False).

3. **First Decision Node (EBIT/TA):**
   - Extracts the value of 'EBIT/TA' from the input dictionary.
   - Evaluates if this value is less than or equal to 0.05 and stores the result in `nodes[0]`.
   
4. **Second Decision Node (WC/TA) if Necessary:**
   - If the first condition (`nodes[0]`) is True, the company is classified as bankrupt (prediction = 1).
   - If False, it proceeds to evaluate the second condition using 'WC/TA'.
   - Evaluates if 'WC/TA' is less than or equal to 0.10 and stores this result in `nodes[1]`.

5. **Prediction Based on Nodes:**
   - Uses the results from the nodes to determine the final prediction.
   - Returns a tuple containing the prediction (0 or 1) and the list of node evaluations.
