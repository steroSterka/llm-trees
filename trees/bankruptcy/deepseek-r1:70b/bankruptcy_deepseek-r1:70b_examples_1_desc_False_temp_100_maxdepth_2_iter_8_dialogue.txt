Here's a Python function that implements the decision tree logic:

```python
def predict(X):
    ebit_ta = X['EBIT/TA']
    bve_bvl = X['BVE/BVL']

    node0 = ebit_ta <= 0.15
    node1 = bve_bvl <= 0.25

    nodes = [int(node0), int(node1)]

    if node0:
        prediction = 1 if node1 else 0
    else:
        prediction = 0

    return prediction, nodes
```

**Explanation:**
- The function takes a dictionary `X` containing the features.
- It extracts and evaluates the two inner nodes (`EBIT/TA` and `BVE/BVL`) against their respective thresholds.
- Each node's condition is stored as an integer (1 for True, 0 for False).
- Based on the decision tree logic, it determines whether the company went bankrupt (1) or not (0).
- The function returns both the prediction and a list of the inner nodes' truth values.
