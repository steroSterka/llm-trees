Here's a structured Python function that implements the decision tree logic as described:

```python
def predict(X: dict):
    nodes = [None, None]
    
    # First condition: Working Capital/Total Assets <= 0.20
    nodes[0] = X['WC/TA'] <= 0.20
    
    if nodes[0]:
        prediction = 1  # Bankrupt
    else:
        # Second condition: Retained Earnings/Total Assets <= 0.15
        nodes[1] = X['RE/TA'] <= 0.15
        
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Non-Bankrupt
    
    return prediction, nodes
```

This function evaluates the financial health of a company based on two key ratios:
1. **Working Capital to Total Assets (WC/TA)**: This ratio indicates the company's ability to use its current assets to repay short-term liabilities. A lower ratio may suggest liquidity issues.
2. **Retained Earnings to Total Assets (RE/TA)**: This ratio reflects the company's profitability and reinvestment policy. Lower retained earnings can indicate poor financial health.

The function returns:
- `prediction`: 1 if the company is predicted to go bankrupt, 0 otherwise.
- `nodes`: A list where each element is a boolean indicating whether the condition at each decision node was met (True/False).
