To create a Python function that predicts whether a company went bankrupt based on the given financial features using a decision tree of maximum depth 2, follow these steps:

### Approach
The decision tree is structured to prioritize two key financial metrics:
1. **EBIT/TA (Earnings Before Interest and Tax to Total Assets)**: This metric assesses a company's operational profitability. If EBIT/TA is less than or equal to zero, the company is classified as bankrupt.
2. **BVE/BVL (Book Value of Equity to Book Value of Liabilities)**: For companies with positive EBIT/TA, this metric evaluates solvency. A ratio of 1 or below indicates higher financial risk and potential bankruptcy.

The function will:
1. Evaluate the first condition based on EBIT/TA.
2. If the first condition is met, classify the company as bankrupt.
3. If not, evaluate the second condition based on BVE/BVL to determine the final classification.
4. Return both the prediction (0 for non-bankrupt, 1 for bankrupt) and a list of boolean values indicating whether each condition was met.

### Solution Code
```python
def predict(X: dict):
    nodes = [None, None]  # Initialize with two inner node conditions
    
    # First condition: EBIT/TA <= 0
    ebit_ta_threshold = 0
    nodes[0] = (X['EBIT/TA'] <= ebit_ta_threshold)
    
    # Second condition: BVE/BVL <= 1
    bve_bvl_threshold = 1
    nodes[1] = (X['BVE/BVL'] <= bve_bvl_threshold)
    
    prediction = None
    
    if nodes[0]:
        prediction = 1  # Bankrupt if EBIT/TA is non-positive
    else:
        if nodes[1]:
            prediction = 1  # Bankrupt if BVE/BVL indicates high risk
        else:
            prediction = 0  # Non-bankrupt if both conditions not met
    
    # Convert boolean values to integers for the nodes list
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
```

### Explanation
1. **Initialization**: The `nodes` list is initialized to keep track of whether each condition in the decision tree is satisfied.
2. **First Condition (EBIT/TA)**: The function checks if EBIT/TA is less than or equal to zero. If true, it sets the prediction to 1 (bankrupt).
3. **Second Condition (BVE/BVL)**: If the first condition is not met, the function evaluates BVE/BVL. A value of 1 or below results in a classification of bankrupt.
4. **Prediction and Nodes**: The boolean values of the conditions are converted to integers (0 for False, 1 for True) and returned along with the final prediction.

This structured approach efficiently combines profitability and solvency metrics to classify whether a company is at risk of bankruptcy based on its financial health.
