Here's a function that predicts whether a company will go bankrupt based on its financial metrics using a decision tree of depth 2:

```python
def predict(X):
    # Evaluate root node condition: EBIT/TA <= 0
    ebit_condition = X['EBIT/TA'] <= 0
    
    nodes = [ebit_condition]  # Start the list with the root condition
    
    if ebit_condition:
        # If root condition is true, evaluate BVE/BVL <= 1
        bv_el_condition = X['BVE/BVL'] <= 1
        nodes.append(bv_el_condition)
        
        if bv_el_condition:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    else:
        # If root condition is false, evaluate WC/TA >= 0.2
        wc_ta_condition = X['WC/TA'] >= 0.2
        nodes.append(wc_ta_condition)
        
        if wc_ta_condition:
            prediction = 0  # Not Bankrupt
        else:
            prediction = 1  # Bankrupt
    
    return prediction, nodes
```

**Explanation:**

- **Root Node (EBIT/TA <= 0):** The first condition checks if the company's Earnings Before Interest and Taxes divided by Total Assets is less than or equal to zero. This indicates poor profitability relative to assets.
  
- **Left Child (BVE/BVL <= 1):** If the root condition is true, we then check if the Book Value of Equity divided by Market Value of Equity is less than or equal to one. A value ≤1 suggests that the market valuation is not significantly higher than the book value, which could indicate financial distress.
  
- **Right Child (WC/TA >= 0.2):** If the root condition is false (EBIT/TA > 0), we check if Working Capital divided by Total Assets is at least 0.2. A lower ratio might imply liquidity issues.

The function returns a prediction (1 for bankruptcy, 0 otherwise) and a list of evaluated conditions (`nodes`), capturing the decision path taken through the tree.
