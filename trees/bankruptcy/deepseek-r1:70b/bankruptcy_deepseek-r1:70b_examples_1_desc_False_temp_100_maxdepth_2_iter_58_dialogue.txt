```python
def predict(X: dict):
    # Initialize the list to hold truth values of inner nodes
    nodes = [None, None]  # For two splits
    
    # Root split (First condition)
    ebit_ta = X['EBIT/TA']
    nodes[0] = ebit_ta <= 0.05

    # Second split on the right branch
    s_ta = X['S/TA']
    nodes[1] = s_ta <= 0.30

    # Determine prediction based on the tree structure
    if nodes[0]:
        prediction = 1  # Bankrupt (EBIT/TA is low)
    else:
        if nodes[1]:
            prediction = 1  # Bankrupt (Sales/Total Assets are low despite higher EBIT/TA)
        else:
            prediction = 0  # Not bankrupt

    return prediction, nodes
```

This function first evaluates the conditions for both inner nodes and then uses these evaluations to determine the final prediction. The thresholds used are reasonable and based on common financial metrics for assessing a company's health.
