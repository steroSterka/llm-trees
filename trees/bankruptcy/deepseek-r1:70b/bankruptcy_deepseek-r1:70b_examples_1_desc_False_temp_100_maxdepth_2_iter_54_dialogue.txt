Here is the Python function that implements the decision tree classifier based on the specified financial features to predict whether a company went bankrupt or not:

```python
def predict(X: dict):
    # Compute node conditions for internal nodes
    nodes = [
        X["WC/TA"] <= 0.20,  # First internal node condition
        X["EBIT/TA"] <= 0.10   # Second internal node condition
    ]
    
    if nodes[0]:
        prediction = 1  # Company is classified as bankrupt
    else:
        if nodes[1]:
            prediction = 1  # Company is classified as bankrupt
        else:
            prediction = 0  # Company is not bankrupt
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation:

- **Feature Extraction**: The function takes a dictionary `X` containing the financial features of the company.
  
- **Node Conditions**:
  - The first internal node checks if "WC/TA" (Working Capital/Total Assets) is less than or equal to 0.20.
  - The second internal node checks if "EBIT/TA" (Earnings Before Interest and Tax/Total Assets) is less than or equal to 0.10.

- **Prediction Logic**:
  - If the first condition (`nodes[0]`) is true, the company is predicted to be bankrupt.
  - If the first condition is false, the function checks the second condition (`nodes[1]`). 
    - If the second condition is true, the company is predicted to be bankrupt.
    - Otherwise, the company is predicted not to be bankrupt.

- **Return Values**: The function returns a tuple where:
  - `prediction` is an integer (0 or 1) indicating whether the company went bankrupt.
  - `[int(nodes[0]), int(nodes[1])]` is a list of integers representing the truth values (1 for true, 0 for false) of the conditions evaluated at each internal node.

This function effectively captures the decision-making process of the specified decision tree and provides both the prediction and the evaluation of each internal node's condition.
