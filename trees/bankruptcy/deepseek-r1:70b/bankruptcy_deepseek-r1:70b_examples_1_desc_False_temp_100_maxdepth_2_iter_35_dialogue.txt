Here is the Python function that implements the decision tree logic based on the provided features and thresholds:

```python
def predict(X: dict):
    # Initialize nodes list with None
    nodes = [None, None]
    
    # First condition: Working Capital/Total Assets <= 0.20
    nodes[0] = X['WC/TA'] <= 0.20
    
    if nodes[0]:
        # Second condition: Retained Earnings/Total Assets > 0.15
        nodes[1] = X['RE/TA'] > 0.15
    else:
        # Second condition: Sales/Total Assets > 0.60
        nodes[1] = X['S/TA'] > 0.60
    
    # Determine prediction based on the second node's result
    prediction = 0 if nodes[1] else 1
    
    # Convert boolean values in nodes to integers (1 for True, 0 for False)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
```

This function takes a dictionary `X` containing the financial features of a company and returns both a prediction (whether the company went bankrupt or not) and a list indicating whether each inner node's condition was satisfied. The thresholds used are based on typical ranges observed in financial analysis to determine bankruptcy risk effectively.
