To solve this problem, we need to predict whether a company will go bankrupt based on its financial metrics using a simple decision tree model. The model uses two key metrics: Working Capital to Total Assets (WC/TA) ratio and either Book Value of Equity to Total Assets (BVE/BVL) or Earnings Before Interest and Taxes to Total Assets (EBIT/TA), depending on the WC/TA value.

### Approach
1. **Root Node Evaluation**: First, we evaluate the WC/TA ratio. If it is less than or equal to 0.20, we proceed to check the BVE/BVL metric.
2. **Internal Node Evaluation for Low WC/TA**: If the WC/TA ratio is low (<= 0.20), we then check if the BVE/BVL ratio is less than or equal to 1.00.
3. **Internal Node Evaluation for High WC/TA**: If the WC/TA ratio is high (> 0.20), we instead evaluate the EBIT/TA metric to see if it is less than or equal to 0.05.
4. **Prediction Based on Nodes**: Depending on the evaluations of these metrics, we predict whether the company will go bankrupt (1) or not (0).

The approach ensures that each prediction path only evaluates two conditions, keeping the model simple and efficient.

### Solution Code
```python
def predict_bankruptcy(X):
    # Initialize nodes to store the evaluated conditions
    nodes = [None, None]
    
    # Evaluate root node condition: WC/TA <= 0.20
    nodes[0] = X['WC/TA'] <= 0.20
    
    if nodes[0]:
        # If WC/TA is low, evaluate BVE/BVL condition
        nodes[1] = X['BVE/BVL'] <= 1.00
    else:
        # If WC/TA is high, evaluate EBIT/TA condition
        nodes[1] = X['EBIT/TA'] <= 0.05
    
    prediction = 0  # Default prediction: Not Bankrupt
    
    if nodes[0]:
        # Low WC/TA scenario
        if nodes[1]:
            prediction = 1  # Predict Bankruptcy
    else:
        # High WC/TA scenario
        if nodes[1]:
            prediction = 1  # Predict Bankruptcy
    
    return prediction, nodes
```

### Explanation
- **Root Node (WC/TA)**: The model first checks the WC/TA ratio. A low value indicates potential liquidity issues, prompting further investigation.
- **Internal Nodes (BVE/BVL and EBIT/TA)**: Depending on the WC/TA result, either BVE/BVL or EBIT/TA is evaluated. These metrics provide insights into the company's valuation and profitability.
- **Prediction**: Based on the combined evaluation of these metrics, the model predicts whether bankruptcy is likely.

This structured approach ensures that each step logically follows from the previous one, making the decision-making process clear and efficient.
