```python
def predict(X):
    # Extract necessary features

    BVE_BVL = X['BVE/BVL']

    # Evaluate conditions for inner nodes
    node0 = EBIT_TA <= 0.15

    # Convert booleans to integers (1 for True, 0 for False)
    nodes = [int(node0), int(node1)]

    # Determine prediction based on decision tree logic

        if node1:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Non-Bankrupt

    return prediction, nodes
```

This function evaluates the company's financial health using two key metrics:

1. **EBIT/TA (Earnings Before Interest and Tax / Total Assets):** This metric assesses the company's profitability relative to its total assets. A lower ratio may indicate poor profitability, which could be a sign of distress leading to bankruptcy.

2. **BVE/BVL (Book Value of Equity / Book Value of Liabilities):** This metric indicates the solvency position of the company. If the book value of equity is low compared to liabilities, it suggests higher leverage and potentially higher risk of insolvency or bankruptcy.

The function first checks if the EBIT/TA ratio is less than or equal to 0.15; if true, it predicts bankruptcy (1). If not, it then evaluates whether the BVE/BVL ratio is less than or equal to 1.5. A true result here also leads to a prediction of bankruptcy (1), while a false result leads to a prediction of non-bankruptcy (0).
