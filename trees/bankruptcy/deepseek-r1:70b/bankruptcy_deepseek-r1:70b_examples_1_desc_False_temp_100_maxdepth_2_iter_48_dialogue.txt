```python
def predict(X: dict):
    nodes = [None, None]  # We'll have two inner node conditions
    
    # First inner node condition: EBIT/TA <= 0.10
    nodes[0] = X['EBIT/TA'] <= 0.10
    
    if nodes[0]:
        # Second inner node condition for low EBIT/TA branch: RE/TA <= 0.20
        nodes[1] = X['RE/TA'] <= 0.20
    else:
        # Second inner node condition for high EBIT/TA branch: BVE/BVL <= 1.00
        nodes[1] = X['BVE/BVL'] <= 1.00
    
    if nodes[0]:
        prediction = 1 if nodes[1] else 0
    else:
        prediction = 1 if nodes[1] else 0
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation:
- **nodes[0]** checks whether the company's EBIT/TA ratio is less than or equal to 0.10.
- Depending on this condition:
  - If `nodes[0]` is True, **nodes[1]** checks whether the company's RE/TA ratio is less than or equal to 0.20.
  - If `nodes[0]` is False, **nodes[1]** checks whether the company's BVE/BVL ratio is less than or equal to 1.00.
- The final prediction is based on these conditions:
  - If both nodes are True (low EBIT/TA and low RE/TA), the company is predicted to be bankrupt (1).
  - If only `nodes[0]` is False but `nodes[1]` is True (high BVE/BVL ratio despite higher EBIT/TA), the company is predicted to be bankrupt (1).
  - In all other cases, the company is predicted not to be bankrupt (0).

This function returns both the prediction and a list of binary values indicating whether each condition was met.
