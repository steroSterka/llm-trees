To solve this problem, we need to predict whether a company will go bankrupt based on its financial metrics using a decision tree approach. The decision tree uses four key financial ratios: Working Capital to Total Assets (WC/TA), Retained Earnings to Total Assets (RE/TA), EBIT to Total Assets (EBIT/TA), and Sales to Total Assets (S/TA). 

### Approach
1. **Extract Financial Metrics**: Extract the relevant financial metrics from the input dictionary.
2. **Compute Conditions**: Evaluate each condition based on the thresholds derived from the decision tree:
   - WC/TA ratio should be less than or equal to 0.20.
   - RE/TA ratio should be less than or equal to -0.50.
   - EBIT/TA ratio should be greater than 0.10.
   - S/TA ratio should be greater than 1.50.
3. **Determine Prediction**: Use the evaluated conditions to navigate through the decision tree and determine if the company is likely to go bankrupt (prediction = 1) or not (prediction = 0).
4. **Store Conditions**: Convert each condition's boolean result into an integer (1 for True, 0 for False) to form a list of nodes representing the evaluation path.

### Solution Code
```python
def predict(X):
    # Compute necessary conditions based on financial metrics
    wc_ta_condition = X['WC/TA'] <= 0.20
    re_ta_condition = X['RE/TA'] <= -0.50
    ebit_ta_condition = X['EBIT/TA'] > 0.10
    s_ta_condition = X['S/TA'] > 1.50

    # Create nodes list with truth values (1 for True, 0 otherwise)
    nodes = [
        int(wc_ta_condition),
        int(re_ta_condition),
        int(ebit_ta_condition),
        int(s_ta_condition)
    ]

    # Determine prediction based on the decision tree logic
    if wc_ta_condition:
        if re_ta_condition:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Non-Bankrupt
    else:
        if ebit_ta_condition:
            prediction = 0  # Non-Bankrupt
        else:
            if s_ta_condition:
                prediction = 0  # Non-Bankrupt
            else:
                prediction = 1  # Bankrupt

    return prediction, nodes
```

### Explanation
- **Financial Metrics Extraction**: The function begins by extracting the necessary financial metrics from the input dictionary. These metrics are used to evaluate conditions that determine the company's bankruptcy risk.
- **Condition Evaluation**: Each condition is evaluated in sequence, starting with the WC/TA ratio. If this ratio meets its threshold, further conditions like RE/TA are checked. If not, subsequent conditions such as EBIT/TA and S/TA are evaluated based on the decision tree's structure.
- **Prediction Logic**: The prediction logic follows a hierarchical approach, first checking if the company's WC/TA is below the critical threshold. Depending on this outcome, it proceeds to check other metrics like RE/TA, EBIT/TA, and finally S/TA, adjusting the prediction accordingly.
- **Nodes List**: Each condition's result is stored in a list as integers (1 for True, 0 for False), providing a clear trace of which conditions were met during the evaluation process.

This approach ensures that each financial metric is evaluated in the context of the decision tree, providing an accurate prediction based on the given thresholds and logical flow.
