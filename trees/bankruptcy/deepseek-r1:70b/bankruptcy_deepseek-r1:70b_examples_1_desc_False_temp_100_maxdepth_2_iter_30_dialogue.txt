```python
def predict(X: dict):
    # Initialize nodes to track condition evaluations
    nodes = [None, None]
    
    # Root Node: EBIT/TA <= 0.15
    ebit_threshold = 0.15
    nodes[0] = X['EBIT/TA'] <= ebit_threshold
    
    if nodes[0]:
        # First Inner Node: Working Capital/TA <= 0.20
        wc_threshold = 0.20
        nodes[1] = X['WC/TA'] <= wc_threshold
        
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    else:
        # Second Inner Node: BVE/BVL <= 1.5
        bve_bvl_threshold = 1.5
        nodes[1] = X['BVE/BVL'] <= bve_bvl_threshold
        
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    
    # Convert booleans to integers for the nodes list
    nodes = [int(condition) for condition in nodes]
    
    return prediction, nodes
```

### Explanation:

- **Root Node (EBIT/TA):** The function starts by evaluating whether the Earnings Before Interest and Tax divided by Total Assets is less than or equal to 0.15. This threshold indicates low profitability.
  
- **First Inner Node (WC/TA):** If EBIT/TA is below the threshold, the function then checks if Working Capital/Total Assets is less than or equal to 0.20, signaling potential liquidity issues.

- **Second Inner Node (BVE/BVL):** If EBIT/TA is above the initial threshold, the function evaluates whether the Book Value of Equity divided by the Book Value of Liabilities is less than or equal to 1.5, indicating solvency concerns.

The function returns a prediction (0 for not bankrupt, 1 for bankrupt) and a list where each element is 1 if the corresponding inner node condition was met and 0 otherwise. This structure ensures that both the final prediction and the decision path taken are clear.
