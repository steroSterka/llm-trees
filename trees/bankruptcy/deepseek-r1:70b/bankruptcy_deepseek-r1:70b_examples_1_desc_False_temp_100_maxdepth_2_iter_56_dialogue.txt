```python
def predict(X: dict):
    nodes = [None, None]
    # Evaluate first split condition
    nodes[0] = X['EBIT/TA'] <= 0.15
    # Evaluate second split condition
    nodes[1] = X['BVE/BVL'] <= 0.50

    if nodes[0]:
        prediction = 1  # Predict bankrupt if EBIT/TA is low
    else:
        if nodes[1]:
            prediction = 1  # Predict bankrupt if BVE/BVL is also low
        else:
            prediction = 0  # Predict not bankrupt if both are above thresholds

    return prediction, [int(nodes[0]), int(nodes[1])]
```

**Explanation:**

- **Nodes List**: The function initializes a list `nodes` with two elements to store the evaluation of each inner node condition. Each element will be converted to an integer (1 for True, 0 for False) in the final output.
  
- **First Split (EBIT/TA)**: Evaluates whether EBIT/TA is less than or equal to 0.15. This checks the company's profitability.
  
- **Second Split (BVE/BVL)**: Evaluates whether BVE/BVL is less than or equal to 0.50. This assesses the company's solvency.
  
- **Prediction Logic**:
  - If the first condition (`EBIT/TA <= 0.15`) is true, the function predicts bankruptcy (1).
  - If the first condition is false, it then checks the second condition (`BVE/BVL <= 0.50`). If true, it still predicts bankruptcy; otherwise, it predicts that the company did not go bankrupt (0).

- **Return Values**: The function returns a tuple where the first element is the prediction (0 or 1), and the second element is a list of integers representing whether each inner node condition was met.
