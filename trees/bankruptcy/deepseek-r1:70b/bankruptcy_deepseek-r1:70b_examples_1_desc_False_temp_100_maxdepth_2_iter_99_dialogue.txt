Here is a Python function that implements the decision tree logic for predicting whether a company went bankrupt based on the given financial features:

```python
def predict(X):
    """
    Predicts whether a company went bankrupt based on its financial features using a decision tree classifier.

    Parameters:
    X (dict): Dictionary containing the feature values with keys 'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', 'BVE/BVL'.

    Returns:
    tuple: A tuple containing the prediction (0 for not bankrupt, 1 for bankrupt) and a list of boolean values representing the inner node conditions.
    """
    
    # Define thresholds
    ebit_threshold = 0.15
    wc_threshold = 0.25

    nodes = []

    # First split: Check EBIT/TA against threshold
    ebit_condition = X['EBIT/TA'] <= ebit_threshold
    nodes.append(1 if ebit_condition else 0)

    # Initialize WC condition as False by default (not evaluated unless necessary)
    wc_condition = False

    if ebit_condition:
        # Second split: Check WC/TA against threshold only if EBIT condition is met
        wc_condition = X['WC/TA'] < wc_threshold

    nodes.append(1 if wc_condition else 0)

    # Determine the final prediction based on conditions
    if ebit_condition and wc_condition:
        prediction = 1  # Company went bankrupt
    elif ebit_condition and not wc_condition:
        prediction = 0  # Company did not go bankrupt
    else:  # EBIT/TA > threshold implies company is not bankrupt
        prediction = 0

    return prediction, nodes
```

### Explanation:

1. **Function Definition**:
   - The function `predict` takes a dictionary `X` containing the financial feature values.

2. **Thresholds**:
   - `ebit_threshold`: Set to 0.15, indicating the cutoff for EBIT/TA ratio.
   - `wc_threshold`: Set to 0.25, indicating the cutoff for WC/TA ratio.

3. **Node Tracking**:
   - `nodes` list keeps track of whether each inner node condition was met (1 if true, 0 if false).

4. **First Split (EBIT/TA)**:
   - Checks if EBIT/TA is less than or equal to the threshold.
   - The result is appended to `nodes`.

5. **Second Split (WC/TA)**:
   - If the first condition (EBIT/TA) was met, checks WC/TA against its threshold.
   - The result is appended to `nodes`.

6. **Prediction Logic**:
   - If both EBIT and WC conditions are true, predicts bankruptcy.
   - If only EBIT condition is true but WC is not, predicts not bankrupt.
   - If EBIT condition is false, directly predicts not bankrupt.

7. **Return Values**:
   - Returns a tuple with the prediction (0 or 1) and the `nodes` list indicating the evaluation path through the decision tree.
