```python
def predict(X):
    # Initialize nodes as a list of booleans
    nodes = [False, False]
    
    # Evaluate EBIT/TA condition
    if X['EBIT/TA'] <= 0.15:
        nodes[0] = True
        prediction = 1
    else:
        # Since first condition is not met, check BVE/BVL
        if X['BVE/BVL'] <= 1.00:
            nodes[1] = True
            prediction = 1
        else:
            # If neither condition is met
            prediction = 0
    
    # Convert booleans to integers for the list representation
    nodes_int = [int(n) for n in nodes]
    
    return prediction, nodes_int
```

This function first checks if the EBIT/TA ratio is less than or equal to 0.15. If so, it classifies the company as bankrupt and sets the corresponding node value. If not, it proceeds to evaluate the BVE/BVL ratio. Depending on this second condition, it either classifies the company as bankrupt or non-bankrupt, updating the appropriate node value. The function then converts these boolean values into integers for the final output list.
