```python
def predict(X):
    # Initialize nodes list to track the evaluation of each inner node condition
    nodes = [None, None]
    
    # Evaluate the first inner node (BVE/BVL condition)
    bve_bvl_condition = X['BVE/BVL'] <= 0.80
    nodes[0] = 1 if bve_bvl_condition else 0
    
    if bve_bvl_condition:
        # Proceed to evaluate the EBIT/TA condition for the left branch
        ebit_ta_condition = X['EBIT/TA'] <= 0.05
        nodes[1] = 1 if ebit_ta_condition else 0
        
        prediction = 1 if ebit_ta_condition else 0
    else:
        # Proceed to evaluate the WC/TA condition for the right branch
        wc_ta_condition = X['WC/TA'] <= 0.20
        nodes[1] = 1 if wc_ta_condition else 0
        
        prediction = 1 if wc_ta_condition else 0
    
    return prediction, nodes
```

This function first checks if `BVE/BVL` is less than or equal to 0.80. Depending on the result, it then evaluates either `EBIT/TA` or `WC/TA`. The results of these evaluations are stored in the `nodes` list, which tracks whether each condition was met (1 for true, 0 for false). Finally, the function returns a prediction based on the evaluated conditions and the nodes list.
