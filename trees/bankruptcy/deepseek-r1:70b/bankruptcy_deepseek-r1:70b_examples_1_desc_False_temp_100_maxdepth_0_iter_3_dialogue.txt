To solve this problem, we need to create a function that predicts whether a company is bankrupt (1) or not (0) based on its financial metrics. The prediction is made using a decision tree that evaluates specific thresholds for different financial ratios in a hierarchical manner.

### Approach
The approach involves evaluating five key financial ratios (EBIT/TA, RE/TA, S/TA, BVE/BVL, and WC/TA) against certain thresholds. These evaluations are structured as nodes in a decision tree, where each node represents a condition check. The function evaluates all these conditions upfront and then uses them to navigate through the decision tree hierarchy to make the final prediction.

Here's a step-by-step breakdown of the approach:

1. **Evaluate Conditions Upfront**: Each financial ratio is checked against its respective threshold, and the results are stored in a list called `nodes`.
2. **Determine Prediction Using Decision Tree Logic**: Based on the evaluated conditions, the function navigates through the decision tree hierarchy to determine whether the company is bankrupt or not.
3. **Convert Conditions to Binary Values**: The boolean results of the condition checks are converted to 1s (True) and 0s (False) for clarity.

### Solution Code
```python
def predict_bankruptcy(X):
    # Initialize nodes list with None
    nodes = [None] * 5

    # Evaluate all inner node conditions upfront
    nodes[0] = X['EBIT/TA'] <= 0.15
    nodes[1] = X['RE/TA'] <= -0.25
    nodes[2] = X['S/TA'] <= 0.80
    nodes[3] = X['BVE/BVL'] <= 1.00
    nodes[4] = X['WC/TA'] <= 0.20

    # Determine prediction based on the decision tree logic using these node evaluations
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    else:
        if nodes[2]:
            if nodes[3]:
                prediction = 1  # Bankrupt
            else:
                prediction = 0  # Not Bankrupt
        else:
            if nodes[4]:
                prediction = 1  # Bankrupt
            else:
                prediction = 0  # Not Bankrupt

    # Convert boolean values in nodes to 1s and 0s
    nodes = [1 if n else 0 for n in nodes]

    return prediction, nodes
```

### Explanation
- **Evaluation of Conditions**: The function first evaluates each financial ratio against predefined thresholds. These evaluations are stored in the `nodes` list as boolean values (True or False).
- **Decision Tree Navigation**: Using the evaluated conditions, the function then navigates through a hierarchical decision-making process:
  - If EBIT/TA is less than or equal to 0.15, it checks if RE/TA is less than or equal to -0.25.
  - If not, it proceeds to check S/TA against the threshold of 0.80 and subsequently evaluates BVE/BVL if necessary.
  - If neither EBIT/TA nor S/TA conditions are met, it finally checks WC/TA against its threshold.
- **Conversion to Binary**: The boolean results in `nodes` are converted to 1s (True) and 0s (False) for clarity.

This structured approach ensures that the prediction is made efficiently by following a clear decision-making hierarchy based on financial metrics.
