To solve this problem, we need to create a function that predicts whether a company will go bankrupt based on its financial metrics. The prediction is determined using a decision tree model with specific thresholds for each metric.

### Approach
The approach involves evaluating four key financial metrics in a hierarchical manner:
1. **EBIT/TA (Earnings Before Interest and Taxes divided by Total Assets)**: If this ratio is less than or equal to 0.05, the company is considered to have a high risk of bankruptcy.
2. **BVE/BVL (Book Value of Equity divided by Book Value of Liabilities)**: If EBIT/TA exceeds 0.05, we then check if BVE/BVL is less than or equal to 1.5 as the next criterion for potential insolvency.
3. **WC/TA (Working Capital divided by Total Assets)**: If both EBIT/TA and BVE/BVL do not indicate a high risk, we evaluate WC/TA. If this ratio is less than or equal to 0.15, it suggests moderate risk.
4. **RE/TA (Retained Earnings divided by Total Assets)**: Finally, if WC/TA indicates moderate risk, we check RE/TA. A ratio of 0.10 or lower is considered indicative of high risk.

The function evaluates these metrics in sequence and returns a prediction based on the first met criterion.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    # Compute all node conditions upfront
    nodes = [
        X['EBIT/TA'] <= 0.05,
        X['BVE/BVL'] <= 1.5,
        X['WC/TA'] <= 0.15,
        X['RE/TA'] <= 0.10
    ]
    
    # Determine prediction based on the decision tree logic
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not bankrupt
    else:
        if nodes[2]:
            if nodes[3]:
                prediction = 1  # Bankrupt
            else:
                prediction = 0  # Not bankrupt
        else:
            prediction = 0  # Not bankrupt
    
    return prediction, [int(node) for node in nodes]
```

### Explanation
The function `predict` takes a dictionary `X` containing the financial metrics of a company. It computes four boolean conditions (nodes) based on these metrics and their respective thresholds. Each condition represents an evaluation step in the decision tree:

1. **Node 0**: Checks if EBIT/TA is less than or equal to 0.05.
2. **Node 1**: Checks if BVE/BVL is less than or equal to 1.5, but only relevant if Node 0 is true.
3. **Node 2**: Checks if WC/TA is less than or equal to 0.15, relevant if Node 0 is false.
4. **Node 3**: Checks if RE/TA is less than or equal to 0.10, relevant if both Nodes 0 and 2 are true.

The function then uses these nodes in a hierarchical manner to determine the prediction:
- If Node 0 is true, it checks Node 1 to decide between bankruptcy (1) or not (0).
- If Node 0 is false, it checks Node 2. If Node 2 is true, it further checks Node 3; otherwise, it concludes the company is not bankrupt.

The final result is a tuple containing the prediction (0 or 1) and a list of integers representing each node's evaluation (True as 1, False as 0).
