Here is a Python function that implements the decision tree logic for predicting whether a company went bankrupt based on the provided features. The function returns both the prediction and a list indicating the truth values of the inner node conditions:

```python
def predict(X: dict):
    nodes = [None, None]
    
    # Evaluate first condition: WC/TA <= 0.20
    nodes[0] = X['WC/TA'] <= 0.20
    
    # Evaluate second condition regardless of the first outcome: RE/TA <= -0.50
    nodes[1] = X['RE/TA'] <= -0.50
    
    if nodes[0]:
        prediction = 1  # Bankrupt
    else:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    
    return prediction, nodes
```

**Explanation:**

- **nodes List:** This list captures the truth values of each inner node condition. The first element corresponds to whether `WC/TA` is less than or equal to 0.20, and the second element corresponds to whether `RE/TA` is less than or equal to -0.50.

- **Prediction Logic:**
  - If `nodes[0]` is `True`, the company is classified as Bankrupt.
  - If `nodes[0]` is `False`, we then check `nodes[1]`. If `nodes[1]` is `True`, the company is classified as Bankrupt; otherwise, it is classified as Not Bankrupt.

- **Return Values:** The function returns a tuple with the prediction (0 or 1) and the list of node evaluations (`True` or `False`).

This implementation ensures that all specified conditions are evaluated and recorded, providing both the final prediction and the intermediate decision steps taken by the model.
