To solve this problem, we need to create a function that predicts whether a company is considered "bankrupt" or "not bankrupt" based on certain financial ratios. The prediction is made using a decision tree approach where we evaluate specific thresholds for these ratios step-by-step.

### Approach
The approach involves using a decision tree model with the following structure:

1. **First Split (Root Node):** Evaluate if the company's RE/TA ratio is less than or equal to 0.15.
   - If true, proceed to check the WC/TA ratio.
   - If false, proceed to check the S/TA ratio.

2. **Second Split (Left Child):** If the first condition (RE/TA <= 0.15) is met, evaluate if the WC/TA ratio is less than or equal to 0.20.
   - If true, classify the company as bankrupt.
   - If false, classify the company as not bankrupt.

3. **Second Split (Right Child):** If the first condition (RE/TA <= 0.15) is not met, evaluate if the S/TA ratio is less than or equal to 0.60.
   - If true, classify the company as bankrupt.
   - If false, classify the company as not bankrupt.

The function will return a prediction (1 for bankrupt, 0 for not bankrupt) and an array indicating which nodes in the decision tree were evaluated during the process.

### Solution Code
```python
def predict(X: dict):
    # Initialize the nodes list with None values
    nodes = [None, None]
    
    # Evaluate the first node condition (RE/TA <= 0.15)
    nodes[0] = X["RE/TA"] <= 0.15
    
    # Based on the first node's result, evaluate the second node condition
    if nodes[0]:
        nodes[1] = X["WC/TA"] <= 0.20
    else:
        nodes[1] = X["S/TA"] <= 0.60
    
    # Determine the prediction based on the evaluated nodes
    prediction = int((nodes[0] and nodes[1]) or (not nodes[0] and nodes[1]))
    
    return prediction, nodes
```

### Explanation
- **Decision Tree Structure:** The decision tree is structured to first check the RE/TA ratio. Depending on whether this ratio meets a specific threshold, it then checks either the WC/TA or S/TA ratios.
- **Node Evaluation:** Each node in the decision tree corresponds to a condition check for a specific financial ratio. The nodes list keeps track of which conditions were evaluated during the prediction process.
- **Prediction Logic:** After evaluating the necessary conditions, the function determines if the company should be classified as bankrupt based on whether any of the critical conditions are met.

This approach ensures that we systematically evaluate each relevant financial metric to make an accurate prediction using a straightforward decision tree model.
