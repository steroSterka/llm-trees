```python
def predict(X: dict):
    nodes = 2 * [None]
    nodes[0] = X["WC/TA"] <= 0.20  # First condition
    if nodes[0]:
        nodes[1] = X["EBIT/TA"] <= 0.10  # Second condition
    else:
        nodes[1] = X["RE/TA"] <= 0.15   # Second condition
    
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not bankrupt
    else:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not bankrupt

    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation of the function:

1. **Nodes and Conditions**:
   - The first condition checks whether `WC/TA` (Working Capital/Total Assets) is less than or equal to `0.20`.
   - If the first condition is true (`nodes[0] = True`), the second condition checks whether `EBIT/TA` (Earnings Before Interest and Tax/Total Assets) is less than or equal to `0.10`.
   - If the first condition is false (`nodes[0] = False`), the second condition checks whether `RE/TA` (Retained Earnings/Total Assets) is less than or equal to `0.15`.

2. **Prediction Logic**:
   - The prediction is determined based on the results of these conditions.
   - If both conditions are satisfied (`nodes[0] = True and nodes[1] = True`), the company is classified as bankrupt (`prediction = 1`).
   - If only one condition is satisfied, the company is classified as not bankrupt (`prediction = 0`).
