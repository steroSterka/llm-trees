```python
def predict(X: dict) -> tuple[int, list[int]]:
    # Evaluate all inner nodes
    ebit_ta_condition = X['EBIT/TA'] <= 0
    bve_bvl_condition = X['BVE/BVL'] <= 1
    
    # Convert boolean conditions to integers (True -> 1, False -> 0)
    nodes = [int(ebit_ta_condition), int(bve_bvl_condition)]
    
    prediction = 0  # Default to Non-Bankrupt
    
    if nodes[0]:
        prediction = 1
    else:
        if nodes[1]:
            prediction = 1
        else:
            prediction = 0
    
    return prediction, nodes
```

**Explanation:**

- The function `predict` takes a dictionary `X` containing the financial features of a company.
- It evaluates two conditions based on the features 'EBIT/TA' and 'BVE/BVL'.
- The first condition checks if 'EBIT/TA' is less than or equal to 0, indicating potential unprofitability.
- The second condition checks if 'BVE/BVL' is less than or equal to 1, indicating possible financial distress.
- These conditions are converted into a list of integers (`nodes`), where `True` is represented by 1 and `False` by 0.
- Based on these conditions, the function predicts whether the company went bankrupt (1) or not (0).
- The final prediction and the list of node evaluations are returned as a tuple.
