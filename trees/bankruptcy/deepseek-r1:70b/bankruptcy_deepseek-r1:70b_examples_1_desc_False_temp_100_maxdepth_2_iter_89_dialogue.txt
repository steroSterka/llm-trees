To solve this problem, we need to predict whether a company will go bankrupt based on two financial metrics: Book Value of Equity to Total Liabilities (BVE/TL) and Working Capital to Total Assets (WC/TA). The prediction is made using a decision tree approach with a maximum depth of 2.

### Approach
1. **First Check**: Evaluate the ratio of BVE/TL. If this ratio is less than or equal to 1, it indicates that the company might be at higher risk.
   - If true, proceed to check WC/TA.
     - If WC/TA is less than or equal to 0.20, predict bankruptcy (1).
     - Otherwise, predict non-bankruptcy (0).
2. **Second Check**: If BVE/TL is greater than 1, it indicates a lower risk. Proceed to check EBIT/TA.
   - Regardless of the result of EBIT/TA, predict non-bankruptcy (0) as both outcomes under this condition lead to the same result.

The decision tree approach ensures that we make decisions based on the given financial metrics in a structured and efficient manner.

### Solution Code
```python
def predict(X: dict):
    nodes = [False, False]
    
    # First check: BVE/TL ratio <= 1
    nodes[0] = X['BVE/BVL'] <= 1
    
    if nodes[0]:
        # Second check: WC/TA <= 0.20
        nodes[1] = X['WC/TA'] <= 0.20
        prediction = 1 if nodes[1] else 0
    else:
        # Second check: EBIT/TA >= 0.15 (outcome doesn't affect prediction)
        nodes[1] = X['EBIT/TA'] >= 0.15
        prediction = 0
    
    return prediction, [int(nodes[0]), int(nodes[1])]
```

### Explanation
- **First Check**: The BVE/TL ratio is evaluated to determine if the company's equity is insufficient relative to its liabilities.
  - If `BVE/BVL <= 1`, it indicates potential financial distress. We then check the WC/TA ratio.
    - A low WC/TA ratio (`<= 0.20`) suggests poor liquidity, leading to a bankruptcy prediction (1).
    - A higher WC/TA ratio suggests better liquidity, leading to a non-bankruptcy prediction (0).
- **Second Check**: If the BVE/TL ratio is healthy (`> 1`), we then evaluate EBIT/TA. However, regardless of this metric's outcome, the company is predicted to avoid bankruptcy.

This structured approach efficiently narrows down the financial health of a company using two key metrics in a decision tree model.
