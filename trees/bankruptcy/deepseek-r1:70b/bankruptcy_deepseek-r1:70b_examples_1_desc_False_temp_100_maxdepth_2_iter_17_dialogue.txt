To create a Python function that predicts whether a company went bankrupt based on financial features using a decision tree of maximum depth 2:

```python
def predict(X: dict):
    nodes = [
        X["EBIT/TA"] <= 0.10,
        X["WC/TA"] > 0.00
    ]
    
    if nodes[0]:
        prediction = 1
    else:
        if nodes[1]:
            prediction = 0
        else:
            prediction = 1
    
    return prediction, nodes
```

**Explanation:**

- **nodes**: A list containing two boolean values representing the conditions in the decision tree.
  - `nodes[0]`: Checks if EBIT/TA is less than or equal to 0.10.
  - `nodes[1]`: Checks if WC/TA is greater than 0.00.

- **prediction**: 
  - If `nodes[0]` is True, the company is classified as bankrupt (1).
  - If `nodes[0]` is False:
    - If `nodes[1]` is True, the company is not bankrupt (0).
    - Otherwise, the company is bankrupt (1).

This function effectively uses a decision tree structure to classify bankruptcy based on the provided financial features.
