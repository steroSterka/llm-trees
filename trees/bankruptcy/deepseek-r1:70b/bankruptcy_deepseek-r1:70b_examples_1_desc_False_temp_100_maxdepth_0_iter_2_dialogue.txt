To solve this problem, we need to create a function that predicts whether a company will go bankrupt based on specific financial metrics using a decision tree approach. The function will evaluate these metrics and return the prediction along with the evaluation results of each condition in the decision tree.

### Approach
The approach involves constructing a decision tree where each node represents a condition based on specific financial ratios. The conditions are evaluated in a hierarchical manner to determine if bankruptcy is predicted. Here's a step-by-step breakdown:

1. **Extract Features**: Extract the relevant financial ratios from the input dictionary.
2. **Evaluate Conditions**: Evaluate each condition (node) in the decision tree upfront, regardless of the path taken through the tree.
3. **Determine Prediction**: Use the evaluated conditions to determine the prediction based on the hierarchical structure of the decision tree.
4. **Return Results**: Return both the prediction and a list indicating whether each condition was met.

### Solution Code
```python
def predict_bankruptcy(X: dict):
    # Extract relevant features from the input dictionary
    bve_bvl = X['BVE/BVL']
    ebit_ta = X['EBIT/TA']
    s_ta = X['S/TA']
    
    # Initialize nodes list to store the evaluation of each condition
    nodes = [None] * 3
    
    # Evaluate each condition in the decision tree upfront
    nodes[0] = (bve_bvl <= 0.5)       # BVE/BVL <= 0.5
    nodes[1] = (ebit_ta <= 0)         # EBIT/TA <= 0%
    nodes[2] = (s_ta <= 20)           # S/TA <= 20%
    
    # Convert boolean values in nodes to integers (1 for True, 0 for False)
    nodes = [1 if node else 0 for node in nodes]
    
    # Determine the prediction based on the hierarchical conditions
    if nodes[0]:
        prediction = 1  # Bankrupt if BVE/BVL condition is met
    else:
        if nodes[1]:
            prediction = 1  # Bankrupt if EBIT/TA condition is met
        else:
            if nodes[2]:
                prediction = 1  # Bankrupt if S/TA condition is met
            else:
                prediction = 0  # Non-Bankrupt if none of the conditions are met
    
    return prediction, nodes
```

### Explanation
The function `predict_bankruptcy` takes a dictionary `X` containing financial metrics and returns a tuple with two elements: an integer indicating whether bankruptcy is predicted (1 for bankrupt, 0 for non-bankrupt) and a list of integers representing the evaluation results of each condition in the decision tree.

1. **Feature Extraction**: The relevant financial ratios 'BVE/BVL', 'EBIT/TA', and 'S/TA' are extracted from the input dictionary.
2. **Condition Evaluation**: Each condition is evaluated upfront to determine if it is met (True or False), ensuring all nodes are assessed regardless of the decision path.
3. **Prediction Logic**: The prediction is determined by checking each condition in hierarchical order. If any condition is met, the company is predicted to be bankrupt; otherwise, it is considered non-bankrupt.
4. **Result Conversion**: Boolean results for each condition are converted to integers (1 for True, 0 for False) for clarity.

This approach ensures that all conditions are evaluated and reported, providing transparency into how each decision was reached in the tree structure.
