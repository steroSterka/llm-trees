Here's a Python function implementing the decision tree based on the specified financial features to predict whether a company went bankrupt or not:

```python
def predict(X: dict):
    nodes = [None] * 2
    
    # First split condition: Check if EBIT/TA <= 0.10
    nodes[0] = X['EBIT/TA'] <= 0.10
    
    if nodes[0]:
        # Second split condition: Check if WC/TA > 0.20 within the first branch
        nodes[1] = X['WC/TA'] > 0.20
        
        if nodes[1]:
            prediction = 0  # Non-bankrupt
        else:
            prediction = 1  # Bankrupt
    else:
        # If EBIT/TA > 0.10, classify as non-bankrupt regardless of other features
        prediction = 0
    
    return prediction, nodes
```

### Explanation:

- **First Split**: The decision tree starts by checking if the company's `EBIT/TA` (Earnings Before Interest and Tax divided by Total Assets) is less than or equal to 0.10. This threshold helps identify companies with lower profitability.

- **Second Split (if applicable)**: If a company passes the first condition (`EBIT/TA <= 0.10`), it then checks if its `WC/TA` (Working Capital divided by Total Assets) is greater than 0.20. This secondary check assesses the company's liquidity and operational efficiency.

- **Prediction Logic**:
  - If both conditions are met, the company is classified as non-bankrupt (`prediction = 0`).
  - If only the first condition is met but not the second, it is classified as bankrupt (`prediction = 1`).
  - If the first condition is not met (i.e., `EBIT/TA > 0.10`), the company is classified as non-bankrupt regardless of other factors.

This approach effectively balances profitability and liquidity to make a prediction within a maximum depth of two, ensuring clarity and simplicity in the decision-making process.
