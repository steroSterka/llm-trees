To solve this problem, we need to classify whether a company should be considered for investment based on its financial metrics. The classification is determined using a decision tree approach with specific thresholds for Earnings Before Interest and Taxes (EBIT), Sales Turnover (S/TA), and Book Value per Share (BVE/BVL).

### Approach
The problem can be approached by constructing a simple decision tree where each node represents a check against a financial metric. The tree has three levels:
1. **Root Node**: Checks if EBIT is greater than or equal to 0.10.
2. **Second Level Nodes**: If the root condition is met, it checks if Sales Turnover (S/TA) is greater than or equal to 0.50. If the root condition is not met, it checks if Book Value per Share (BVE/BVL) is less than or equal to 1.00.

The decision tree structure ensures that each path from root to leaf has at most two splits, aligning with a maximum depth of 2. This approach allows us to classify companies based on their financial health efficiently.

### Solution Code
```python
def predict_financial_health(X):
    # Define the nodes representing the conditions checked
    ebit_condition = X['EBIT/TA'] >= 0.10
    sales_condition = X['S/TA'] >= 0.50
    bve_condition = X['BVE/BVL'] <= 1.00
    
    # Store all conditions in a list
    nodes = [ebit_condition, sales_condition, bve_condition]
    
    if nodes[0]:  # Check EBIT condition first
        if nodes[1]:  # If EBIT is good, check Sales condition
            return (1, nodes)  # Both metrics are healthy, recommend investment
        else:
            return (0, nodes)  # EBIT is good but Sales are not, do not recommend
    else:  # EBIT is below threshold
        if nodes[2]:  # Check Book Value condition
            return (1, nodes)  # BVE is within limit, recommend investment
        else:
            return (0, nodes)  # Neither metric is healthy, do not recommend

# Example usage:
financial_data = {
    'EBIT/TA': 0.15,
    'S/TA': 0.40,
    'BVE/BVL': 0.80
}
prediction, nodes = predict_financial_health(financial_data)
print(f"Prediction: {prediction}")
print("Conditions Met:")
print(f"EBIT/TA >= 0.10: {nodes[0]}")
print(f"S/TA >= 0.50: {nodes[1]}")
print(f"BVE/BVL <= 1.00: {nodes[2]}")
```

### Explanation
- **Root Node (EBIT Condition)**: The first check determines if the company's EBIT is healthy by comparing it against a threshold of 0.10. If this condition is met, we proceed to evaluate the Sales Turnover.
- **Second Level Nodes**: 
  - If the root condition is satisfied, we then check if the Sales Turnover meets or exceeds 0.50. Meeting both conditions indicates strong financial health and warrants an investment recommendation.
  - If the root condition is not met, we instead evaluate the Book Value per Share to ensure it does not exceed 1.00. Meeting this alternative condition suggests moderate financial health and also warrants an investment recommendation.
- **Decision Making**: Based on these checks, the function returns a binary recommendation (0 for not recommending investment and 1 for recommending investment) along with the evaluation results of each condition.

This structured approach ensures that we efficiently classify companies using a decision tree model, considering both profitability and asset valuation metrics.
