Here's a Python function representing the decision tree to predict whether a company went bankrupt or not based on its financial features:

def predict(X: dict):
    """
    Predicts whether a company went bankrupt or not using a decision tree classifier.

    Parameters:
    X (dict): A dictionary containing the financial features of the company.
        - 'WC/TA': Working Capital/Total Assets
        - 'RE/TA': Retained Earnings/Total Assets
        - 'EBIT/TA': Earnings Before Interest and Tax/Total Assets
        - 'S/TA': Sales/Total Assets
        - 'BVE/BVL': Book Value of Equity/Book Value of Liabilities

    Returns:
    tuple: A tuple containing the prediction (0 = no, 1 = yes) and a list representing the truth values of the inner nodes.
    """

    # Initialize nodes with None
    nodes = 2 * [None]

    # Node 0 condition: Working Capital/Total Assets <= 0.20
    nodes[0] = X['WC/TA'] <= 0.20

    # Node 1 condition: Retained Earnings/Total Assets <= 0.10 (only evaluated if Node 0 is False)
    if not nodes[0]:
        nodes[1] = X['RE/TA'] <= 0.10
    else:
        nodes[1] = None  # Not evaluated

    # Prediction based on node conditions
    if nodes[0]:  # Low working capital, likely to go bankrupt
        prediction = 1
    elif nodes[1]:  # Low retained earnings, likely to go bankrupt
        prediction = 1
    else:  # Better financial health, less likely to go bankrupt
        prediction = 0

    # Replace None with 0 (False) for unevaluated node conditions
    nodes = [int(node) if node is not None else 0 for node in nodes]

    return prediction, nodes


# Example usage:

This code implements the decision tree logic using the provided financial features. It first checks if the Working Capital/Total Assets ratio is below 0.20.
