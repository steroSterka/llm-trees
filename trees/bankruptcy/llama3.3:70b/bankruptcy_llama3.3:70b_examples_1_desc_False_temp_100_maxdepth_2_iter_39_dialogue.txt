```python
def predict(X: dict):
    """
    Predicts whether a company went bankrupt based on its financial features.

    Args:
        X (dict): A dictionary containing the company's financial features.
            - WC/TA: Working Capital/Total Assets
            - RE/TA: Retained Earnings/Total Assets
            - EBIT/TA: Earnings Before Interest and Tax/Total Assets
            - S/TA: Sales/Total Assets
            - BVE/BVL: Book Value of Equity/Book Value of Liabilities

    Returns:
        tuple: A tuple containing the prediction (0 = no, 1 = yes) and a list of truth values for the inner nodes.
    """
    nodes = 2 * [None]
    # Node 0: Check if Working Capital/Total Assets is less than or equal to 0.2
    nodes[0] = X["WC/TA"] <= 0.2
    
    # Node 1: Check if Earnings Before Interest and Tax/Total Assets is less than or equal to 0.05
    nodes[1] = X["EBIT/TA"] <= 0.05

    prediction = None
    if nodes[0]:
        # If Working Capital/Total Assets is low, predict bankruptcy regardless of EBIT/TA
        prediction = 1
    else:
        # If Working Capital/Total Assets is sufficient, check EBIT/TA
        if nodes[1]:
            # If EBIT/TA is poor, predict bankruptcy
            prediction = 1
        else:
            # If EBIT/TA is good, predict no bankruptcy
            prediction = 0

    return prediction, [int(node) for node in nodes]
```

```python
prediction, nodes = predict(X)
```
