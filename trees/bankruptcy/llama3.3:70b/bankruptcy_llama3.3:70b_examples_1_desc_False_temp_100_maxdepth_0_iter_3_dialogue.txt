**Decision Tree:**

|--- Working Capital/Total Assets <= 0.20
||--- class: Bankrupt
|--- Working Capital/Total Assets > 0.20
||--- Retained Earnings/Total Assets <= 0.10
|||--- class: Bankrupt

|||--- EBIT/Total Assets <= 0.05

||||--- class: Not Bankrupt

**Explanation:**

- **Root Node**: The tree starts by examining the `Working Capital/Total Assets` ratio. If this ratio is less than or equal to 0.20, it suggests that the company has limited liquidity and may struggle to meet its short-term obligations, leading to a classification of "Bankrupt".
  
- **First Split**: For companies with a `Working Capital/Total Assets` ratio greater than 0.20, we then look at the `Retained Earnings/Total Assets` ratio. A ratio less than or equal to 0.10 may indicate that the company has not been able to retain sufficient earnings from its operations, which could be a sign of financial distress and potentially lead to bankruptcy.

- **Second Split**: If the `Retained Earnings/Total Assets` is greater than 0.10, we examine the `EBIT/Total Assets` ratio. This ratio measures a company's profitability before interest and taxes relative to its total assets. An `EBIT/Total Assets` ratio less than or equal to 0.05 might suggest that the company is not generating enough earnings from its operations compared to its asset base, which could be indicative of financial difficulties.

- **Leaf Nodes**: The leaf nodes represent the classification outcome based on the feature values. Companies that pass through the criteria indicating potential financial health are classified as "Not Bankrupt", while those that fail these criteria are classified as "Bankrupt".

This decision tree is a simplified example and actual construction would require specific data to train the model, including thresholds for each feature that optimize the classification accuracy between bankrupt and non-bankrupt companies. def predict_bankruptcy(X: dict):
    """
    Predicts whether a company will go bankrupt based on its financial features.
    
    Parameters:
    X (dict): A dictionary containing the financial features of the company.
        - WC/TA: Working Capital/Total Assets
        - RE/TA: Retained Earnings/Total Assets
        - EBIT/TA: Earnings Before Interest and Tax/Total Assets
        - S/TA: Sales/Total Assets
        - BVE/BVL: Book Value of Equity/Book Value of Liabilities
    
    Returns:
    prediction (int): 0 if the company is predicted not to go bankrupt, 1 otherwise.
    nodes (list): A list representing the truth values of the inner nodes in the decision tree.
    """
    
    # Initialize the nodes list with None
    nodes = 3 * [None]
    
    # Node 0: Check if Working Capital/Total Assets is less than or equal to 0.20
    nodes[0] = X['WC/TA'] <= 0.20
    
    # If Node 0 is True, check the next condition
    if nodes[0]:
        # Node 1: Check if Retained Earnings/Total Assets is less than or equal to 0.10
        nodes[1] = X['RE/TA'] <= 0.10
        
        # If Node 1 is True, predict bankruptcy
        if nodes[1]:
            prediction = 1
            # Node 2: Not needed in this case, so set it to False
            nodes[2] = False
        else:
            # Node 2: Check if EBIT/Total Assets is less than or equal to 0.05
            nodes[2] = X['EBIT/TA'] <= 0.05
            
            # If Node 2 is True, predict bankruptcy
            if nodes[2]:
                prediction = 1
            else:
                prediction = 0
    else:
        # Node 1 and Node 2: Not needed in this case, so set them to False
        nodes[1] = False
        nodes[2] = False
        
        # Predict not bankrupt if Working Capital/Total Assets is greater than 0.20
        prediction = 0
    
    # Convert boolean values in nodes list to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
