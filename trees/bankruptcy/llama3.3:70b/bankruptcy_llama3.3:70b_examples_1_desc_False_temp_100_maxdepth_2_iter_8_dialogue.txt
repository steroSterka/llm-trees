```python
def predict_bankruptcy(X: dict):
    """
    Predicts whether a company went bankrupt or not based on its financial features.
    
    Parameters:
    X (dict): A dictionary containing the financial features of the company.
              The keys are 'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', and 'BVE/BVL'.
    
    Returns:
    tuple: A tuple containing the prediction (0 or 1) and a list representing the truth values of the inner nodes.
    """
    
    # Initialize the nodes with None
    nodes = 2 * [None]
    
    # Node 0: Check if Working Capital/Total Assets is less than or equal to 0.5
    nodes[0] = X['WC/TA'] <= 0.5
    
    # Node 1: Check if Retained Earnings/Total Assets is less than or equal to -0.5
    nodes[1] = X['RE/TA'] <= -0.5
    
    # Make the prediction based on the nodes
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    else:
        prediction = 0  # Not Bankrupt
    
    return prediction, nodes

# Example usage:
X = {
    'WC/TA': 0.3,
    'RE/TA': -1.2,
    'EBIT/TA': 0.1,
    'S/TA': 2.5,
    'BVE/BVL': 1.8
}

prediction, nodes = predict_bankruptcy(X)
print(f"Prediction: {prediction}")
print(f"Nodes: {nodes}")
```

In this function, the decision tree is represented by two inner nodes:

- Node 0 checks if the Working Capital/Total Assets (`WC/TA`) is less than or equal to 0.5.
- Node 1 checks if the Retained Earnings/Total Assets (`RE/TA`) is less than or equal to -0.5.

The prediction is made based on the values of these nodes:

- If `WC/TA` is less than or equal to 0.5 and `RE/TA` is less than or equal to -0.5, the company is predicted to be bankrupt.
- If `WC/TA` is less than or equal to 0.5 but `RE/TA` is greater than -0.5, the company is predicted not to be bankrupt.
- If `WC/TA` is greater than 0.5, the company is predicted not to be bankrupt regardless of the value of `RE/TA`.
