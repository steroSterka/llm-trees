```python
def predict(X: dict):
    """
    Predict whether a company went bankrupt or not based on financial features.

    Args:
    X (dict): Dictionary containing financial features of the company.
             - WC/TA: Working Capital/Total Assets
             - RE/TA: Retained Earnings/Total Assets
             - EBIT/TA: Earnings Before Interest and Tax/Total Assets
             - S/TA: Sales/Total Assets
             - BVE/BVL: Book Value of Equity/Book Value of Liabilities

    Returns:
    prediction (int): 0 if the company did not go bankrupt, 1 if it went bankrupt.
    nodes (list): List of boolean values representing the truth values of the inner nodes.
                  The first element corresponds to the condition "WC/TA <= 0.20",
                  and the second element corresponds to the condition "BVE/BVL <= 1.00" or "EBIT/TA <= 0.10".
    """

    # Initialize the list to store the truth values of the inner nodes
    nodes = 2 * [None]

    # Evaluate the conditions for the root node and its children
    nodes[0] = X["WC/TA"] <= 0.20
    if nodes[0]:
        nodes[1] = X["BVE/BVL"] <= 1.00
    else:
        nodes[1] = X["EBIT/TA"] <= 0.10

    # Make the prediction based on the conditions
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    else:
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt

    # Convert boolean values to integers (1 for True, 0 for False)
    nodes = [int(node) for node in nodes]

    return prediction, nodes
```

This function first evaluates the conditions for the root node and its children. Then it makes a prediction based on these conditions. The `nodes` list stores the truth values of the inner nodes as integers (1 for True, 0 for False). Finally, the function returns the prediction and the `nodes` list.
