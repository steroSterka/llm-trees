```python
def predict_bankruptcy(X: dict):
    nodes = 2 * [None]
    
    # First split: Working Capital/Total Assets <= 0.20
    nodes[0] = X['WC/TA'] <= 0.20
    
    # Second split for companies with sufficient working capital: Book Value of Equity/Book Value of Liabilities <= 1.00
    if not nodes[0]:
        nodes[1] = X['BVE/BVL'] <= 1.00
    else:
        nodes[1] = False  # This node is irrelevant if the first condition is true
    
    prediction = 0  # Default to no bankruptcy
    
    if nodes[0]:  # Company has low working capital, likely to go bankrupt
        prediction = 1
    elif nodes[1]:  # Despite sufficient working capital, solvency is a concern
        prediction = 1
    
    return prediction, [int(node) for node in nodes]
```

This function uses the following logic:
- If `WC/TA` is less than or equal to 0.20, it indicates potential liquidity issues, and thus, the company is predicted to go bankrupt (`prediction = 1`).
- For companies with `WC/TA` greater than 0.20, if `BVE/BVL` is less than or equal to 1.00, it suggests solvency concerns despite sufficient working capital, leading to a prediction of bankruptcy.
- In all other cases, the company is predicted not to go bankrupt (`prediction = 0`). 

The function returns the prediction and a list where each element corresponds to whether the condition at that node was true (1) or false (0).
