def predict(X: dict):
    """
    Predict whether a company went bankrupt or not based on its financial features.
    
    Parameters:
    X (dict): Dictionary containing the financial features of the company.
             The keys are 'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', and 'BVE/BVL'.
    
    Returns:
    prediction (int): 0 if the company did not go bankrupt, 1 if it went bankrupt.
    nodes (list): List of boolean values representing the conditions at each inner node.
                  The first element corresponds to the condition 'WC/TA <= 0.20',
                  and the second element corresponds to the condition 'BVE/BVL <= 1.00'.
    """

    nodes = 2 * [None]
    
    # Evaluate the conditions at each inner node
    nodes[0] = X['WC/TA'] <= 0.20
    nodes[1] = X['BVE/BVL'] <= 1.00
    
    # Make a prediction based on the conditions
    if nodes[0]:
        prediction = 1  # If the company has severe liquidity issues, it is likely to go bankrupt
    else:
        if nodes[1]:
            prediction = 1  # If the company's equity cannot cover its liabilities, it is likely to go bankrupt
        else:
            prediction = 0  # Otherwise, the company is unlikely to go bankrupt
    
    return prediction, [int(node) for node in nodes]

# Example usage:

In this function, we first evaluate the conditions at each inner node and store the results in the `nodes` list. Then, we make a prediction based on these conditions.
