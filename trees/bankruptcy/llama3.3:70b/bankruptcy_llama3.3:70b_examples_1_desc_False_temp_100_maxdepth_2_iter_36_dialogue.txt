- **EBIT/TA**: This measures a company's profitability from its operations, with higher values generally indicating lower risk of bankruptcy.

- **Book Value of Equity/Book Value of Liabilities**: A higher ratio here suggests a company has more equity than liabilities, reducing the likelihood of bankruptcy.

For simplicity and based on general financial principles, let's consider that **EBIT/TA** (a direct measure of operational profitability) and **Working Capital/Total Assets** (a measure of liquidity) are among the most critical factors in assessing a company's risk of bankruptcy. Thus, we'll use these for our decision tree.

### Decision Tree:

   - If **EBIT/TA <= 0**, then this indicates potential operational loss or insufficient profitability to cover expenses, suggesting a higher risk of bankruptcy.
     - Go to Node 2.
   - If **EBIT/TA > 0**, the company is operationally profitable.
     - Go to Node 3.

   - If **Working Capital/Total Assets >= 0.2**, while there are operational losses, the company might have enough liquidity to manage its short-term obligations, potentially avoiding bankruptcy.

   - If **Working Capital/Total Assets < 0.5**, while the company is profitable, lower liquidity might pose some risks, but given the positive EBIT/TA, it's less likely to go bankrupt.

This function takes in a dictionary `X` containing the feature values and returns a tuple with the predicted target variable value (0 for no bankruptcy, 1 for bankruptcy) and a list of truth values representing the conditions at each inner node.

```python
def predict(X: dict):
    """
    Predicts whether a company went bankrupt or not based on financial features.
    
    Parameters:
    X (dict): Dictionary containing feature values. Keys should match the exact feature names.
             Features: 'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', 'BVE/BVL'
             
    Returns:
    tuple: A tuple containing the predicted target variable value (0 or 1) and a list of truth values for inner nodes.
    """
    
    # Initialize nodes with None
    nodes = 2 * [None]
    
    # Node 0 condition: EBIT/TA <= 0
    nodes[0] = X['EBIT/TA'] <= 0
    
    # If the company is operationally unprofitable (EBIT/TA <= 0), check liquidity (WC/TA)
    if nodes[0]:
        # Node 1 condition: WC/TA < 0.2
        nodes[1] = X['WC/TA'] < 0.2
        
        # Prediction based on conditions
        if nodes[1]:
            prediction = 1  # Bankrupt
        else:
            prediction = 0  # Not Bankrupt
    else:
        # If operationally profitable (EBIT/TA > 0), regardless of WC/TA, predict not bankrupt
        nodes[1] = False  # This condition is not actually used in the decision but included for consistency
        prediction = 0  # Not Bankrupt
    
    # Convert boolean node values to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes

# Example usage:
X = {
    'WC/TA': 0.1,
    'RE/TA': -0.5,
    'EBIT/TA': -0.2,

prediction, nodes = predict(X)
```
