```python
def predict(X: dict):
    """
    Predicts whether a company went bankrupt based on its financial metrics.
    
    Args:
        X (dict): A dictionary containing the company's financial metrics.
            - 'WC/TA': Working Capital/Total Assets
            - 'RE/TA': Retained Earnings/Total Assets
            - 'EBIT/TA': Earnings Before Interest and Tax/Total Assets
            - 'S/TA': Sales/Total Assets
            - 'BVE/BVL': Book Value of Equity/Book Value of Liabilities
    
    Returns:
        prediction (int): 0 if the company did not go bankrupt, 1 if it did.
        nodes (list): A list representing the truth values of the inner nodes.
    """
    
    # Initialize the list to store the truth values of the inner nodes
    nodes = 2 * [None]
    
    # Define the conditions for the inner nodes
    nodes[0] = X['EBIT/TA'] <= 0.05  # Low profitability
    nodes[1] = X['BVE/BVL'] <= 1.0   # High leverage
    
    # Make predictions based on the node values
    if nodes[0]:
        prediction = 1  # Company is likely to go bankrupt due to low profitability
    else:
        if nodes[1]:
            prediction = 1  # Company is likely to go bankrupt due to high leverage
        else:
            prediction = 0  # Company is unlikely to go bankrupt
    
    # Convert boolean node values to integers (1 for True, 0 for False)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes

# Example usage:
company_metrics = {
    'WC/TA': 0.2,
    'RE/TA': 0.3,
    'EBIT/TA': 0.04,
    'S/TA': 1.5,
    'BVE/BVL': 0.8
}

prediction, nodes = predict(company_metrics)
print(f"Prediction: {prediction}")
print(f"Nodes: {nodes}")
```

In this function, the decision tree checks two conditions:
- If the company's `EBIT/TA` is less than or equal to 0.05, it is likely to go bankrupt due to low profitability.
- If the company's `BVE/BVL` is less than or equal to 1.0, it has high leverage and is likely to go bankrupt.

The function returns a prediction (0 for not bankrupt, 1 for bankrupt) and a list of node values, where each node value represents whether the corresponding condition was met (1 for True, 0 for False).
