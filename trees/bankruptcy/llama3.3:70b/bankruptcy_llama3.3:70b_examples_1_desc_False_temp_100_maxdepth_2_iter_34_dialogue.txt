|--- Working Capital/Total Assets <= 0.20

|--- Working Capital/Total Assets > 0.20

This decision tree is constructed with the assumption that:
- A company with very low working capital relative to its total assets might struggle to meet short-term obligations, indicating a higher risk of bankruptcy.
- For companies with sufficient working capital, the comparison between equity and liabilities becomes crucial. If a company's book value of equity is less than or equal to its liabilities, it may indicate insolvency or high risk of bankruptcy.

Please note, this is a conceptual example based on general financial principles. Actual decision tree construction would require specific data to determine feature importance accurately and to tune the thresholds in the tree for optimal classification performance.

Here's the Python function that implements the decision tree:

```python
def predict(X: dict):
    """
    This function predicts whether a company went bankrupt or not based on its financial features.
    
    Parameters:
    X (dict): A dictionary containing the financial features of the company. The keys should match the exact feature names:
             'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', 'BVE/BVL'.
             
    Returns:
    prediction (int): 0 if the company did not go bankrupt, 1 if it went bankrupt.
    nodes (list): A list of boolean values representing the truth values of the inner nodes in the decision tree.
    """
    
    # Initialize the list to store the node values
    nodes = 2 * [None]
    
    # Node 0: Check if Working Capital/Total Assets is less than or equal to 0.20
    nodes[0] = X['WC/TA'] <= 0.20
    
    # Node 1: Check if Book Value of Equity/Book Value of Liabilities is less than or equal to 1.00
    nodes[1] = X['BVE/BVL'] <= 1.00
    
    # Make the prediction based on the node values
    if nodes[0]:
        prediction = 1  # Company likely went bankrupt due to low liquidity
    else:
        if nodes[1]:
            prediction = 1  # Company likely went bankrupt due to potential insolvency
        else:
            prediction = 0  # Company did not go bankrupt
    
    return prediction, [int(node) for node in nodes]

# Example usage:
features = {
    'WC/TA': 0.15,
    'RE/TA': 0.30,
    'EBIT/TA': 0.10,
    'S/TA': 0.80,
    'BVE/BVL': 0.50
}

prediction, nodes = predict(features)
print("Prediction:", prediction)
print("Node values:", nodes)

```

This function first checks the Working Capital/Total Assets ratio and then the Book Value of Equity/Book Value of Liabilities ratio to make a prediction about whether the company went bankrupt or not. The node values are returned as a list of integers (0 or 1) representing the truth values of the conditions in the decision tree.
