2. **Retained Earnings/Total Assets**: Retained earnings represent profits reinvested in the business, and this ratio can indicate profitability and financial health.

3. **Earnings Before Interest and Tax (EBIT)/Total Assets**: This is a measure of profitability relative to total assets, indicating how well a company uses its assets to generate income before considering interest and tax expenses.

4. **Sales/Total Assets**: This turnover ratio indicates the efficiency with which a company uses its assets to generate sales.

5. **Book Value of Equity/Book Value of Liabilities**: This ratio compares the book value of equity (total assets minus total liabilities) to the book value of liabilities, indicating leverage and financial risk.

def predict(X: dict):
    """
    Decision Tree to Predict Bankruptcy Based on Financial Ratios.
    
    Parameters:
    X (dict): Dictionary containing financial ratios for a company.
             Keys: 'WC/TA', 'RE/TA', 'EBIT/TA', 'S/TA', 'BVE/BVL'
    
    Returns:
    prediction (int): 0 if the company is predicted not to go bankrupt, 1 otherwise.
    nodes (list): List of boolean values representing the conditions at each inner node.
                  1 if the condition is satisfied, 0 otherwise.
    """

    # Initialize list to store node conditions
    nodes = 2 * [None]
    
    # Root Node: EBIT/TA <= 0.05
    nodes[0] = X['EBIT/TA'] <= 0.05
    
    # If the company is profitable (EBIT/TA > 0.05), check its liquidity (WC/TA)
    if not nodes[0]:
        nodes[1] = X['WC/TA'] <= 0.20
    else:
        nodes[1] = False  # This node's condition doesn't apply if the company isn't profitable
    
    # Make prediction based on node conditions
    if nodes[0]:  # Company is not profitable
        prediction = 1  # Predict bankruptcy
    else:  # Company is profitable
        if nodes[1]:  # Company has liquidity issues despite being profitable
            prediction = 1  # Predict bankruptcy due to potential liquidity problems
        else:
            prediction = 0  # Predict no bankruptcy
    
    # Convert boolean node conditions to integers (1 for True, 0 for False)
    nodes = [int(node) for node in nodes]
    
    return prediction, nodes
