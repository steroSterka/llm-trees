- **Earnings Before Interest and Tax (EBIT)/Total Assets**: Reflects a company's profitability from its operations, unaffected by financing decisions.
- **Sales/Total Assets**: A measure of asset efficiency, indicating how effectively assets are being used to generate sales.
- **Book Value of Equity/Book Value of Liabilities**: A higher ratio indicates lower financial leverage and potentially lower bankruptcy risk.

def predict(X: dict):
    """
    Predicts whether a company went bankrupt or not based on financial features.
    
    Parameters:

    Returns:
    tuple: A tuple containing the predicted target variable value (0 = no bankruptcy, 1 = bankruptcy) and a list of boolean values representing the truth values of the inner nodes.
    """

    # Initialize the list to store the truth values of the inner nodes
    nodes = 2 * [None]
    
    # First node: Working Capital/Total Assets <= 0.2
    nodes[0] = X['WC/TA'] <= 0.2
    
    # Second node: If WC/TA <= 0.2, then Retained Earnings/Total Assets <= 0; otherwise, EBIT/Total Assets <= 0.05
    if nodes[0]:
        nodes[1] = X['RE/TA'] <= 0
    else:
        nodes[1] = X['EBIT/TA'] <= 0.05
    
    # Prediction based on the decision tree
    if nodes[0]:
        if nodes[1]:
            prediction = 1  # Bankrupt

        if nodes[1]:

    return prediction, nodes
