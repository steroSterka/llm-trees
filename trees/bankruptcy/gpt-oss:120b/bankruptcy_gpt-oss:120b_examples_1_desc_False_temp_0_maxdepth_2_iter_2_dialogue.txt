### How the tree was derived  

| Rank | Feature (ratio)                              | Why it is “most important” (Altman Z‑score intuition) |
|------|----------------------------------------------|--------------------------------------------------------|
| **1**| **Working Capital / Total Assets** (WC/TA)   | Direct measure of short‑term liquidity; low values are a strong early warning of cash‑flow distress. |
| **2**| **EBIT / Total Assets** (EBIT/TA)            | Captures operating profitability after covering operating expenses; a very low EBIT relative to assets signals an inability to generate earnings to service debt. |
| **3**| Retained Earnings / Total Assets (RE/TA)    | Reflects accumulated profitability; useful but generally less discriminative once liquidity and current profitability are accounted for. |
| **4**| Sales / Total Assets (Sales/TA)              | Shows asset‑turnover efficiency; often correlated with the above ratios and therefore less “pure” as a split at depth 2. |
| **5**| Book Value of Equity / Book Value of Liabilities (BE/BL) | Important for solvency but typically redundant after WC/TA and EBIT/TA have been examined. |

### Interpretation of the splits  

* **Root split – Working Capital / Total Assets**  
  * **≤ 0.20** – The company retains at least 20 % of its assets as working capital, indicating a comfortable liquidity cushion; we predict **no bankruptcy**.  
  * **> 0.20** – The firm is using a larger share of its assets for working capital (or has a very low asset base). This situation alone does **not** guarantee distress, so we look deeper.

* **Second‑level split – EBIT / Total Assets** (only for the “WC/TA > 0.20” branch)  
  * **≤ 0.05** – Operating profit is ≤ 5 % of total assets, a classic red flag of poor profitability; we predict **BANKRUPTCY**.  
  * **> 0.05** – The firm still generates a modest operating profit relative to its asset base, enough to offset the higher working‑capital burden; we predict **NO BANKRUPTCY**.

**Python implementation of the depth‑2 bankruptcy decision tree**

```python
def predict_bankruptcy(X: dict):
    """
    Predict whether a company will go bankrupt (1) or not (0).

    Parameters
    ----------
    X : dict
        A dictionary that contains the five financial‑ratio features.
        Required keys (exact spelling):
            'WC/TA'   – Working Capital / Total Assets
            'EBIT/TA' – Earnings Before Interest & Tax / Total Assets
        (the other three ratios are not needed for this depth‑2 tree,
         but they may be present in the dict.)

    Returns
    -------
    prediction : int
        0 → company did NOT go bankrupt
        1 → company went bankrupt
    nodes : list[int]
        Truth values of the inner nodes (1 = condition satisfied,
        0 = condition not satisfied) in the order they are evaluated:
        [root_node, second_level_node]
    """

    # ---- inner node evaluations ------------------------------------------------
    # Node 0 : root – is the liquidity ratio low enough?
    node0 = 1 if X['WC/TA'] <= 0.20 else 0          # 1 → WC/TA ≤ 0.20

    # Node 1 : second level – profitability ratio (evaluated only when we are
    #          on the “WC/TA > 0.20” branch, but we compute it anyway).
    node1 = 1 if X['EBIT/TA'] <= 0.05 else 0        # 1 → EBIT/TA ≤ 0.05

    # ---- decision logic --------------------------------------------------------
    if node0:                       # WC/TA ≤ 0.20  → safe side
        prediction = 0              # NOT bankrupt
    else:                           # WC/TA  > 0.20  → need deeper test
        if node1:                   # EBIT/TA ≤ 0.05
            prediction = 1          # BANKRUPT
        else:                       # EBIT/TA  > 0.05
            prediction = 0          # NOT bankrupt

    # Return both the class label and the list of node truth values
    return prediction, [node0, node1]
```

### How to use it

```python

    'RE/TA'   : 0.12,   # not used in this tree

    'S/TA'    : 1.10,

```
