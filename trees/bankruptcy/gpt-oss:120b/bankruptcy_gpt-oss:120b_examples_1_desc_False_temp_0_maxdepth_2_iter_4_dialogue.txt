### Decision Tree (max‑depth = 2)

```
|--- Working Capital / Total Assets <= 0.15
|    |--- class: NOT Bankrupt
|--- Working Capital / Total Assets > 0.15
|    |--- Retained Earnings / Total Assets <= -0.05
|    |    |--- class: BANKRUPT
|    |--- Retained Earnings / Total Assets > -0.05
|    |    |--- class: NOT Bankrupt
```

---

### How the tree was built  

| Rank | Feature (ratio)                              | Why it is most important (common in the literature) |
|------|----------------------------------------------|------------------------------------------------------|
| **1**| **Working Capital / Total Assets**           | Directly measures short‑term liquidity. Low values indicate that the firm cannot cover its current liabilities with its current assets – a strong predictor of distress. |
| **2**| **Retained Earnings / Total Assets**         | Captures accumulated profitability. Negative retained‑earnings ratios (i.e., accumulated losses) are a classic red flag for bankruptcy. |
| **3**| Earnings Before Interest & Tax / Total Assets| Reflects operating efficiency, but usually adds less discriminative power once the two top ratios are considered. |
| **4**| Sales / Total Assets                         | A proxy for asset turnover; useful but less decisive for the binary outcome. |
| **5**| Book Value of Equity / Book Value of Liabilities| Provides a balance‑sheet “solvency” perspective, but it often correlates with the first two ratios. |

Only the top two features are used because the tree depth is limited to 2. If you later wish to expand the model (e.g., depth = 3 or more), the next most informative splits would typically involve **EBIT/Total Assets** and **Sales/Total Assets**.

---

### Interpreting the tree  

| Path (conditions)                                           | Predicted outcome |
|--------------------------------------------------------------|-------------------|
| **Working Capital/Total Assets ≤ 0.15**                      | **Not Bankrupt** – the firm has at least 15 % of its assets in liquid working capital, a comfortable cushion. |
| **Working Capital/Total Assets > 0.15** **and**<br>**Retained Earnings/Total Assets ≤ ‑0.05** | **Bankrupt** – despite having a relatively high working‑capital cushion, the firm has accumulated losses exceeding 5 % of its asset base, a strong distress signal. |
| **Working Capital/Total Assets > 0.15** **and**<br>**Retained Earnings/Total Assets > ‑0.05** | **Not Bankrupt** – the firm is both liquid and not deeply loss‑making. |

**Python implementation of the depth‑2 bankruptcy decision tree**

```python
def predict(X: dict):
    """
    Predict whether a company went bankrupt (target = 1) or not (target = 0)
    using a very small decision tree (max depth = 2).

    Expected keys in ``X`` (exact spelling, case‑sensitive):
        - 'WC/TA'   : Working Capital / Total Assets
        - 'RE/TA'   : Retained Earnings / Total Assets
        - 'EBIT/TA' : Earnings Before Interest and Tax / Total Assets
        - 'S/TA'    : Sales / Total Assets
        - 'BVE/BVL' : Book Value of Equity / Book Value of Liabilities

    The function returns a tuple ``(prediction, nodes)`` where
        * ``prediction`` is 0 (not bankrupt) or 1 (bankrupt)
        * ``nodes`` is a list of the truth values of the inner nodes
          (1 = condition satisfied, 0 = condition not satisfied)

    Tree structure (filled with sensible thresholds taken from classic
    bankruptcy‑prediction literature):

        |--- WC/TA <= 0.15
        |        --> NOT bankrupt (0)
        |--- WC/TA > 0.15
                 |--- RE/TA <= -0.05
                 |        --> BANKRUPT (1)
                 |--- RE/TA > -0.05
                          --> NOT bankrupt (0)

    The thresholds:
        * 0.15  – a firm whose working‑capital ratio is ≤ 15 % of assets
                 is usually considered to have a comfortable liquidity cushion.
        * –0.05 – a retained‑earnings ratio ≤ ‑5 % of assets signals
                 accumulated losses and is a strong distress indicator.
    """
    # ------------------------------------------------------------------
    # 1️⃣  Evaluate the two inner‑node conditions (store as 0/1 integers)
    # ------------------------------------------------------------------
    nodes = [0, 0]                                 # placeholder for two nodes
    nodes[0] = int(X["WC/TA"] <= 0.15)              # root node
    nodes[1] = int(X["RE/TA"] <= -0.05)             # second‑level node

    # ------------------------------------------------------------------
    # 2️⃣  Follow the tree logic to obtain the final class label
    # ------------------------------------------------------------------
    if nodes[0]:               # WC/TA <= 0.15  → automatically safe
        prediction = 0         # NOT bankrupt
    else:                      # WC/TA > 0.15  → need the second test
        if nodes[1]:           # RE/TA <= -0.05
            prediction = 1     # BANKRUPT
        else:
            prediction = 0     # NOT bankrupt

    # ------------------------------------------------------------------
    # 3️⃣  Return result
    # ------------------------------------------------------------------
    return prediction, nodes
```
