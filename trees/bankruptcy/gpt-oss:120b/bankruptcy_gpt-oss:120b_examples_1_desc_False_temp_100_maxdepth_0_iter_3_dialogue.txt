## How the tree was built (conceptually)

| Rank | Feature                                 | Why it tends to be most predictive |
|------|-----------------------------------------|------------------------------------|
| 1️⃣   | **Working Capital / Total Assets**      | Direct measure of short‑term liquidity; firms with very low or negative ratios often cannot meet current obligations. |
| 2️⃣   | **Retained Earnings / Total Assets**    | Captures accumulated profitability (or losses). Persistent negative retained earnings signal deteriorating solvency. |
| 3️⃣   | **EBIT / Total Assets**                 | Reflects operating profitability independent of financing structure. Low operating returns are a classic distress indicator. |
| 4️⃣   | **Sales / Total Assets**                | A proxy for asset‑turnover efficiency. Low turnover can mean assets are not generating sufficient cash flow. |
| 5️⃣   | **Book Value of Equity / Book Value of Liabilities** | The classic “equity‑to‑debt” cushion; when equity is far below liabilities the firm is highly leveraged and vulnerable. |

The tree stops splitting once a leaf node reaches a **pure (or near‑pure) class** according to the training data, or when further splits would not improve the impurity measure (e.g., Gini or entropy) beyond a preset threshold.

**Python function – decision‑tree classifier for bankruptcy**

```python
def predict(X: dict):
    """
    Predict whether a company went bankrupt (target = 1) or not (target = 0)
    using a hand‑crafted decision tree based on five financial ratios.

    Parameters
    ----------
    X : dict
        Dictionary that must contain the following keys (exact spelling!)
        - 'WC/TA'  : Working Capital / Total Assets
        - 'RE/TA'  : Retained Earnings / Total Assets
        - 'EBIT/TA': Earnings Before Interest and Tax / Total Assets
        - 'S/TA'   : Sales / Total Assets
        - 'BVE/BVL': Book Value of Equity / Book Value of Liabilities

    Returns
    -------
    prediction : int
        1 → bankrupt, 0 → not bankrupt
    nodes : list[int]
        Truth values (1 = True, 0 = False) of the five inner‑node conditions,
        in the order they appear in the tree.
    """

    # ------------------------------------------------------------------
    # 1️⃣  Inner‑node evaluations (independent of the traversal path)
    # ------------------------------------------------------------------
    nodes = [None] * 5                     # allocate list for 5 inner nodes

    # node 0 : WC/TA <= 0.12
    nodes[0] = 1 if X["WC/TA"] <= 0.12 else 0

    # node 1 : RE/TA <= -0.02
    nodes[1] = 1 if X["RE/TA"] <= -0.02 else 0

    # node 2 : EBIT/TA <= 0.05
    nodes[2] = 1 if X["EBIT/TA"] <= 0.05 else 0

    # node 3 : S/TA <= 0.30
    nodes[3] = 1 if X["S/TA"] <= 0.30 else 0

    # node 4 : BVE/BVL <= 0.80
    nodes[4] = 1 if X["BVE/BVL"] <= 0.80 else 0

    # ------------------------------------------------------------------
    # 2️⃣  Tree traversal – decide the final class
    # ------------------------------------------------------------------
    if nodes[0]:                      # WC/TA <= 0.12
        prediction = 1                # bankrupt
    else:                             # WC/TA > 0.12
        if nodes[1]:                  # RE/TA <= -0.02
            prediction = 1
        else:                         # RE/TA > -0.02
            if nodes[2]:              # EBIT/TA <= 0.05
                prediction = 1
            else:                     # EBIT/TA > 0.05
                if nodes[3]:          # S/TA <= 0.30
                    prediction = 1
                else:                 # S/TA > 0.30
                    if nodes[4]:      # BVE/BVL <= 0.80
                        prediction = 1
                    else:             # BVE/BVL > 0.80
                        prediction = 0

    return prediction, nodes
```
