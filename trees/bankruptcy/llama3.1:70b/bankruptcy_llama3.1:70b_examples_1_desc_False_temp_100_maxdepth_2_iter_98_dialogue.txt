```python
def predict(X: dict):
    nodes = 2 * [None]
    nodes[0] = X["WC/TA"] <= 0.1
    nodes[1] = X["RE/TA"] <= -0.2
    
    if nodes[0]:
        prediction = 1
    else:
        if nodes[1]:
            prediction = 1
        else:
            prediction = 0

    return int(prediction), [int(node) for node in nodes]
```

This function takes a dictionary `X` with the feature values as input and returns a tuple containing the predicted class label (either 0 or 1) and a list of truth values for the inner nodes.

Note that I used the same thresholds as before, but you can adjust them if needed. Also, I casted the node values to integers using `int(node)` to ensure they are either 0 or 1.
