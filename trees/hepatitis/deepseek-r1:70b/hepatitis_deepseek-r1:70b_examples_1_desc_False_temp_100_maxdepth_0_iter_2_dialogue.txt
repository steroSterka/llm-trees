To solve this problem, we need to create a function that predicts whether a patient will survive based on specific medical thresholds. The prediction is determined by evaluating several conditions in sequence, each checking against a particular threshold for different medical parameters.

### Approach
The approach involves evaluating four key medical parameters in a specific order:
1. **Albumin Levels**: If the albumin level is below or equal to 3.5, the patient is predicted not to survive.
2. **Prothrombin Time**: If the prothrombin time exceeds 15 seconds and the albumin level is above 3.5, the patient is predicted not to survive.
3. **Bilirubin Levels**: If the bilirubin level exceeds 2.5 mg/dL and both previous conditions are not met, the patient is predicted not to survive.
4. **Ascites Presence**: If ascites is present (indicated by a value of 1) and none of the previous conditions are met, the patient is predicted not to survive.

Each condition is evaluated in sequence, and if any condition is met, the prediction is set accordingly. The function returns both the final prediction and a list indicating whether each condition was met.

### Solution Code
```python
def predict(X: dict) -> tuple[int, list[int]]:
    # Initialize nodes with all condition evaluations
    albumin_threshold = 3.5
    prothrombin_threshold = 15
    bilirubin_threshold = 2.5
    
    node_albumin = X['ALBUMIN'] <= albumin_threshold
    node_prothrombin = X['PROTIME'] > prothrombin_threshold
    node_bilirubin = X['BILIRUBIN'] > bilirubin_threshold
    node_ascites = X['ASCITES'] == 1
    
    nodes = [node_albumin, node_prothrombin, node_bilirubin, node_ascites]
    
    if node_albumin:
        prediction = 0
    else:
        if node_prothrombin:
            prediction = 0
        else:
            if node_bilirubin:
                prediction = 0
            else:
                if node_ascites:
                    prediction = 0
                else:
                    prediction = 1
    
    # Convert boolean values to integers for the nodes list
    nodes_int = [int(node) for node in nodes]
    
    return prediction, nodes_int
```

### Explanation
The function `predict` takes a dictionary `X` containing medical parameters and returns a tuple with an integer prediction (0 for not surviving, 1 for surviving) and a list of integers indicating whether each condition was met (1 if true, 0 otherwise).

1. **Condition Evaluation**: Each medical parameter is evaluated against its respective threshold to form boolean conditions.
2. **Prediction Logic**: The function checks each condition in sequence. If any condition is met, the prediction is set to 0 (not surviving). If none of the conditions are met, the prediction defaults to 1 (surviving).
3. **Node Conversion**: Boolean results from the condition evaluations are converted to integers for clarity.

This approach ensures that all relevant medical parameters are evaluated in a logical sequence, providing an accurate prediction based on the given thresholds.
