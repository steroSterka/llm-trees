To solve this problem, we need to create a function that predicts whether a patient will survive or die based on their medical conditions, specifically their albumin levels, bilirubin levels, and prothrombin time. The prediction is made using a decision tree approach with two inner nodes (conditions) that determine the outcome.

### Approach
The solution involves evaluating the patient's condition in a sequential manner using a decision tree:
1. **First Condition**: Check if the albumin level is less than or equal to 3.5.
2. **Second Condition**: Depending on the result of the first condition:
   - If the albumin level is low (<= 3.5), check if the bilirubin level is greater than 2.0.
   - If the albumin level is high (> 3.5), check if the prothrombin time is greater than 3.0.

Based on these conditions, we determine whether the patient survives or dies:
- If both the first condition (low albumin) and the second condition (high bilirubin) are true, the patient dies.
- If the first condition is true but the second condition is false, the patient survives.
- If the first condition is false, check the second condition on prothrombin time:
  - If true, the patient dies.
  - If false, the patient survives.

### Solution Code
```python
def predict(X):
    nodes = []
    
    # First condition: albumin level <=3.5
    albumin_cond = X['ALBUMIN'] <= 3.5
    nodes.append(albumin_cond)
    
    if albumin_cond:
        # Second condition: bilirubin >2.0 when albumin is low
        bilirubin_cond = X['BILIRUBIN'] > 2.0
        nodes.append(bilirubin_cond)
    else:
        # Second condition: prothrombin time >3.0 when albumin is high
        protime_cond = X['PROTIME'] > 3.0
        nodes.append(protime_cond)
    
    # Determine the prediction based on conditions
    if albumin_cond:
        if bilirubin_cond:
            prediction = 0  # Die
        else:
            prediction = 1  # Survive
    else:
        if protime_cond:
            prediction = 0  # Die
        else:
            prediction = 1  # Survive
    
    return prediction, nodes
```

### Explanation
- **Initialization**: We start by initializing an empty list `nodes` to keep track of the conditions evaluated.
- **First Condition**: We check if the albumin level is less than or equal to 3.5 and store this result in `albumin_cond`. This condition is added to the `nodes` list.
- **Second Condition**: Depending on whether the albumin condition was true:
  - If true, we check if the bilirubin level exceeds 2.0 and add this result to `nodes`.
  - If false, we check if prothrombin time exceeds 3.0 and add this result to `nodes`.
- **Prediction**: Based on the results stored in `nodes`, we determine the final prediction:
  - If both conditions (low albumin and high bilirubin) are true, the patient dies.
  - If low albumin is true but high bilirubin is false, the patient survives.
  - If albumin is not low, we check prothrombin time: if it's high, the patient dies; otherwise, they survive.

This approach efficiently uses a decision tree to make predictions based on medical conditions, ensuring that each condition is evaluated in sequence to determine the outcome.
