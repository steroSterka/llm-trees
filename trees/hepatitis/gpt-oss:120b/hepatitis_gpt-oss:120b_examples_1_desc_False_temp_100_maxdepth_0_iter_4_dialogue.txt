#### How the tree was derived (quick rationale)

| Split level | Feature (type) | Why it’s often most predictive |
|-------------|----------------|--------------------------------|
| **Root**    | **bilirubin** (continuous) | Direct measure of liver excretory failure; higher values strongly correlate with mortality. |
| **1️⃣**     | **prothrombin time** (continuous) | Reflects synthetic function of the liver; prolonged PT = higher bleed risk & poorer prognosis. |
| **2️⃣**     | **albumin** (continuous) | Low albumin indicates chronic liver decompensation and poor nutritional reserve. |
| **3️⃣**     | **ascites** (yes/no) | Clinical manifestation of portal hypertension & advanced disease – almost always a poor‑prognosis sign. |
| **4️⃣**     | **age** (continuous) | Older patients have less physiologic reserve and higher baseline mortality. |
| **Other variables** (sex, steroids, antivirals, fatigue, malaise, anorexia, liver size, liver firmness, spleen palpable, spider angiomata, varices, alkaline phosphatase, SGOT, histologic data) are **still valuable** but typically rank lower than the variables above in standard prognostic scores (e.g., Child‑Pugh, MELD). ### Using the tree

1. **Measure bilirubin**.  
   *If ≤ 2.0 mg/dL* → go to the left branch; *if > 2.0* → go to the right branch.

2. **Check prothrombin time** (seconds).  
   *If ≤ 14* → continue left; *if > 14* → the patient is classified as **Die**.

3. **Check albumin** (g/dL).  
   *If ≥ 3.5* → **Survive**; *if < 3.5* → **Die**.

4. If bilirubin > 2.0, **look for ascites**.  
   *If ascites present* → **Die**.  
   *If no ascites* → evaluate PT ≤ 16.  

5. With PT ≤ 16 and no ascites, **age** becomes the deciding factor:

    # Node 3 : ASCITES = 0  (i.e., no ascites) – used when BILIRUBIN > 2
    nodes[3] = int(X["ASCITES"] == 0)

    # Node 4 : PROTIME <= 16 (used when BILIRUBIN > 2 and ASCITES = 0)
    nodes[4] = int(X["PROTIME"] <= 16)

    # Node 5 : AGE <= 55 (used when the previous three conditions are true)
    nodes[5] = int(X["AGE"] <= 55)

    # ------------------------------------------------------------------
    # 2. Follow the tree logic to obtain the final prediction
    # ------------------------------------------------------------------
    if nodes[0]:                         # BILIRUBIN <= 2.0
        if nodes[1]:                     # PROTIME <= 14
            if nodes[2]:                 # ALBUMIN >= 3.5
                prediction = 1           # survive
            else:
                prediction = 0           # die
        else:
            prediction = 0               # die (PROTIME > 14)
    else:                                # BILIRUBIN > 2.0
        if nodes[3]:                     # ASCITES = 0 (no ascites)
            if nodes[4]:                 # PROTIME <= 16
                if nodes[5]:             # AGE <= 55
                    prediction = 1       # survive
                else:
                    prediction = 0       # die (older)
            else:
                prediction = 0           # die (PROTIME > 16)
        else:

### How the function works
| Node index | Condition (what the node tests) | Meaning when the value is **1** |
|------------|--------------------------------|---------------------------------|
| 0 | `BILIRUBIN <= 2.0` | Patient has low bilirubin (good liver excretory function) |
| 1 | `PROTIME <= 14` | Coagulation is within normal range |
| 2 | `ALBUMIN >= 3.5` | Adequate synthetic liver function |
| 3 | `ASCITES == 0` | No clinically detectable ascites |
| 4 | `PROTIME <= 16` | Slightly prolonged but not severe clotting defect |
| 5 | `AGE <= 55` | Patient is relatively young |

The tree first checks bilirubin; if it is low, it looks at coagulation (PROTIME) and albumin to decide survival.  
If bilirubin is high, the presence of ascites, a second PROTIME check, and age determine the outcome. All other branches lead to a **die** prediction (0), which is consistent with the clinical intuition that high bilirubin, ascites, prolonged PT, low albumin, or advanced age are strong mortality risk factors.
