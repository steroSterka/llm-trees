        X[col] = le.fit_transform(X[col])

X_train_selected = X_train[top_features]
X_test_selected = X_test[top_features]

```python
def predict_patient_outcome(X: dict):
    nodes = 2 * [None]
    # Node 0 checks if BILIRUBIN levels are within a relatively normal range (< 2 mg/dL)
    nodes[0] = X["BILIRUBIN"] <= 2
    
    # Node 1 checks if ALK PHOSPHATE is within a higher but still concerning range (> 150 units/liter)
    nodes[1] = X["ALK PHOSPHATE"] > 150
    
    if nodes[0]:
        # If bilirubin levels are relatively normal, patient likely survives
        prediction = 1
    else:
        # If bilirubin levels are high, we look at ALK PHOSPHATE for further assessment
        if nodes[1]:
            # High ALK PHOSPHATE and high BILIRUBIN suggest severe liver issues; patient unlikely to survive
            prediction = 0
        else:
            # Elevated BILIRUBIN but not severely elevated ALK PHOSPHATE might still indicate a chance of survival
            prediction = 1

    # Convert boolean nodes to integers (True -> 1, False -> 0)
    nodes = [int(node) for node in nodes]

    return prediction, nodes
```

This function takes a dictionary `X` with patient features as input and returns the predicted outcome (`0` for die, `1` for survive) along with a list of boolean values indicating whether each inner node's condition was met. The thresholds used are somewhat arbitrary and based on general medical guidelines; in practice, these would be determined through analysis of the actual dataset or clinical expertise.
